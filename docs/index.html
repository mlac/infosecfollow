1. BeyondTrust Zero-Day Opens Remote Support Servers

Nation-State Activity · [zero-day, apt, patch]

Latest developments: CISA added CVE-2026-102764 to its Known Exploited Vulnerabilities catalog on October 16, 2026 and told organizations running BeyondTrust Remote Support 26.2.3 and earlier to patch at once, upgrading first if they sit below version 24.3.1, saying attackers use the 9.3-rated improper origin validation flaw for initial access and then establish persistence, escalate privileges, and move laterally; researchers tie the zero-day exploitation to Armory Castle, the China-nexus espionage group they previously tracked as UNC5221 and Warp Panda, which broke in during late August 2026, installed custom tools, and deleted logs and artifacts to cover its path.

read more

BeyondTrust Remote Support, the product organizations once bought as Bomgar, gives help desks privileged access to employee machines, so a takeover of the server hands an attacker that same reach. Administrators running Remote Support should apply the fix and hunt for deleted logs and unexplained sessions dating to August 2026.

3. FortiOS, F5, Juniper, and Office Draw Fixes

Vulnerabilities and Exploits · [patch, malware, zero-day]

Latest developments: CISA added CVE-2025-61624 to its Known Exploited Vulnerabilities catalog on October 16, 2026, the path traversal flaw in the command line interpreter of FortiOS, FortiPAM, FortiProxy, and FortiSwitchManager that a suspected advanced actor exploits to deliver PEERSTITCH, a memory-resident ARM64 malware that bypasses checks on tagged VPN sessions; F5 and Juniper Networks patched critical flaws that reach remote code execution and full device takeover; Microsoft closed two dozen remote code execution bugs in Office plus several information disclosure flaws and a security bypass; and Microsoft said its KB5127648 Windows 11 security update may stop users from turning Smart App Control on.

read more

PEERSTITCH lives only in memory, so a reboot erases it and a forensic image of disk shows nothing, and the Fortinet bug it rides carries a modest 5.4 severity score. Administrators should patch FortiOS, F5, Juniper, and Office now, and Windows 11 users who cannot enable Smart App Control after October's update should treat the control as off.

6. BlockStrap and OpenBSD Hand Over Root

Vulnerabilities and Exploits · [rce, patch, exploit]

Latest developments: Researchers warned on October 16, 2026 that attackers may soon exploit CVE-2026-103849, a maximum-severity flaw in the BlockStrap component of Magento and Adobe Commerce that runs arbitrary PHP code on a store's server, and the security firm Calif published a full proof of concept that takes root on OpenBSD 7.9 by chaining a roughly 37-year-old integer overflow in shared memory with a separate kernel flaw, defeating OpenBSD's KARL kernel address randomization along with SMAP and SMEP hardware protections.

read more

A BlockStrap takeover gives an attacker the code that handles every checkout on an online store, and the OpenBSD chain turns any local account on a patched-reputation operating system into root. Merchants should patch Magento and Adobe Commerce now, and OpenBSD administrators should install the fixes the project shipped before Calif released the exploit.
