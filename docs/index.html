1. VMware vCenter Zero-Day Serves a Chinese APT

Nation-State Activity · [zero-day, apt, patch]

Latest developments: Broadcom shipped fixed builds for every supported VMware vCenter Server branch after Google reported that a China-linked espionage group exploited the authentication bypass, rated 9.8, as a zero-day starting in September 2026, and the advisory lists no workaround.

read more

2. nginx2root Exploits Go Public as Splunk Patches 140 Bugs

Vulnerabilities and Exploits · [patch, exploit, end-of-life]

Latest developments: F5 patched five nginx2root vulnerabilities that let remote, unauthenticated attackers run arbitrary code, and proof-of-concept exploits reached the public, with researchers chaining two of the bugs to a Linux kernel flaw to take root; Xint named the set, Rapid7, Wiz, Ikotas Labs, Palo Alto Networks, and Metnir independently found CVE-2026-123633 and CVE-2026-123007, and nobody has reported exploitation in the wild; Splunk fixed nearly 140 flaws across three core products, among them authentication bypass, remote code execution, and privilege escalation; ASUS released Control Center Express 1.7.29 to close three critical bugs, one of them a hard-coded key that hands a remote attacker administrative control of the management console and every device it manages; SonicWall told customers in a Wednesday advisory to replace every Gen 6 and Gen 6.5 appliance and pull it off the internet edge, because SonicOS 6.x now receives no firmware or security updates regardless of severity; and CISA warned that three flaws in Elecbrakes EB2, VM1, and ELBC2000 controllers let an attacker seize a trailer's brakes, rewrite the firmware, and kill the brake lights.

read more

The nginx2root bugs have sat in NGINX's open-source HTTP/2 code since version 1.9.5 shipped on September 22, 2015, and F5 fixed them in 1.31.9 and 1.30.7. Any internet-facing NGINX with HTTP/2 enabled, Splunk deployment, ASUS management console, or SonicWall Gen 6 firewall needs action this week.

4. PHP, Ruby, and Databases Ship Code-Execution Fixes

Vulnerabilities and Exploits · [patch, exploit]

Latest developments: PHP shipped its releases on November 19, 2026, closing 18 vulnerabilities, seven of them critical remote code execution bugs, among them CVE-2026-115560 in session upload progress and phpAfterShell, CVE-2026-126714, which cuts a session write off at the right moment so file-based session storage returns objects the attacker chose and a gadget chain in the application turns them into commands; Dark Reading reported that exploitability varies sharply with configuration, so the releases demand prompt patching without PHP2Shell-grade alarm; PHP 8.6 landed the same day, starting sessions with session.use_strict_mode and session.cookie_httponly on and session.cookie_samesite set to Lax; Ruby fixed seven memory-safety bugs in its regular expression engine and string case-conversion code, and its maintainers say proof-of-concept exploits run code through five of them; and a researcher published working exploits that carry a low-privilege database account into code execution on PostgreSQL, MySQL, and ClickHouse servers, plus a separate Oracle chain.

read more

Three of the most widely deployed back-end runtimes now carry fresh unauthenticated or low-privilege paths to the operating system account under the service. Upgrade PHP and Ruby today, and audit which database accounts can create objects or call engine functions.
