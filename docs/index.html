3. Certificate Clocks Tighten for Web and Windows

Identity and Trust Infrastructure · [pki, patch, policy]

Latest developments: Let's Encrypt said it will issue certificates valid for 64 days by default starting February 10, 2027, down from 90 days and ahead of a later move to 45 days, with the last 90-day certificate expiring May 11, 2027 and no revocations during the transition; Microsoft separately told customers to patch Windows before the certificates that authenticate Windows Update servers expire on May 17 or June 19, 2027, depending on the Windows version.

read more

Shorter web certificate lifetimes make manual renewal untenable and force teams onto automated ACME issuance, while Windows devices that miss Microsoft's certificate rotation updates will lose access to Windows Update and the security fixes it delivers. Subscribers already on Let's Encrypt's 45-day or 6-day certificates see no change; Windows administrators should confirm machines take the rotation updates well before May 2027.
