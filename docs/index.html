Latest developments: Help Net Security's November 8, 2026 roundup carries an interview in which Vinay Thakker, chief technology officer of KloudStax, lays out the first ten lines of a command policy for AI coding agents: each agent runs under its own identity, carries a person's identity only while acting for that person, and operates inside set credential and network limits.
