4. Gheist Expands Across 850 GitHub Accounts

Ransomware and Cybercrime · [supply chain, credential theft, devops]

Latest developments: Wiz Research put numbers on the campaign on October 27, 2026, recovering more than 13,500 planted branches from over 850 compromised GitHub accounts, and explained the name Gheist, which comes from the user agent the attacker's tool sends with its GitHub API requests.

read more

The tool takes a stolen GitHub token, enumerates every repository that token opens, plants a workflow that prints the repository's secrets into a build log, then downloads the log and deletes the run. The damage lands inside private repositories and GitHub Enterprise environments, so rotate tokens and audit Actions run history.
