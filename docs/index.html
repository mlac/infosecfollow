4. ClickFix Lures Wear Zillow, Teams, and AI Brands

Ransomware and Cybercrime · [phishing, malware, social engineering]

Latest developments: The SANS Internet Storm Center documented Macfinger, a ClickFix campaign that pushes the DownTheDRAIN infostealer onto macOS, which extends the pattern three other teams reported this week: EfficientIP Research Labs traced ClickFix pages dressed as Zillow apartment reviews that copied a PowerShell command to the visitor's clipboard behind a routine-looking verification check and installed NetSupport RAT with its window hidden and a restart at every login; the browser security company Island counted 186 lookalike domains impersonating AI tools, a pattern it calls TypoPrompting, serving the same verification lures plus browser-hijacking malware and search-hijacking extensions; and Huntress documented attackers who used a fake Microsoft Teams meeting scheduler to talk an employee at a construction company into typing a device code into Microsoft's genuine sign-in page, which handed them a valid session token before the Huntress security operations center caught it.

read more

All of these campaigns ask the victim to perform one normal-looking step—paste a command, enter a code—and that step delivers remote access, an infostealer, or a session token. Blocking clipboard-to-shell execution on Windows and macOS, disabling the device code sign-in flow where business needs allow, and filtering lookalike AI domains cut off the common path.
