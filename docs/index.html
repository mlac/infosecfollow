Platform Security · [privacy, hardware]

Latest developments: Apple published the architecture of Secure Exclaves, which isolates camera and microphone data from the main operating system on HomeView and the newest iPhones, so a compromise of iOS alone leaves ambient sensor data out of an attacker's reach.
