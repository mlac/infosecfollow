1. SSHole, Plex2Shell, and SonicWall Under Active Attack

Vulnerabilities and Exploits · [exploit, patch, zero-day]

Latest developments: SecurityWeek pinned the first wave of exploitation of CVE-2026-123158, the OpenSSH authentication bypass researchers call sshole, on botnets and cryptocurrency miners on November 9, 2026 and expects better-resourced crews to follow; the SANS Internet Storm Center logs rising attempts against it through its Cowrie honeypots, which keep only the first 255 characters of an SSH password while the exploit needs one between 257 and 1,024 bytes; and SecurityWeek confirmed that attackers run the four-flaw Plex2Shell chain against Plex Media Server on QNAP network-attached storage devices.

read more

The sshole flaw lets anyone with network access, an account name, and an overlong password log into key-only or passwordless accounts on musl-based Linux systems, which OpenSSH fixed in version 10.6p2. SonicWall has now shipped a patch for CVE-2026-19868, the SSL-VPN flaw that walks past SAML-enforced multifactor authentication, and lists no workaround, so administrators should update SonicOS, OpenSSH, and Plex Media Server on QNAP boxes immediately.
