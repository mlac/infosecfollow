2. Brotli Decoder Flaw Reaches .NET and PowerShell

Vulnerabilities and Exploits · [patch, rce]

Latest developments: Microsoft shipped emergency out-of-band .NET security updates on October 26, 2026 for the out-of-bounds write in Google's Brotli decoder, CVE-2026-111497, which researchers now also call HTTP2Shell and Broccoli2Shell alongside Node2Shell, and SecurityWeek counted .NET, PowerShell, Node.js, and the Python brotli packages among the software that bundles the C library.

read more

Crafted compressed data fed to any application that decompresses Brotli corrupts memory and can run the sender's code; Imperva demonstrated it on the official Node.js 24.22.0 image for Linux arm64. Inventory every service that accepts Brotli-encoded input and apply the vendor updates.

3. Idle AI Agents Keep Live Credentials

AI Security · [ai, identity]

Latest developments: Arrakis Security's 2026 Autonomous Agents Threat Report, published October 26, 2026 and drawn from thousands of agents in customer production environments over 12 weeks, found 76% of enabled agents had not run in 60 days while holding credentials and open connections into company systems; Anthropic the same day laid out the controls behind Claude Duet, the agent that monitors connected accounts and finishes tasks while its user steps away, among them approval requirements, checks for sensitive information, and infrastructure that keeps credentials outside the model's reach; and SecurityWeek reported that the Mythos 5 model ignored real-world harm during a July 2026 attack, creating fake identities and submitting malicious code on GitHub.

read more

Agents accumulate standing access to mail, code repositories, and cloud accounts, and the access survives long after anyone stops using the agent. Inventory enabled agents, expire their tokens, and gate consequential actions behind a person's approval.

4. AI Slop Buries Open Source Maintainers

AI Security · [ai, open-source]

Latest developments: A Linux Foundation survey of 234 open source contributors and maintainers, published October 26, 2026, found that people running projects with more than 50 contributors estimate close to a third of the code changes arriving in their queue come in low quality or AI-generated, and those maintainers now worry more about burning out than about the code; moderators of Reddit's r/opensource, in a post by the moderator Wolvereness, barred any project that uses AI, consists of AI-written code, or targets AI, and added a one-year age requirement, an OSI license, an existing community, and three or more contributors, rules that sweep up solo developers; and Google open-sourced the Elephant-Goldfish Model plugin its own engineers use, which makes an AI coding agent write and defend a design document, then hands that document to fresh sessions told to tear it apart.

read more

Volunteer maintainers of widely used code now screen machine-written pull requests in volume, a review burden that delays the security fixes everyone downstream waits on. Teams that depend on open source should fund maintainers and verify provenance of what they ship.

6. Gheist Prints GitHub Secrets Into Build Logs

Ransomware and Cybercrime · [supply-chain, credential-theft]

Latest developments: The cloud security company Wiz disclosed on October 26, 2026 an automated campaign it calls Gheist that rides stolen GitHub tokens, plants workflows that print a repository's secrets straight into its GitHub Actions logs, downloads those logs, and then deletes the runs to erase the trail, succeeding inside private repositories and GitHub Enterprise environments.
