2. FortiOS, F5, Juniper, and Office Draw Fixes

Vulnerabilities and Exploits · [patch, malware, zero-day]

Latest developments: A suspected advanced actor exploited CVE-2025-61624, a path traversal flaw in the command line interpreter of FortiOS, FortiPAM, FortiProxy, and FortiSwitchManager, to deliver PEERSTITCH, a memory-resident ARM64 malware that bypasses checks on tagged VPN sessions; F5 and Juniper Networks patched critical flaws that reach remote code execution and full device takeover; Microsoft closed two dozen remote code execution bugs in Office plus several information disclosure flaws and a security bypass; and Microsoft said its KB5127648 Windows 11 security update may stop users from turning Smart App Control on.

read more

PEERSTITCH lives only in memory, so a reboot erases it and a forensic image of disk shows nothing, and the Fortinet bug it rides carries a modest 5.4 severity score. Administrators should patch FortiOS, F5, Juniper, and Office now, and Windows 11 users who cannot enable Smart App Control after October's update should treat the control as off.

3. BeyondTrust Zero-Day Opens Remote Support Servers

Nation-State Activity · [zero-day, apt, patch]

Latest developments: BeyondTrust told customers on Thursday, October 15, 2026 to patch CVE-2026-102764, a 9.3-rated improper origin validation flaw in an internal messaging component of its Remote Support product, and researchers tied the zero-day exploitation to Armory Castle, the China-nexus espionage group they previously tracked as UNC5221 and Warp Panda, which used the bug for initial access in late August 2026, installed custom tools, and then deleted logs and artifacts to cover its path.

read more

BeyondTrust Remote Support, the product organizations once bought as Bomgar, gives help desks privileged access to employee machines, so a takeover of the server hands an attacker that same reach. Administrators running Remote Support should apply the fix and hunt for deleted logs and unexplained sessions dating to August 2026.

Latest developments: Netscout counted more than 9.1 million distributed denial-of-service attacks worldwide between January and June 2026, up nearly a quarter year over year, with attacks above 1 terabit per second or 1 billion packets per second climbing 1,286%, growth the firm traces to the botnets Aisuru, Kimwolf, and Jackskid and their successors, which knock services down before traffic fills the target's links.
