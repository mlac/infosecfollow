1. nginx2root Exploits Go Public as Splunk Patches 140 Bugs

Vulnerabilities and Exploits · [patch, exploit, end-of-life]

Latest developments: F5 patched five nginx2root vulnerabilities that let remote, unauthenticated attackers run arbitrary code, and proof-of-concept exploits reached the public, with researchers chaining two of the bugs to a Linux kernel flaw to take root; Xint named the set, Rapid7, Wiz, Ikotas Labs, Palo Alto Networks, and Metnir independently found CVE-2026-123633 and CVE-2026-123007, and nobody has reported exploitation in the wild; Broadcom disclosed a VMware vCenter authentication bypass rated 9.8 that hands a network attacker unauthorized access, shipped fixed versions for every supported branch, and listed no workaround; Splunk fixed nearly 140 flaws across three core products, among them authentication bypass, remote code execution, and privilege escalation; and SonicWall told customers in a Wednesday advisory to replace every Gen 6 and Gen 6.5 appliance and pull it off the internet edge, because SonicOS 6.x now receives no firmware or security updates regardless of severity.

read more

The nginx2root bugs have sat in NGINX's open-source HTTP/2 code since version 1.9.5 shipped on September 22, 2015, and F5 fixed them in 1.31.9 and 1.30.7. Any internet-facing NGINX with HTTP/2 enabled, vCenter console, Splunk deployment, or SonicWall Gen 6 firewall needs action this week.

Vulnerabilities and Exploits · [exploit, patch]

Five widely deployed products—Cisco Expressway, Apache Roller, Apache Axis, Puppet Enterprise, and Drupal—now carry unauthenticated paths to code execution with attacks already running. Patch the internet-facing ones first and treat the Puppet server as a route to every endpoint it configures.

3. PHP, Ruby, and Databases Ship Code-Execution Fixes

Vulnerabilities and Exploits · [patch, exploit]

Latest developments: PHP shipped its releases on November 19, 2026, closing 18 vulnerabilities, seven of them critical remote code execution bugs, among them CVE-2026-115560 in session upload progress and phpAfterShell, CVE-2026-126714, which cuts a session write off at the right moment so file-based session storage returns objects the attacker chose and a gadget chain in the application turns them into commands; PHP 8.6 landed the same day, starting sessions with session.use_strict_mode and session.cookie_httponly on and session.cookie_samesite set to Lax; Ruby fixed seven memory-safety bugs in its regular expression engine and string case-conversion code, and its maintainers say proof-of-concept exploits run code through five of them; and a researcher published working exploits that carry a low-privilege database account into code execution on PostgreSQL, MySQL, and ClickHouse servers, plus a separate Oracle chain.

read more

Three of the most widely deployed back-end runtimes now carry fresh unauthenticated or low-privilege paths to the operating system account under the service. Upgrade PHP and Ruby today, and audit which database accounts can create objects or call engine functions.

Sources: SecurityWeek · The Hacker News · The Hacker News · The Hacker News · ↑ top

4. AI Agents Run on Their Builders' Credentials

AI Security · [ai, identity]

Latest developments: Nudge Security, drawing on telemetry from its customers' environments, found that the AI agents employees assemble inside project trackers, CRMs, and automation tools run on the credentials of whoever built them and inherit that person's access to company data, with no one monitoring how the agents spend it; Wired documented Artex, the open-source AI penetration-testing framework, as the point-and-shoot tool newcomers now use to scan and attack targets through chatbot prompts; Google built a replica of the internet, a sandbox its Chrome team calls a mirror dimension, to train browsing agents without turning them loose on real sites; Microsoft moved its Perception agentic security platform out of preview, making four blue team agents and the Recon Agent generally available; and Palo Alto Networks agreed to buy Applied Compute, which post-trains and runs open-weight models, for $4.5 billion in stock.

read more

Employee-built agents carry human entitlements into automated workflows while attackers drive the same agent frameworks offensively. Inventory which agents run in your environment, whose identity each one uses, and what systems it can reach.

7. Java4Shell Draws Live Exploit Attempts

Vulnerabilities and Exploits · [exploit, patch, zero-day]

Latest developments: GreyNoise, watchTowr, and Cloudflare each reported probing and exploit attempts against CVE-2026-114938, and Cisco, Elastic, Red Hat, and Siemens published advisories spelling out which of their products carry the vulnerable runtime; Dark Reading reported that researchers found the flaw using AI.

read more

Java4Shell is a memory corruption bug in the Base64 decoder of the x86-64 HotSpot Java Virtual Machine that hands an attacker who never logs in remote code execution on Jenkins, Atlassian Jira, Confluence, and Keycloak.
