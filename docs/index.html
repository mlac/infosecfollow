1. Java4Shell Forces Emergency Java Patching

Vulnerabilities and Exploits · [patch, zero-day, java]

Latest developments: CISA urged organizations on November 17, 2026 to patch CVE-2026-114938 immediately, a memory-corruption flaw researchers call Java4Shell that sits in the Base64 decoder of the x86-64 HotSpot Java Virtual Machine and hands an unauthenticated attacker remote code execution on Jenkins, Atlassian Jira, Confluence, and Keycloak; Oracle released fixes the same day for 11 Java SE vulnerabilities, all remotely exploitable without authentication and topping out at CVSS 8.1, and CISA separately added CVE-2026-115731, a deserialization flaw in Perforce Puppet Enterprise, to its Known Exploited Vulnerabilities catalog.

read more

Crafted Base64 input crashes the Java Virtual Machine inside the Java Development Kit and can run attacker code, and enterprise applications decode untrusted Base64 by the thousands of requests. Install Oracle's November 17, 2026 Java SE updates and the corresponding OpenJDK builds, then inventory every Java service that accepts input from the internet.
