1. Attackers Exploit the SSHole Bypass

Vulnerabilities and Exploits · [zero-day, patch, linux]

Latest developments: The threat intelligence firm Previdian warned on November 6, 2026 that attackers already exploit CVE-2026-123158, the OpenSSH flaw Wakefield researcher Ozgun Kultekin nicknamed sshole, hours after its disclosure and one day after OpenSSH shipped version 10.6p2; D-Link published mitigation steps the same day for multiple unpatched zero-days in its DGS-3130 series managed stackable switches; and Microsoft's fix for CVE-2026-83844, an out-of-bounds read in Windows Paint that allows remote code execution, reaches users only as Microsoft Store build 11.2609.401.0 and never through Windows Update.

read more

CVE-2026-123158 lets anyone who can reach an SSH port log into key-only or passwordless accounts on Alpine Linux and other musl libc systems running without PAM, using any password between 257 and 1,024 bytes. Install OpenSSH 10.6p2 or a distribution package built from it immediately, apply D-Link's mitigations for DGS-3130 switches, and update Paint from the Store.
