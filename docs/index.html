1. Java4Shell Narrows to AVX-512 Chips

Vulnerabilities and Exploits · [zero-day, patch, vulnerability]

Latest developments: Cisco Talos scored Java4Shell at 9.2 under CVSS 4.0, and researchers pinned down its reach: the vulnerable code runs only on Java 17.0.6 and later and only on x86-64 Intel and AMD processors that support the AVX-512 VBMI feature, with Calif demonstrating remote code execution against Jira, Jenkins, and Keycloak while VulnCheck says a working attack takes per-target engineering and no one has yet confirmed a successful intrusion.

read more

CVE-2026-114938 is an out-of-bounds write in the Base64 decoder of OpenJDK that hands an unauthenticated attacker denial of service or code execution on Jenkins, Atlassian Jira, Confluence, Keycloak, and other Java servers reaching most of the Fortune 500. Oracle and the OpenJDK project released fixes on November 17, 2026, and CISA tells organizations to patch immediately.

3. Poisoned Agent Framework Steals Cloud Keys

Software Supply Chain Security · [supply chain, credential theft, ai]

Latest developments: Attackers published malicious versions 1.26.1 and 1.26.2 of Microsoft's agent-framework package to PyPI 33 minutes apart on November 17, 2026, each one running a credential stealer every time Python starts and shipping out Azure, Azure DevOps, and GitHub Actions credentials, with Aikido, Chainguard, Endor Labs, OX Security, SafeDep, Socket, StepSecurity, and Wiz all reporting the compromise.

10. A Flash Chip Attack Cracks BitLocker PINs

Vulnerabilities and Exploits · [vulnerability, encryption, endpoint]

Latest developments: Researchers at Technische Universität Berlin showed that anyone who opens a PC case can reset the TPM lockout that limits guesses at Windows Hello and BitLocker PINs on AMD-based machines and some Intel machines, and in lab tests they recovered a four-digit Hello PIN on an AMD laptop and a six-digit BitLocker PIN on an Intel laptop in days.

read more

The trusted platform module normally throttles PIN guessing, and clearing that counter turns a short PIN into a brute-force problem small enough to finish over a long weekend, which puts stolen and lost laptops at risk. Organizations relying on BitLocker PINs should require long passphrases, add pre-boot protections beyond the PIN, and treat physical access to a device as a full compromise path.
