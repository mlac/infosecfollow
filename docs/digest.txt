1. PHP2SHELL EXPLOITATION BEGAN BEFORE DISCLOSURE
   Vulnerabilities and Exploits · [zero-day, patch, exploit]
   Latest developments: Amazon's threat intelligence team, whose
   chief information security officer CJ Moses described the
   finding, said its MadPot honeypot service logged an exploit
   attempt from a commercial anonymization network on October
   17, 2026, four days before the PHP Foundation disclosed
   CVE-2026-109618 and CVE-2026-109619, and broad scanning
   followed within hours of the patches; Palo Alto Networks
   confirmed that every version of PAN-OS and Panorama carries
   the flaws and has shipped no fixed release, Fortinet is
   checking 12 products and Cisco 31 products and cloud
   services, and OpenAI proposed a five-stage disclosure process
   for critical open-source bugs after Calif found one of the
   two flaws with the GPT-5.6 Sol model under OpenAI's Patch the
   Planet initiative and Wiz reported both independently.
   PHP2Shell is a pair of critical flaws in the PHP runtime that
   run an unauthenticated attacker's code on any server
   answering web requests, regardless of the application on top.
   CISA tells organizations to move to PHP 8.5.12, 8.4.27,
   8.3.36, or 8.2.35 immediately; customers of appliances that
   embed PHP, among them PAN-OS and Panorama, must wait on
   vendor builds and restrict management interfaces meanwhile.
   - SecurityWeek: https://www.securityweek.com/php2shell-exploitation-started-days-before-patches/
   - The Hacker News: https://thehackernews.com/2026/10/someone-tried-to-exploit-php2shell-4.html
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/22/php2shell-vulnerability-fortinet-cisco-palo-alto-networks/

2. ORACLE, CISCO, AND NODE.JS SHIP A PATCH WAVE
   Vulnerabilities and Exploits · [patch, rce, dos]
   Latest developments: Oracle's October 2026 Critical Patch
   Update, published October 22, 2026, carries more than 1,200
   fixes, nearly 100 of them critical, with Fusion Middleware
   taking the largest share; Cisco closed 34 flaws spanning
   command execution, authentication bypass, and cross-site
   scripting; Node.js patched 10 bugs across its 22.x, 24.x, and
   26.x lines, the worst a remote code execution flaw in the
   Brotli decompression code it bundles; FoxIO published working
   proof-of-concept code for QPACK flaws that let one
   unauthenticated connection crash many HTTP/3 servers by
   expanding a small batch of compressed headers into thousands
   of times more memory; and Splunk, SolarWinds, and Signal
   shipped their own fixes, the last closing CVE-2026-113380 in
   RingRTC versions before 2.72.0, which kept sending a caller's
   audio to the other party after that caller hung up.
   The quarterly releases and out-of-cycle fixes land in the
   same week as PHP2Shell, which stretches patch teams thin.
   Administrators should rank unauthenticated code execution
   first, starting with internet-facing Node.js services, Cisco
   gear, and any HTTP/3 endpoint, then work through Oracle's
   middleware stack.

3. CLAUDE AUDITS OPEN SOURCE AS AGENT PERMISSIONS SPREAD
   AI Security · [ai, supply chain, research]
   Latest developments: Anthropic's Frontier Red Team reported
   on October 22, 2026 that it used Claude to examine 25
   open-source projects and found 493 problems involving
   unnecessary exposure, conflicting settings, and code that
   runs before security checks, among them 94 cases where a
   project drops security controls with no warning; a survey of
   1,100 information technology and security decision-makers
   found 70% now let AI make decisions and take actions that
   needed a person's sign-off a year ago, with three in four
   organizations hitting at least one AI-related security
   problem or warning sign in the past year; and researchers at
   Imperial College London tampered with speech-to-text models
   so that one chosen speaker's words transcribed as text the
   attacker picked, in one test a request to send $5,000 that AI
   agents reading the transcript executed in a sandboxed banking
   environment.
   The three findings share a root: organizations hand agents
   authority faster than they inspect the code and models
   underneath. Teams running agents should cut exposed
   functionality in the software agents touch, require approval
   for financial actions, and treat fine-tuning access to a
   speech model as a privileged pipeline.
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/22/anthropic-attack-surface-reduction-open-source/

4. APT41 BOOTKIT AND SANDWORM WIPER
   Nation-State Activity · [apt, malware, wiper]
   Latest developments: Kaspersky's Global Research and Analysis
   Team disclosed BlackX on October 22, 2026, a UEFI bootkit
   built along the lines of BlackLotus that the Chinese group
   APT41 revived against diplomatic organizations in Central
   Asia, exploiting the Baton Drop flaw CVE-2022-21894 in the
   Windows boot manager to run before the operating system
   loads; separately, researchers said on October 21, 2026 that
   the Russian state-linked group Sandworm worked with a second
   threat actor last year to destroy data at a Ukrainian grain
   logistics company.
   A UEFI bootkit loads ahead of Windows and survives a
   reinstall, which puts boot-chain integrity and firmware
   monitoring at the center of any response. Diplomatic missions
   in Central Asia and Ukrainian agricultural logistics firms
   face the two campaigns; both call for verified offline
   backups and checks that Secure Boot revocations for
   CVE-2022-21894 sit in place.
   - Securelist (Kaspersky): https://securelist.com/uefi-bootkit-blackx/121539/
   - The Record: https://therecord.media/ukraine-hackers-russia-grain-sandworm
