1. DISCOVER-TECH ADS CARRIED CANDIRU'S ZERO-CLICK SPYWARE
   Surveillance and Spyware · [spyware, zero-click, adtech]
   Latest developments: SecurityWeek named the delivery channel
   on October 17, 2026: the Israeli advertising company
   Discover-Tech, whose ads fingerprint and track devices at
   scale and then infect selected targets, carried Candiru's
   spyware onto devices at Al Jazeera Media Network, and

   staff should block ad networks and advertising identifiers at

3. STOLEN CONNECTWISE CREDENTIAL OPENS 173 MICROSOFT 365 TENANTS
   Ransomware and Cybercrime · [supply chain, credential theft,
   cloud]
   Latest developments: Researchers warned on October 17, 2026
   of an active campaign in which unidentified attackers use one
   compromised Microsoft 365 credential belonging to ConnectWise
   Cloud Backup, the service formerly sold as SkyKick, to sign
   in to 173 customer Microsoft 365 tenants.
   ConnectWise Cloud Backup copies Microsoft 365 mail and files
   for managed service providers and their clients, so a single
   vendor credential reaches far down the customer chain.
   Administrators should pull sign-in logs for the ConnectWise
   service principal, revoke active sessions, and rotate
   application secrets.
   - The Hacker News: https://thehackernews.com/2026/10/hackers-use-compromised-connectwise.html

4. MALFEX NPM PACKAGE HIDES A SHELLCODE LOADER
   Ransomware and Cybercrime · [supply chain, malware, npm]
   Latest developments: Researchers reported on October 17, 2026
   that imgdecode, an npm package a user calling itself
   malfexteste8 uploaded on September 30, 2026, buries a
   shellcode loader inside a Windows native addon as part of the
   MALFEX supply chain campaign; the package counts 979
   downloads and still sits on the registry.
   Native addons ship as compiled binaries that most package
   scanners never open, so the loader runs on a developer's
   Windows machine at install time. Search build systems and
   lockfiles for imgdecode and remove it.
   - The Hacker News: https://thehackernews.com/2026/10/malfex-npm-package-imgdecode-hides.html

5. EDGE APPLIANCES LEAD THE INITIAL ACCESS COUNT
   Vulnerabilities and Exploits · [zero-day, patch, apt]
   Latest developments: Unit 42 published its September 2026
   tally on October 16, 2026, putting edge device exploits first
   among initial access vectors, ahead of credential abuse and
   phishing, and Dark Reading set the BeyondTrust Remote Support
   zero-day CVE-2026-102764 beside the Ivanti Connect Secure,
   Cisco Secure Email Gateway, and Palo Alto Networks PAN-OS
   flaws attackers exploited the same week.
   VPN gateways, remote support servers, email security
   appliances, and firewalls now absorb most of the exploited
   bugs, and the China-nexus espionage group Armory Castle rides
   the 9.3-rated BeyondTrust improper origin validation flaw for
   initial access. Patch BeyondTrust Remote Support, Ivanti
   Connect Secure, Cisco Secure Email Gateway, and PAN-OS, then
   hunt for persistence and deleted logs.
   - Dark Reading: https://www.darkreading.com/endpoint-security/beyondtrust-remote-support-exploited-edge-bugs
