9. LINUX KERNEL MPTCP FLAW YIELDS REMOTE ROOT
   Vulnerabilities and Exploits · [vulnerability, patch, ai]
   Latest developments: Security researchers at Anthropic built
   a working exploit for the critical Linux kernel vulnerability
   that lets an unauthenticated attacker run commands as root on
   any server listening with Multipath TCP, BleepingComputer
   reported on October 30, 2026, pinning the flaw this briefing
   described earlier in the week as a kernel networking bug to
   MPTCP listeners specifically.
   Multipath TCP spreads one connection across several network
   paths, and the Linux kernel exposes it wherever an
   administrator or application turns a listener on, including
   Ubuntu and Red Hat Enterprise Linux builds. Operators should
   take distribution kernel updates now and switch off MPTCP
   listeners that no application requires.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/critical-linux-kernel-flaw-allows-remote-root-attacks-on-mptcp-servers/
