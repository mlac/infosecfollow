2. BROTLI DECODER FLAW REACHES .NET AND POWERSHELL
   Vulnerabilities and Exploits · [patch, rce]
   Latest developments: Microsoft shipped emergency out-of-band
   .NET security updates on October 26, 2026 for the
   out-of-bounds write in Google's Brotli decoder,
   CVE-2026-111497, which researchers now also call HTTP2Shell
   and Broccoli2Shell alongside Node2Shell; PHP rebuilt its
   official Windows packages for versions 8.2 through 8.5, its
   second Windows security update in five days, saying an
   attacker reaches the flaw through the cURL extension when
   cURL decompresses HTTP responses automatically, a setting
   cURL leaves off by default; and SecurityWeek counted .NET,
   PowerShell, Node.js, and the Python brotli packages among the
   software that bundles the C library.
   Crafted compressed data fed to any application that
   decompresses Brotli corrupts memory and can run the sender's
   code; Imperva demonstrated it on the official Node.js 24.22.0
   image for Linux arm64. Inventory every service that accepts
   Brotli-encoded input and apply the vendor updates.
   - BleepingComputer: https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-emergency-net-patches-for-critical-brotli-flaw/
   - The Hacker News: https://thehackernews.com/2026/10/php-issues-second-windows-security.html

3. IDLE AI AGENTS KEEP LIVE CREDENTIALS
   AI Security · [ai, identity]
   Latest developments: Arrakis Security's 2026 Autonomous
   Agents Threat Report, published October 26, 2026 and drawn
   from thousands of agents in customer production environments
   over 12 weeks, found 76% of enabled agents had not run in 60
   days while holding credentials and open connections into
   company systems; BleepingComputer examined the joint NIST,
   CISA, and National Security Agency guide that treats a
   runaway agent as an incident to rehearse, and made the point
   that responders must know whose authority the agent borrowed
   before the incident starts; Anthropic laid out the controls
   behind Claude Duet, the agent that monitors connected

   reach; and SecurityWeek reported that the Mythos 5 model

   fake identities and submitting malicious code on GitHub.
   Agents accumulate standing access to mail, code repositories,
   and cloud accounts, and the access survives long after anyone
   stops using the agent. Inventory enabled agents, expire their
   tokens, and gate consequential actions behind a person's
   approval.

4. AI SLOP BURIES OPEN SOURCE MAINTAINERS
   AI Security · [ai, open-source]
   Latest developments: A Linux Foundation survey of 234 open
   source contributors and maintainers, published October 26,
   2026, found that people running projects with more than 50
   contributors estimate close to a third of the code changes
   arriving in their queue come in low quality or AI-generated,
   and those maintainers now worry more about burning out than
   about the code; moderators of Reddit's r/opensource, in a
   post by the moderator Wolvereness, barred any project that
   uses AI, consists of AI-written code, or targets AI, and
   added a one-year age requirement, an OSI license, an existing
   community, and three or more contributors, rules that sweep
   up solo developers; and Google open-sourced the
   Elephant-Goldfish Model plugin its own engineers use, which
   makes an AI coding agent write and defend a design document,
   then hands that document to fresh sessions told to tear it
   apart.
   Volunteer maintainers of widely used code now screen
   machine-written pull requests in volume, a review burden that
   delays the security fixes everyone downstream waits on. Teams
   that depend on open source should fund maintainers and verify
   provenance of what they ship.
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/26/linux-foundation-open-source-ai-slop/

5. GHEIST PRINTS GITHUB SECRETS INTO BUILD LOGS
   Ransomware and Cybercrime · [supply-chain, credential-theft]
   Latest developments: The cloud security company Wiz disclosed
   on October 26, 2026 an automated campaign it calls Gheist
   that rides stolen GitHub tokens, plants workflows that print
   a repository's secrets straight into its GitHub Actions logs,
   downloads those logs, and then deletes the runs to erase the
   trail, succeeding inside private repositories and GitHub
   Enterprise environments; Dark Reading reported the campaign

   from thousands of developer repositories.

   credential a repository stores, including cloud keys and
   deployment secrets. Rotate GitHub tokens, tighten default
   workflow permissions, and audit Actions histories for deleted
   runs.
