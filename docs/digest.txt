2. CLAUDE CODE EXTENSION BACKDOOR GETS A TEARDOWN
   AI Security · [supply chain, backdoor, ai]
   Latest developments: Microsoft published a technical analysis
   late on October 30, 2026 of the malicious Claude Code-branded
   extension, walking through its persistent SSH backdoor and
   giving defenders detection and remediation steps, while Ars
   Technica reported that nobody has yet explained how the
   attacker reached Anthropic's verified Cursor publisher
   account.
   A tainted build of Anthropic's Claude Code extension moved
   through Cursor's marketplace under the legitimate publisher
   identity for roughly 11 hours on October 29, 2026, exposing
   as many as 5,000 developers to code that installs a
   persistent SSH backdoor. Developers who installed the
   extension in that window should rotate SSH keys and
   credentials and check authorized_keys and startup items
   against Microsoft's indicators.
   - Microsoft Security Blog: https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor/
   - Ars Technica Security: https://arstechnica.com/security/2026/10/anthropic-vs-code-extension-on-cursor-backdoored-for-nearly-12-hours/

3. IVANTI CONNECT SECURE CHAIN YIELDS ROOT
   Vulnerabilities and Exploits · [zero-day, patch, vpn]
   Latest developments: The Hacker News reported on October 31,
   2026 that attackers chain three Ivanti Connect Secure flaws
   together to reach unauthenticated root access on the gateway,
   going beyond the two bugs CISA listed as exploited a day
   earlier.
   CISA added CVE-2026-111357, rated 8.8 for missing
   authentication on a critical function, and CVE-2026-118527,
   predictable identifier generation, to its Known Exploited
   Vulnerabilities catalog on Friday, October 30, 2026, citing
   exploitation in the wild. Organizations running Ivanti
   Connect Secure remote access gateways should apply Ivanti's
   fixes now and hunt for compromise, because the chain hands an
   unauthenticated attacker full control of the appliance.
   - The Hacker News: https://thehackernews.com/2026/10/attackers-chain-three-ivanti-connect.html

4. VOLTA INFOSTEALER RANKS VICTIMS WITH A LANGUAGE MODEL
   AI Security · [infostealer, ai, credential theft]
   Latest developments: Cisco Talos disclosed VOLTA on October
   31, 2026, a self-deleting infostealer that feeds what it
   takes to large language models, which profile the victim and
   rank that person's most valuable assets for the operator.
   VOLTA steals browser credentials, authenticated sessions, and
   cryptocurrency wallets, erases itself from the host, and uses
   model-driven appraisal to decide which stolen accounts
   deserve immediate exploitation. Defenders should treat any
   VOLTA infection as a triaged, prioritized theft and reset the
   highest-value credentials on that endpoint first.
   - Cisco Talos: https://blog.talosintelligence.com/appraisal-by-ai-model-driven-victim-prioritization-in-the-volta-infostealer/

5. A CHATGPT SHARE LINK HIJACKED SESSIONS
   AI Security · [ai, vulnerability, data leak]
   Latest developments: The security firm Parameter showed that
   a malicious ChatGPT share link ran the attacker's code inside
   the logged-in session of anyone who opened it and read that
   person's private conversations, a flaw the researchers filed
   through OpenAI's bug bounty program on October 18, 2026 and
   OpenAI closed eight days later, rating it P1, its most
   serious category.
   Shared ChatGPT conversation links, which users pass around
   freely in chats and documents, carried enough execution
   capability to expose a recipient's entire chat history.
   OpenAI has fixed the flaw server-side, so users need no
   action, though anyone who opened an untrusted share link in
   that window should review their conversation history and
   connected apps.
   - The Hacker News: https://thehackernews.com/2026/10/a-shared-chatgpt-link-could-run.html
