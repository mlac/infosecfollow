   Vulnerabilities and Exploits · [zero-day, patch, apt]

   Check Point Security Gateways sit at the perimeter of
   enterprise networks and route all traffic through Gaia OS.
   Administrators should install the hotfixes immediately, hunt
   for TSGA, and check ESXi datastores for deleted files.

2. FBI FLASH ALERT PUTS ARTEX INTRUSIONS UNDER THREE HOURS
   Ransomware and Cybercrime · [ai, malware]
   Latest developments: The FBI issued a flash alert on November
   13, 2026 warning that ARTEX, the open-source agentic hacking
   framework, cuts the work of chaining attack techniques so far
   that some intrusions run from initial targeting to privileged
   access in under three hours; Cisco Talos published its own
   survey of AI-enabled penetration testing and red team
   platforms the same day, mapping how they automate
   reconnaissance, vulnerability testing, and follow-on actions
   and lower the skill a break-in demands; and OpenAI opened
   early access to Daybreak Red Team, which runs coordinated
   agents against web applications and verifies fixes, paired
   with Defense Factory, which investigates findings and
   prepares patches.
   ARTEX and similar frameworks let one operator run a complete
   intrusion chain at machine speed against any exposed
   application. Defenders should plan for hours between first
   contact and privileged access, and tune detection toward fast
   automated reconnaissance and credential attacks.
