1. PHP2SHELL FORCES AN OUT-OF-CYCLE PHP RELEASE
   Vulnerabilities and Exploits · [zero-day, patch]
   Latest developments: PHP released the emergency fixes on
   October 21, 2026 in versions 8.5.12, 8.4.27, 8.3.36, and
   8.2.35, closing CVE-2026-109618 and CVE-2026-109619; Sophos
   published a proof-of-concept exploit, and the SANS Internet
   Storm Center raised its InfoCon level to yellow, citing
   exploit code that circulated before the patch landed.
   The two flaws, which the PHP security team rates 9.2 under
   CVSS v4.0, run an attacker's code on a web server with no
   login and reach every installation that serves web requests,
   among them PHP-FPM and Apache with mod_php. PHP underpins
   most of the public web, including WordPress, Drupal, and
   Magento sites, so patch now and hunt for web shells on
   anything internet-facing.
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/21/php2shell-php-vulnerabilities-patched-cve-2026-109618-cve-2026-109619/
   - SANS Internet Storm Center: https://isc.sans.edu/diary/rss/33440
   - Sophos News: https://www.sophos.com/en-us/blog/proof-of-concept-exploit-released-for-php-vulnerabilities-109618-109619

4. EMUDHRA KEYS FELL TO WEAK CRYPTOGRAPHY
   Vulnerabilities and Exploits · [certificates, patch]
   Latest developments: The explanation arrived: researchers
   found the private keys behind eight eMudhra intermediate
   certificates weak enough to recover almost instantly, which
   would let anyone mint a trusted certificate for any website,
   and the Indian certificate authority revoked all eight.
   Google, Mozilla, Apple, and the Go project blocked the eight
   keys on October 20, 2026, and Go releases 1.27.3 and 1.26.10
   reject any chain that passes through them. Organizations
   running their own trust stores, pinning, or older Go binaries
   should push the blocks and the updated releases themselves.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/mozilla-google-apple-block-compromised-emudhra-ca-certificates/

9. FINGER COMMAND POWERS NEW CLICKFIX LURES
   Ransomware and Cybercrime · [social engineering, malware]
   Latest developments: Dark Reading detailed a ClickFix
   campaign on October 21, 2026 that buys malicious Google
   search results for Amazon queries and calls finger, the
   Windows directory-lookup utility that dates to the early
   internet, to fetch a fake CAPTCHA page that installs malware
   including the Lumma stealer; Google began rolling out Chrome
   safeguards that warn users with Enhanced Protection turned on
   when a page tries to get them to copy and paste a command.
   ClickFix social engineering talks a user into pasting
   attacker-supplied commands into Windows, which sidesteps
   download and email controls entirely. Blocking or alerting on
   finger.exe execution costs nothing in most enterprises and
   removes this delivery path.

10. HIJACKED TOR EXIT RELAYS STOLE SSH PASSWORDS
   Ransomware and Cybercrime · [credential theft,
   infrastructure]
   Latest developments: A researcher found that attackers took
   control of more than 300 Tor exit relays in early October
   2026 and pointed SSH traffic leaving those relays at servers
   that captured login passwords.
   Exit relays carry the last hop of a Tor circuit, where
   traffic leaves the network for its destination, so whoever
   runs one sees and can redirect that traffic. The theft
   reached only password logins to SSH servers made over Tor
   between October 1 and October 5 where the user accepted the
   changed host key; anyone who fits that window should rotate
   the password and move to key-based authentication.
   - The Hacker News: https://thehackernews.com/2026/10/attackers-hijacked-over-300-tor-exit.html
