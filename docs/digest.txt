6. BROTLI AND MAGENTO BUGS ENTER THE KEV CATALOG
   Vulnerabilities and Exploits · [patch, exploitation, supply
   chain]
   Latest developments: CISA cited evidence of active
   exploitation on October 27, 2026 and added two flaws to its
   Known Exploited Vulnerabilities catalog: CVE-2026-111497, the
   unchecked return value bug in Google's Brotli compression
   library, and CVE-2026-48356, an unrestricted file upload flaw
   in Adobe Commerce and Magento; Help Net Security laid out how
   far the Brotli bug travels past the Node.js disclosure that
   made it famous on October 21, 2026.
   The Brotli out-of-bounds write, which researchers call
   Node2Shell, Broccoli2Shell, and Brotli2Shell, sits in the C
   library that Node.js, .NET, PowerShell, Bun, Envoy, and the
   Python brotli packages all bundle, and it fires when an
   application decompresses attacker-supplied Brotli data. Patch
   the runtimes and rebuild anything that statically links the
   library, and update Adobe Commerce and Magento storefronts
   now.
   - CISA Advisories: https://www.cisa.gov/news-events/alerts/2026/10/27/cisa-adds-two-known-exploited-vulnerabilities-catalog
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/27/node2shell-broccoli2shell-vulnerability-cve-2026-111497/

7. TAILSCALE RUSHES TAILWORM PATCHES
   Vulnerabilities and Exploits · [vulnerability, patch,
   privilege escalation]
   Latest developments: Tailscale's security team is building
   fixes for close to a dozen vulnerabilities in Tailscale SSH,
   the set researchers call Tailworm, after someone published
   the details over the weekend without coordinating with the
   company and before any patch existed; the bugs let an
   attacker steal credentials, crash servers, and escalate to
   root on machines reachable across the same network.
   Tailscale runs a WireGuard mesh that companies use as a flat
   private network, and Tailscale SSH authenticates logins
   through that mesh, so one compromised device reaches every
   server its access rules allow. Until the releases land, turn
   off Tailscale SSH and tighten the access control lists that
   decide which devices may connect to which hosts.
   - SecurityWeek: https://www.securityweek.com/tailscale-rushes-patches-after-uncoordinated-disclosure-of-tailworm-flaws/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/tailscale-warns-of-serious-ssh-flaws-allowing-root-privilege-escalation/

   AI Security · [ai, model theft, vulnerability]
   Latest developments: The security firm Xint showed that

   conversation to save space, returns a model's hidden

   cut the cost of distilling a rival model, a prospect
   SecurityWeek frames as a lift for Chinese competitors.

10. EDK2 FIRMWARE FLAW REACHES MOST SERVERS
   Vulnerabilities and Exploits · [vulnerability, firmware,
   patch]
   Latest developments: Ars Technica reported on October 27,
   2026 that a critical flaw in EDK2 runs an attacker's code
   early in the boot process and affects most servers on the
   planet.
   EDK2 is the open-source UEFI reference implementation that
   server makers build their firmware on, so code that executes
   there starts before the operating system and outlives a
   reinstall. Track your vendors' firmware advisories and
   schedule the firmware updates as they appear, because the fix
   lands below the patching tools most teams use.
   - Ars Technica Security: https://arstechnica.com/security/2026/10/code-execution-flaw-in-uefi-firmware-threatens-most-servers-on-planet-earth/
