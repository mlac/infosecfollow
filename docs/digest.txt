   Vulnerabilities and Exploits · [patch, exploit, ai]
   Latest developments: Previdian warned that attackers exploit
   CVE-2026-105740, a 9.9-rated authenticated remote code

   honeypot exploit attempts; three administrators reported on
   GitHub that attackers plant web shells on Nextcloud servers
   through the optional Collabora Online Built-in CODE Server
   app, with the first logged attack on September 10, 2026; and
   Ahsay Backup of Singapore shipped new fixes for
   CVE-2026-105133 and CVE-2026-105134 after its earlier patches
   proved incomplete, a day after CISA put both bugs in its
   Known Exploited Vulnerabilities catalog alongside Palo Alto
   Networks PAN-OS CVE-2026-0322 and Cisco Secure Email Gateway
   CVE-2026-76519.
   All three products sit at the edge of enterprise networks and
   hand an attacker command execution: Langflow runs AI
   workflows, the Collabora app renders documents inside
   Nextcloud, and AhsayCBS manages backups. Patch Langflow and
   AhsayCBS now, disable or update the Collabora Online Built-in
   CODE Server app, and search web directories for files that
   execute commands.

2. HIRUDO SWAPS INDONESIAN BANKING APPS FOR PATCHED COPIES
   Ransomware and Cybercrime · [android, banking-trojan,
   malware]
   Latest developments: ThreatFabric, the Dutch mobile security
   company, disclosed a new Android banking trojan it calls
   Hirudo that uninstalls a victim's legitimate banking
   application and installs a repackaged copy with the app's own
   security checks switched off from the inside, and it carries
   ready-made replacements for eight Indonesian banking apps.
   Hirudo combines a banking trojan with a full remote access
   trojan, so the operator both harvests credentials from the
   counterfeit app and drives the handset directly. Banks should
   treat app integrity and reinstallation events as fraud
   signals, and Android users should install financial apps only
   from Google Play and refuse requests to sideload an update.
   - SecurityWeek: https://www.securityweek.com/novel-android-banking-rat-hirudo-replaces-banking-apps-with-trojanized-copies/
   - The Hacker News: https://thehackernews.com/2026/10/hirudo-android-trojan-uses-patched.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hirudo-android-malware-replaces-banking-apps-to-evade-security-checks/

3. SPYWARE INFECTS PHONES THROUGH AD NETWORKS
   Surveillance and Spyware · [spyware, zero-click,
   surveillance]
   Latest developments: Wired reported on October 15, 2026 that
   researchers at The Citizen Lab released the first technical
   evidence of sophisticated mercenary spyware traveling through
   online advertising, infecting phones with no click from the
   owner, and The Record reported that Prime Minister Donald
   Tusk, who ordered Poland's investigation into the
   surveillance operation the previous ruling party ran, said
   the spyware manufacturer itself held access to the data
   Polish operators harvested and called the affair one of the
   biggest scandals in Polish history since the fall of
   communism.
   Mercenary spyware vendors sell phone-compromise services to
   government customers, and targeted advertising gives them a
   delivery channel that reaches a chosen handset without a
   message or a link. Executives, journalists, and government
   personnel who face this threat should keep phones on current
   operating system versions, enable lockdown modes where the
   vendor offers them, and treat ad-blocking at the network edge
   as a security control.
   - Wired Security: https://www.wired.com/story/nightmare-scenario-zero-click-spyware-is-infecting-phones-via-targeted-ads/

5. GHOSTACTION DRAINS SECRETS FROM 30,000 REPOSITORIES
   Ransomware and Cybercrime · [supply-chain, credentials,
   breach]
   Latest developments: GitGuardian measured a sharp escalation
   of the GhostAction credential-theft campaign on October 8 and
   9, 2026: the operators compromised the GitHub accounts of
   about 1,900 users, reached more than 30,000 repositories
   belonging to 3,000 users and organizations, and tried to pull
   3,174 secrets out of the continuous integration
   configurations of public repositories.
   GhostAction steals a maintainer's GitHub credentials, then
   pushes a workflow that exports every token, key, and password
   the repository's automation holds, which carries the attacker
   into cloud accounts and package registries downstream.
   Development teams should rotate CI secrets, require
   phishing-resistant multifactor authentication on GitHub
   accounts, and review recent workflow file changes.
   - The Hacker News: https://thehackernews.com/2026/10/ghostaction-compromises-about-1900.html

7. PEERSTITCH IMPLANT HIDES IN FORTIGATE FIREWALLS
   Vulnerabilities and Exploits · [malware, network-edge,
   exploit]
   Latest developments: Palo Alto Networks Unit 42 published an
   intrusion investigation on October 14, 2026 in which
   attackers exploited CVE-2024-47575, the FortiManager
   authentication flaw, reached more than 500 managed firewalls,
   and deployed PEERSTITCH, memory-resident ARM64 malware that
   leaves nothing on the appliance's disk.
   FortiManager centrally administers FortiGate firewalls, so
   one compromised manager carries an attacker to every device
   it controls, and a memory-resident implant survives no reboot
   yet also evades file-based scanning. Organizations running
   FortiManager should confirm they applied the CVE-2024-47575
   fix Fortinet shipped in 2024, rotate device credentials, and
   compare running firewall configurations against known-good
   baselines.
   - Unit 42 (Palo Alto): https://unit42.paloaltonetworks.com/fortimanager-cve-2024-47575-peerstitch-malware/
