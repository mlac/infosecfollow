1. CLICKFIX TURNS SIGNED SIEMENS SOFTWARE INTO A LOADER
   Vulnerabilities and Exploits · [patch, malware, exploited]
   Latest developments: Siemens updated its advisory on October
   17, 2026 to point customers to version 4.0.9.8, which closes
   CVE-2026-110936, the DLL sideloading flaw rated 8.4 under
   CVSS v4 that Jose Oregon of Huntress Labs reported and that
   attackers already exploit by pairing a genuine signed copy of
   Siemens Software Center with malicious DLLs delivered through
   ClickFix lures; Forescout Research - Vedere Labs disclosed
   ROMULUS, a ClickFix delivery platform whose fake landing
   pages push Legion Loader and other malware.
   ClickFix tricks a user into pasting an attacker's command
   into Windows, so the victim runs the malware personally and
   sidesteps download controls. Industrial customers should
   update Siemens Software Center at once, and security teams
   should block clipboard-to-Run-dialog behavior and alert on
   it.
   - The Hacker News: https://thehackernews.com/2026/10/clickfix-attackers-exploit-siemens.html
   - SecurityWeek: https://www.securityweek.com/siemens-software-center-vulnerability-exploited-in-clickfix-malware-attacks/

   AI Security · [ai, agents, policy]
   Latest developments: Help Net Security reported on October
   20, 2026 that the United States Army seeks AI agents that

   Nation-State Activity · [apt, espionage, defense]

7. HIJACKED GITHUB ACCOUNT POISONS OVHCLOUD CLI
   Ransomware and Cybercrime · [supply chain, credential theft]
   Latest developments: OVHcloud said an attacker took over a
   contributor's GitHub account on Monday, October 19, 2026 and
   swapped the download archives on five existing releases of
   the company's command-line tool for a build that steals
   secrets off the disk of any machine that runs it, with the
   files live from 12:47 to 14:21 UTC.

   secrets include the API keys and tokens administrators keep
   on their workstations. Anyone who downloaded the tool from
   GitHub inside that 94-minute window should treat every
   credential on that machine as compromised and rotate it.

10. GO BLOCKS EIGHT CERTIFICATE AUTHORITY KEYS
   Vulnerabilities and Exploits · [patch, cryptography]
   Latest developments: The Go team shipped Go 1.27.3 and Go
   1.26.10 on October 20, 2026, making the language's
   certificate verifier reject any chain that passes through one
   of eight intermediate certificate authority keys, and
   declined to name the single certificate authority that holds
   them.
   Any program rebuilt on the new releases refuses connections
   to sites and services whose certificates trace back to those
   keys, so Go-based clients, proxies, and agents may suddenly
   fail to reach internal endpoints. Teams running Go services
   should test the update against their certificate inventory
   before rolling it out.
   - The Hacker News: https://thehackernews.com/2026/10/go-issues-emergency-update-blocking.html
