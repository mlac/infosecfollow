1. PHP2SHELL HITS PALO ALTO MANAGEMENT INTERFACES
   Vulnerabilities and Exploits · [exploit, patch, zero-day]
   Latest developments: CISA warned federal agencies on October
   29, 2026 to patch Fragnesia, the high-severity Linux kernel
   privilege escalation attackers chain behind the PHP flaws,
   the same day its deadline to fix CVE-2026-109618 and
   CVE-2026-109619 fell; Palo Alto Networks reported active
   exploitation against internet-exposed management interfaces,
   and Unit 42 updated its threat brief that day; The Record
   counted the confirmed cases as roughly a half-dozen, among
   them a well-targeted campaign researchers attribute to China

   unauthenticated attacker code execution through the web
   management consoles of firewalls, VPN gateways, and
   application delivery controllers. Take management interfaces
   off the public internet, install vendor updates as they ship,
   and patch the Linux kernel bug attackers pair with them.

2. CISCO VPN ZERO-DAY LANDS IN A PATCH WAVE
   Vulnerabilities and Exploits · [zero-day, patch]
   Latest developments: CISA added two bugs to its Known
   Exploited Vulnerabilities catalog on October 29, 2026:
   CVE-2026-76418, the flaw rated 8.6 in the Remote Access SSL
   VPN service of Cisco ASA and FTD software that lets an
   unauthenticated remote attacker force the firewall to reload,
   which Cisco patched the same day and which marks the second
   Cisco firewall VPN zero-day under exploitation since August
   2026, and CVE-2026-97229, the integer overflow rated 10.0 in
   GitLab Community and Enterprise Edition that an attacker
   tried to fire at the Alpine Linux project's own GitLab server
   a week after the fix shipped, an attempt Alpine found no
   evidence succeeded; Adobe, Veeam, and Juniper Networks closed
   critical code execution, authorization bypass, and privilege
   escalation bugs, led by CVE-2026-104351 at 9.9 in Adobe
   Campaign Classic; and the security startup NebuSec disclosed
   a Telegram for Android flaw that ran an attacker's code the
   moment a victim answered a voice call, which Telegram fixed
   in version 12.10.4 in late September 2026.
   The Cisco bug gives an unauthenticated attacker a reliable
   way to knock ASA and FTD firewalls offline, and the GitLab
   bug runs code through a crafted regular expression in a
   continuous integration configuration. Patch the Cisco VPN and
   GitLab flaws first, then the Adobe, Veeam, and Juniper
   releases, then move Telegram for Android to 12.10.4 or later.
   - SecurityWeek: https://www.securityweek.com/attackers-exploit-second-cisco-firewall-vpn-zero-day-since-august/

3. KEYDRIFT STEALS CISCO SD-WAN ENCRYPTION KEYS
   Nation-State Activity · [apt, zero-day, patch]
   Latest developments: Cisco Talos disclosed UAT-11473, an
   advanced group that exploited CVE-2026-20127, the
   authentication bypass in Cisco Catalyst SD-WAN Controller
   instances Cisco fixed in February 2026, to deploy custom
   malware called KeyDrift, and Talos tied the attack
   infrastructure to Volt Typhoon's Silent Train covert access
   network; Help Net Security detailed those relay chains on
   October 29, 2026, naming compromised TP-Link and Netgear
   routers alongside Fortinet and Cisco enterprise systems.
   KeyDrift runs inside the controllers that govern an
   organization's SD-WAN fabric and copies the keys that encrypt
   traffic between sites, storing them for later decryption.
   Operators should apply the February fix for CVE-2026-20127,
   rotate SD-WAN keys, and hunt for the indicators Talos
   published.
