1. PHP2SHELL FORCES AN OUT-OF-CYCLE PHP RELEASE
   Vulnerabilities and Exploits · [zero-day, patch]
   Latest developments: The patches landed at 14:00 UTC on
   October 21, 2026 in PHP 8.5.12, 8.4.27, 8.3.36, and 8.2.35,
   closing CVE-2026-109618 and CVE-2026-109619; CISA told
   organizations to patch immediately, SecurityWeek reported the
   first exploitation attempts reaching sensors, The Record
   counted hundreds of websites already taken offline, Brian
   Krebs put the share of sites needing the update near 70% and
   warned of a day of error pages, and Cisco Talos shipped Snort
   rules while Kaspersky added detection for the exploit.
   The two flaws, which the PHP security team rates 9.2 under
   CVSS v4.0, run an attacker's code on a web server with no
   login and reach every installation that serves web requests,
   among them PHP-FPM and Apache with mod_php. PHP underpins
   most of the public web, including WordPress, Drupal, Joomla,
   and Magento sites, so patch now and hunt for web shells on
   anything internet-facing.
   - Krebs on Security: https://krebsonsecurity.com/2026/10/widespread-php-flaw-may-cause-many-site-outages-today/
   - CISA Advisories: https://www.cisa.gov/news-events/alerts/2026/10/21/critical-vulnerabilities-php-require-immediate-patching

2. EMUDHRA KEYS FELL TO WEAK CRYPTOGRAPHY
   Vulnerabilities and Exploits · [certificates, patch]
   Latest developments: Help Net Security supplied the timeline
   on October 21, 2026: a researcher known as Wayne found the
   weakness on October 17, 2026 while running a check against
   the Common CA Database, recovered each private key from the
   matching public certificate in under a second, and signed a
   certificate to prove the compromise; eMudhra, which
   advertises more than 60 million certificates issued, revoked
   all eight.
   Google, Mozilla, Apple, and the Go project blocked the eight
   keys on October 20, 2026, and Go releases 1.27.3 and 1.26.10
   reject any chain that passes through them. Organizations
   running their own trust stores, pinning, or older Go binaries
   should push the blocks and the updated releases themselves.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/mozilla-google-apple-block-compromised-emudhra-ca-certificates/
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/21/emudhra-certificates-private-keys-compromised/

8. FINGER COMMAND POWERS NEW CLICKFIX LURES
   Ransomware and Cybercrime · [social engineering, malware]
   Latest developments: Dark Reading detailed a ClickFix
   campaign on October 21, 2026 that buys malicious Google
   search results for Amazon queries and calls finger, the
   Windows directory-lookup utility that dates to the early
   internet, to fetch a fake CAPTCHA page that installs malware
   including the Lumma stealer; Push Security told
   BleepingComputer the technique has never run bigger, with
   fake AI installers and trusted chatbot platforms now its most
   convincing lures; and Google began rolling out Chrome
   protections that warn users with Enhanced Protection turned
   on when a page asks them to copy and paste a command,
   alongside new site warnings and server-side Gemini analysis
   of suspected scam pages.
   ClickFix social engineering talks a user into pasting
   attacker-supplied commands into Windows, which sidesteps
   download and email controls entirely. Blocking or alerting on
   finger.exe execution costs nothing in most enterprises and
   removes this delivery path.
