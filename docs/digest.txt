1. REFRIGERATION CONTROLLERS TURN INTO SPAM INFRASTRUCTURE
   Ransomware and Cybercrime · [critical-infrastructure, botnet,
   iot]
   Latest developments: French authorities blamed Iran on
   November 9, 2026 for the October 2026 refrigeration attacks,
   naming Shahid Kaveh, a cyber unit of the Islamic
   Revolutionary Guard Corps that investigators previously tied
   to attacks on industrial controllers at United States water
   utilities, and counting food losses plus at least 15 fires
   across more than 700 supermarkets and other retail locations;
   SecurityScorecard reported the same day that attackers also
   hijack internet-exposed Copeland XWeb controllers in
   supermarkets and cold storage facilities and run them as a
   suspected spam botnet and proxy service.
   Copeland XWeb controllers run refrigeration and cold-chain
   monitoring for grocers, blood banks, and warehouses, and many
   sit on the public internet with unpatched firmware or default
   credentials. CISA, the FBI, Health and Human Services, the
   Department of Agriculture, and the Department of
   Transportation tell operators to take the web interfaces
   offline, patch the controllers, and replace default
   passwords.

2. SSHOLE, PLEX2SHELL, AND SONICWALL UNDER ACTIVE ATTACK
   Vulnerabilities and Exploits · [exploit, patch, zero-day]
   Latest developments: CISA added four actively exploited flaws
   to its Known Exploited Vulnerabilities catalog on November 9,
   2026, among them CVE-2026-123158, the OpenSSH bypass
   researchers call sshole, alongside CVE-2026-102895 in
   GPUStack, CVE-2026-116779 in SignalWire FreeSwitch, and
   CVE-2026-123218 in IBM Aspera Faspex; BleepingComputer and
   Ars Technica reported that attackers exploiting sshole now
   execute commands, steal credentials, and hold persistent
   access on Linux systems, with SecurityWeek pinning the first
   wave on botnets and cryptocurrency miners; SonicWall shipped
   a fix for CVE-2026-19868 and listed no workaround; and
   SecurityWeek confirmed attackers running the four-flaw
   Plex2Shell chain against Plex Media Server on QNAP
   network-attached storage devices.
   The sshole flaw lets anyone with network access, an account
   name, and an overlong password log into key-only or
   passwordless accounts on musl-based Linux systems, which
   OpenSSH fixed in version 10.6p2. CVE-2026-19868 walks past
   SAML-enforced multifactor authentication on SonicOS SSL-VPN,
   so administrators should update SonicOS, OpenSSH, and Plex
   Media Server on QNAP boxes immediately.
   - CISA Advisories: https://www.cisa.gov/news-events/alerts/2026/11/09/cisa-adds-four-known-exploited-vulnerabilities-catalog

   running Bitcoin Lightning wallets. Owners who signed into
   Keplr with Google or Apple should move their funds, LNbits
   operators should keep servers down until the project ships
   its patches, and anyone running the poisoned bee-js or Swarm

   AI Security · [ai, exploit, credentials]
   Latest developments: Dark Reading reported on November 9,
   2026 that attackers can exploit a flaw in Claude's
   document-processing tool, which researchers call Office
   Party, by planting a temporary file that Anthropic's
   assistant then reaches and runs on a Linux user's machine,
   and Ars Technica reported the same day that Claude Code
   settings files have scattered thousands of passwords and API
   keys across public GitHub repositories after developers
   approved a command with the do-not-ask-again option.

   approval shortcut writes the approved command, secrets
   included, into a settings file that developers then commit.
   Teams running Claude Code should scrub their settings files,
   rotate every credential that reached a repository, and keep
   the assistant's document handling off machines that hold
   production access.

10. QUBOLE'S AWS ACCESS BREACHES CUSTOMER ACCOUNTS
   Data Breaches · [breach, cloud, credentials]
   Latest developments: The cloud security company Wiz said on
   November 9, 2026 that an attacker holding credentials for the
   Amazon Web Services account Qubole's platform uses to reach
   its customers broke into multiple Qubole customers' AWS
   accounts between October 14 and October 26, 2026 and took
   stored secrets and data; how the attacker obtained those
   credentials remains undisclosed.

   customers grant it cross-account access into their own AWS

   stored in those accounts and comb October CloudTrail records
   for activity from Qubole's role.
