1. ITALY FINES META OVER FACEBOOK GALLERY ACCESS
   Policy and Regulation · [policy, privacy]
   Latest developments: The Garante, Italy's data protection
   authority, fined Meta 805 million euros, about $887 million,
   on November 14, 2026, finding that Facebook for Android read
   Italian users' photos, videos, and related metadata without
   explicit consent, and gave the company 60 days.
   Facebook for Android suggests photos and videos out of a
   user's phone gallery as post material, and the feature
   arrives switched on. The Garante cited a European directive
   that treats a smartphone as part of a person's private sphere
   and demands free and informed consent before an app reaches
   into it.
   - The Hacker News: https://thehackernews.com/2026/11/italy-fines-meta-805-million-over.html
   - SecurityWeek: https://www.securityweek.com/meta-fined-887-million-in-italy-over-android-gallery-photos-and-videos-on-facebook/

2. STOLEN FIREWORKS KEY OPENED CURSOR'S MARKETPLACE
   AI Security · [supply chain, breach, ai]
   Latest developments: Cursor said in a Friday, November 13,
   2026 update that the attacker obtained an access key Cursor
   itself had issued to Fireworks AI, that Fireworks exposed the
   key, and that the attacker used it to copy data from a
   read-only source.
   Attackers distributed a malicious version of Anthropic's
   official Claude Code extension through Cursor's extension
   marketplace, working from credentials stolen in the breach at
   Fireworks AI, the AI infrastructure provider. Developers who
   installed the extension should rotate every credential the
   editor could reach.
   - The Hacker News: https://thehackernews.com/2026/11/stolen-fireworks-ai-key-led-to-cursor.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/

4. AGENTS GET SPENDING POWER BEFORE CONTROLS CATCH UP
   AI Security · [ai, fraud]
   Latest developments: OpenAI began rolling out ChatGPT Wallet,
   built with American Express, Mastercard, and Visa, which pays
   merchants through a stand-in card number so a user's real
   card details reach neither the agent nor the merchant, and
   Token Security published five enterprise gaps it found while
   testing an invoice-processing agent that a malicious email
   could push into changing a vendor's bank details with no
   alert firing.
   Agents now hold payment authority and finance workflows
   inside companies, and the identity and approval controls
   around them lag the capability. Token Security's guidance and
   OpenAI's stand-in card both aim at the same problem: an agent
   that acts with a person's authority and no bounded
   credential.
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/13/openai-chatgpt-wallet/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/how-one-ai-agent-exposed-five-critical-enterprise-security-gaps/
   - SecurityWeek: https://www.securityweek.com/is-ai-making-us-worse-at-cybersecurity/

5. APPLE DETAILS SECURE EXCLAVES FOR CAMERA AND MIC
   Platform Security · [privacy, hardware]
   Latest developments: Apple published the architecture of
   Secure Exclaves, which isolates camera and microphone data
   from the main operating system on HomeView and the newest
   iPhones, so a compromise of iOS alone leaves ambient sensor
   data out of an attacker's reach.
   Secure Exclaves fence off the hardware that watches and
   listens, keeping that data inside a separate execution
   environment rather than the general-purpose operating system.
   The design matters most for always-on home devices, where a
   single operating system flaw would otherwise open a live
   camera and microphone.
   - SecurityWeek: https://www.securityweek.com/apple-reveals-how-secure-exclaves-shield-camera-and-microphone-data/

6. A 22-YEAR-OLD POSTGRESQL BUG RUNS CODE
   Vulnerabilities and Exploits · [patch, vulnerability]
   Latest developments: The worst flaw in this week's PostgreSQL
   release now carries a number and an age: CVE-2026-6460, a
   type confusion bug rated 8.8 that has sat in the code for 22
   years and lets any database user who can create objects run
   commands on the server with the rights of the operating
   system account.

   administrators must also rebuild every C-language extension
