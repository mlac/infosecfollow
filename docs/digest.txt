10. BLACKX BOOTKIT RUNS ON FULLY PATCHED WINDOWS
   Vulnerabilities and Exploits · [firmware, malware]
   Latest developments: Ars Technica reported on November 3,
   2026 that the UEFI bootkit BlackX infected Windows machines
   carrying every available patch, exploiting the distance
   between what Microsoft tells customers Secure Boot stops and
   what the protection actually blocks, and pressed the question
   of how much of that confusion Microsoft owns.
   BlackX loads before Windows does, which puts it beneath the
   operating system's own defenses and lets it survive a
   reinstall. Administrators should audit Secure Boot
   configuration, apply the firmware revocation lists Microsoft
   ships, and watch boot and firmware integrity; patch level
   alone proves nothing here.
   - Ars Technica Security: https://arstechnica.com/security/2026/11/uefi-bootkit-infected-fully-patched-windows-machines-is-microsoft-to-blame/
