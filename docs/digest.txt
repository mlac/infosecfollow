1. UNIT 42 DISSECTS EUROPE'S REFRIGERATION ATTACKS
   Critical Infrastructure Security · [ics,
   critical-infrastructure, advisory]
   Latest developments: Wired called the spree an
   internet-of-things wake-up call on November 7, 2026, pinning
   the damage at blood labs and grocery stores on basic security
   lapses in internet-connected devices, a day after Unit 42,
   the Palo Alto Networks research group, published its own
   examination with defense and mitigation steps, SecurityWeek
   detailed the call from CISA, the FBI, Health and Human
   Services, the Department of Agriculture, and the Department
   of Transportation for operators to harden refrigeration
   controllers, and Dark Reading traced the speed of the spread
   to shared controller platforms across the grocery industry.
   Intruders reached cooling systems at supermarkets in Belgium,
   Sweden, Ireland, Estonia, and Luxembourg and at three sites
   of the Établissement français du sang, the French civilian
   blood service, switching evaporators into defrost and heating
   cycles that spoiled stock and risked equipment damage and
   fire. Operators should segment controller networks, close
   remote management to the internet, and alarm on temperature
   setpoint changes.

2. SONICWALL SSL-VPN FLAW DEFEATS SAML LOGINS
   Vulnerabilities and Exploits · [patch, zero-day, vpn]
   Latest developments: SecurityWeek and BleepingComputer
   spelled out the mechanism on November 7, 2026: CVE-2026-19868
   lets an attacker who already holds credentials for one login
   method walk past SAML checks on SonicOS SSL-VPN,
   SAML-enforced multifactor authentication included, and
   attackers are using it now.
   SonicWall shipped updates for seven SonicOS firewall flaws,
   the exploited authentication bypass among them, and CISA
   placed that bug in its Known Exploited Vulnerabilities
   catalog. Administrators running SonicOS firewalls with
   SSL-VPN should install the new firmware and rotate VPN
   credentials.
   - SecurityWeek: https://www.securityweek.com/sonicwall-patches-exploited-sonicos-bug-that-weakens-vpn-logins/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-new-ssl-vpn-mfa-bypass-flaw-exploited-in-attacks/

   AI Security · [ai, apt, cybercrime]
   Latest developments: Microsoft Threat Intelligence reported
   late on November 6, 2026 that Storm-3358, a financially
   motivated actor, began aiming the agentic AI offensive

   2026, which moves the tool out of the espionage column that

5. CLAUDE CODE APPROVALS LEAK KEYS TO GITHUB
   AI Security · [ai, secrets, supply-chain]
   Latest developments: The Hacker News reported on November 7,
   2026 that the software security company Apiiro found
   passwords and API keys sitting in 1,122 public GitHub
   repositories, put there by Claude Code when developers
   approved a command with the do-not-ask-again option.
   Anthropic's coding assistant saves an approved command word
   for word in a project settings file, secret included, and
   developers then commit that file to source control where
   anyone can read it. Teams should rotate every credential ever
   typed into a Claude Code command and strip the settings file
   from their repositories and history.
   - The Hacker News: https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html

8. RANSOMWARE CREWS RIDE HYPERVISOR MISCONFIGURATION
   Ransomware and Cybercrime · [ransomware, virtualization,
   hardening]
   Latest developments: Kaspersky's Securelist published a
   breakdown on November 6, 2026 of ransomware cases on VMware
   ESXi and Proxmox hosts, mapping the attack layers of a
   virtual environment and the specific misconfigurations that
   turn one hypervisor compromise into the encryption of every
   guest it runs.
   A hypervisor parks dozens of production servers behind a
   single management interface, so an exposed or weakly
   separated ESXi or Proxmox console converts one stolen
   credential into datacenter-wide encryption. Administrators
   should pull hypervisor management off routable networks,
   enforce multifactor authentication on it, and keep backups
   outside the virtual environment.
   - Securelist (Kaspersky): https://securelist.com/virtualization-security-esxi-and-proxmox-ransomware-cases/121819/
