   Ransomware and Cybercrime · [north korea, crypto theft,

   Latest developments: Binance's first full incident report,
   detailed November 4, 2026, traces the $6.34 billion theft to

   recruitment interviews and counts three engineers' computers

   engineers download code from strangers during interviews
   should treat take-home assignments as untrusted and isolate

   Ransomware and Cybercrime · [ics, critical infrastructure,
   supply chain]

   onward with patches out and no mitigation available; the
   Rails project fixed a critical Active Storage flaw in
   versions 8.1.4.1 and 8.0.5.2 that lets an unauthenticated

   213 security fixes, seven of them critical; and Google gave

   action by its owner. Administrators should apply the Xen
   patches, move to Rails 8.1.4.1 or 8.0.5.2, take Chrome 157,
   and require Android security patch level 2026-11-01 or later.

6. APT PACKAGE VERIFICATION FALLS TO A DOWNLOAD SWAP
   Vulnerabilities and Exploits · [patch, vulnerability, supply
   chain]
   Latest developments: Debian, Ubuntu, and the APT developers
   published advisories on November 4, 2026 for a flaw that lets
   an attacker who can modify package downloads substitute their
   own file for a verified package and run code as root, an
   attack that rides APT's habit of retrying failed downloads,
   the default from Debian 12 onward; SonicWall said the same
   day that it will leave two flaws unpatched in Global
   Management System 9.5.2 and earlier, which it has taken end
   of life, among them CVE-2026-109593, an unauthenticated file
   read rated 9.1 that exposes internal GMS files to anyone with
   network access, alongside a second bug that alters database
   records.
   APT installs and updates software on most Debian and Ubuntu
   machines, so a machine-in-the-middle on any plain-HTTP mirror
   turns routine patching into root compromise. Administrators
   should install the new APT packages, point systems at mirrors
   reached over HTTPS, and move off SonicWall GMS 9.5.2 and
   earlier, which will never receive a fix.
   - The Hacker News: https://thehackernews.com/2026/11/debian-and-ubuntu-apt-flaw-lets-mitm.html
