1. JAVA4SHELL NARROWS TO AVX-512 CHIPS
   Vulnerabilities and Exploits · [zero-day, patch,
   vulnerability]
   Latest developments: Cisco Talos scored Java4Shell at 9.2
   under CVSS 4.0, and researchers pinned down its reach: the
   vulnerable code runs only on Java 17.0.6 and later and only
   on x86-64 Intel and AMD processors that support the AVX-512
   VBMI feature, with Calif demonstrating remote code execution
   against Jira, Jenkins, and Keycloak while VulnCheck says a
   working attack takes per-target engineering and no one has
   yet confirmed a successful intrusion.
   CVE-2026-114938 is an out-of-bounds write in the Base64
   decoder of OpenJDK that hands an unauthenticated attacker
   denial of service or code execution on Jenkins, Atlassian
   Jira, Confluence, Keycloak, and other Java servers reaching
   most of the Fortune 500. Oracle and the OpenJDK project
   released fixes on November 17, 2026, and CISA tells
   organizations to patch immediately.
   - Cisco Talos: https://blog.talosintelligence.com/java4shell/
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/18/java4shell-openjdk-vulnerability-cve-2026-114938/
   - SecurityWeek: https://www.securityweek.com/java4shell-vulnerability-puts-many-enterprise-applications-at-risk-of-takeover/

2. PUPPET AND ROLLER FALL TO LIVE EXPLOITS
   Vulnerabilities and Exploits · [patch, exploited,
   vulnerability]
   Latest developments: SecurityWeek spelled out the mechanism
   behind CVE-2026-115731, the Perforce Puppet flaw rated 9.4
   that CISA added to its Known Exploited Vulnerabilities
   catalog: any client holding a certificate signed by the
   Puppet certificate authority can run code on the server; the
   Apache Software Foundation separately warned that attackers
   are exploiting a critical Roller remote code execution bug
   and shipped updates, while Oracle's November 2026 patch
   update closed 950 vulnerabilities, more than 300 of them
   remotely exploitable without authentication, and Google
   released Chrome 158 with 204 fixes.
   Perforce Puppet runs configuration management across
   enterprise fleets, so code execution on the Puppet server
   reaches every managed host; Apache Roller is a Java blog
   server. Patch both now, pull Oracle's 62 critical fixes, and
   push Chrome 158 to endpoints.
   - SecurityWeek: https://www.securityweek.com/critical-perforce-puppet-rce-exploited-in-attacks/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/apache-warns-of-roller-rce-vulnerability-exploited-in-attacks/

3. POISONED AGENT FRAMEWORK STEALS CLOUD KEYS
   Software Supply Chain Security · [supply chain, credential
   theft, ai]
   Latest developments: Attackers published malicious versions
   1.26.1 and 1.26.2 of Microsoft's agent-framework package to
   PyPI 33 minutes apart on November 17, 2026, each one running
   a credential stealer every time Python starts and shipping
   out Azure, Azure DevOps, and GitHub Actions credentials, with
   Aikido, Chainguard, Endor Labs, OX Security, SafeDep, Socket,
   StepSecurity, and Wiz all reporting the compromise.
   agent-framework is Microsoft's Python library for building AI
   agents, and any developer or build pipeline that installed
   the two poisoned releases handed over its cloud and CI
   credentials. Pin and audit package versions, rotate Azure and
   GitHub Actions secrets, and check Docker Hub images for
   exposed keys, which researchers watched attackers extract
   within eight seconds of publication.

9. MALWARE C2 MOVES ONTO PUBLIC BLOCKCHAINS
   Ransomware and Cybercrime · [malware, cybercrime, apt]
   Latest developments: Cisco Talos published its analysis of
   bulletproof dead drops, the practice of parking
   command-and-control addresses in public blockchain
   transactions that no takedown can reach, and named UAT-12643,
   a financially motivated group it suspects aligns with North
   Korea, which pairs that blockchain resilience with targeted
   infostealing.
   Blockchain dead drops remove the single points of
   failure—hosting providers, registrars, hardcoded domains—that
   law enforcement seizes in operations like Endgame, since a
   read from a public ledger looks like ordinary traffic.
   Defenders should monitor outbound calls to blockchain RPC
   endpoints and treat them as command-and-control candidates on
   servers with no business reason to make them.
   - Cisco Talos: https://blog.talosintelligence.com/the-challenge-of-defending-against-bulletproof-dead-drops-on-public-blockchains/
   - Cisco Talos: https://blog.talosintelligence.com/uat-12643-suspected-north-korea-aligned-actor-blends-blockchain-resilience-with-targeted-infostealing/

10. A FLASH CHIP ATTACK CRACKS BITLOCKER PINS
   Vulnerabilities and Exploits · [vulnerability, encryption,
   endpoint]
   Latest developments: Researchers at Technische Universität
   Berlin showed that anyone who opens a PC case can reset the
   TPM lockout that limits guesses at Windows Hello and
   BitLocker PINs on AMD-based machines and some Intel machines,
   and in lab tests they recovered a four-digit Hello PIN on an
   AMD laptop and a six-digit BitLocker PIN on an Intel laptop
   in days.
   The trusted platform module normally throttles PIN guessing,
   and clearing that counter turns a short PIN into a
   brute-force problem small enough to finish over a long
   weekend, which puts stolen and lost laptops at risk.
   Organizations relying on BitLocker PINs should require long
   passphrases, add pre-boot protections beyond the PIN, and
   treat physical access to a device as a full compromise path.
   - The Hacker News: https://thehackernews.com/2026/11/flash-chip-attack-bypasses-tpm-lockout.html
