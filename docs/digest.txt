2. REFRIGERATION ATTACKS REACH FRENCH BLOOD BANKS
   Ransomware and Cybercrime · [ics, critical infrastructure,
   supply chain]

   only civilian blood collection and transfusion organization

   access to refrigeration controllers, inventory supplier

4. XEN, RAILS, CHROME, AND ANDROID SHIP CRITICAL FIXES
   Vulnerabilities and Exploits · [patch, zero-day,
   vulnerability]
   Latest developments: The Xen Project disclosed two flaws on
   November 3, 2026 that let one malicious guest virtual machine
   read and write the memory of every other virtual machine on
   the host, dom0 included, reaching all Xen releases from 4.6
   onward with patches out and no mitigation available; the
   Rails project fixed a critical Active Storage flaw in
   versions 8.1.4.1 and 8.0.5.2 that lets an unauthenticated
   attacker write arbitrary files and read sensitive ones on
   servers that process uploads through ImageMagick, which Dark
   Reading said positions an attacker for lateral movement;
   Google shipped Chrome 157 with 213 security fixes, seven of
   them critical; and Google gave the Android remote code
   execution flaw that needs no user interaction the identifier
   CVE-2026-58868, covering Android 14 through 17.
   The Xen bugs break the wall between tenants on a shared host,
   the Rails bug hands file writes to anyone who can upload an
   image, and the Android flaw runs code on a phone with no
   action by its owner. Administrators should apply the Xen
   patches, move to Rails 8.1.4.1 or 8.0.5.2, take Chrome 157,
   and require Android security patch level 2026-11-01 or later.
   - The Hacker News: https://thehackernews.com/2026/11/xen-hypervisor-flaws-let-one-malicious.html
   - Dark Reading: https://www.darkreading.com/application-security/critical-rails-bug-derail-vulnerable-servers

5. APT PACKAGE VERIFICATION FALLS TO A DOWNLOAD SWAP
   Vulnerabilities and Exploits · [patch, vulnerability, supply
   chain]
   Latest developments: Zyxel patched a zero-day in its GS1900
   series network switches that attackers used to compromise
   nearly 1,000 devices worldwide and steal configuration files
   and credentials, reported November 4, 2026; Debian, Ubuntu,
   and the APT developers published advisories the same day for
   a flaw that lets an attacker who can modify package downloads
   substitute their own file for a verified package and run code
   as root, an attack that rides APT's habit of retrying failed
   downloads, the default from Debian 12 onward; and SonicWall
   said it will leave two flaws unpatched in Global Management
   System 9.5.2 and earlier, which it has taken end of life,
   among them CVE-2026-109593, an unauthenticated file read
   rated 9.1 that exposes internal GMS files to anyone with
   network access, alongside a second bug that alters database
   records.
   APT installs and updates software on most Debian and Ubuntu
   machines, so a machine-in-the-middle on any plain-HTTP mirror
   turns routine patching into root compromise. Administrators
   should install the new APT packages, point systems at mirrors
   reached over HTTPS, update GS1900 switches and rotate their
   credentials, and move off SonicWall GMS 9.5.2 and earlier,
   which will never receive a fix.

10. CRÉDIT MUTUEL ARKÉA LOSES $133 MILLION
   Ransomware and Cybercrime · [fraud, banking, supply chain]
   Latest developments: Crédit Mutuel Arkéa, the French
   cooperative banking group, confirmed in a press notice on
   November 4, 2026 that attackers compromised one of its
   suppliers, which the bank left unnamed, and then moved an
   estimated $133 million by making transfers out of the bank's
   own account.
   The intruders used supplier access to issue payments as the
   bank itself, which turns a vendor compromise into direct
   theft of funds. Banks should treat supplier connections into
   payment systems as privileged, require separate approval for
   transfers from house accounts, and reconcile those accounts
   daily.
