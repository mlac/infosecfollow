1. SAP CONFIRMS ATTACKERS COPIED SOURCE CODE
   Data Breaches · [breach, github, supply chain]
   SAP confirmed suspicious GitHub activity in its information
   technology environment, and reports say hackers used stolen
   employee tokens to copy and alter source code.
   Why it matters: SAP software runs finance and logistics for
   most large enterprises, so altered code raises the risk of
   poisoned updates reaching customers.
   - What to do: Rotate GitHub tokens and move developer
     accounts to short-lived credentials. Track SAP advisories
     for named repositories and affected builds.
   - Flashback: The case echoes the 1Password breach, where an
     attacker hijacked an employee's corporate GitHub account
     and copied private repository code.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/sap-confirms-security-incident-after-suspicious-github-activity/
   - SecurityWeek: https://www.securityweek.com/sap-confirms-cyberattack-source-code-reportedly-compromised/

2. SWITZERLAND CONFIRMS AI AGENTS BREACHED OPERATORS
   AI Security · [ai, critical infrastructure, apt]
   Switzerland's cybersecurity agency said attackers using AI
   agents broke in during four of five confirmed cases,
   including two successful intrusions at critical
   infrastructure operators.
   Why it matters: Agent-driven attacks now land on
   infrastructure operators, shrinking the time defenders get
   between initial access and damage.
   - Zoom in: Three of the five attacks targeted critical
     infrastructure operators. The agency reported no major
     disruptions and named neither the victims nor the
     attackers.
   - Between the lines: Microsoft Threat Intelligence says
     China- and North Korea-linked state groups now run ARTEX,
     the open-source framework whose agents plan and execute
     attacks.
   - The Hacker News: https://thehackernews.com/2026/11/switzerland-confirms-ai-assisted.html
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/27/artex-ai-pentest-framework-china-north-korea-state-hackers/

3. RESEARCHERS DETAIL CACTI AND LINUX ROOT FLAWS
   Vulnerabilities and Exploits · [zero-day, linux, patch]
   Researchers detailed 4HTTP2SHELL, a Cacti zero-day reaching
   code execution in four unauthenticated HTTP requests, plus
   CVE-2026-99362, a 12-year-old Linux NFS server root flaw.
   Why it matters: Cacti has no patch or CVE identifier yet, and
   the Network File System bug gives remote attackers root on
   Linux file servers.
   - What to do: Disable guest access in Cacti and pull the
     interface off the internet. Patch Linux kernels on every
     host exporting NFS shares.
   - The Hacker News: https://thehackernews.com/2026/11/unpatched-cacti-zero-day-enables-rce-in.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/new-nfs2root-linux-flaw-can-let-attackers-gain-root-privileges/

5. DRUPAL FLAGS SECOND EXPLOITED TAKEOVER FLAW
   Vulnerabilities and Exploits · [patch, zero-day, cms]
   The Drupal security team said attackers are exploiting a
   second critical access bypass flaw that lets them breach and
   hijack unpatched websites.
   Why it matters: Site owners who already fixed the
   Fail2Install bug stay exposed, and a hijacked content
   management system hands attackers the whole web server.
   - What to do: Install the newest Drupal core security release
     now and treat internet-facing sites as compromised. CISA's
     deadline for CVE-2026-132165 hit November 27, 2026.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/drupal-warns-of-new-access-bypass-flaw-exploited-in-attacks/

   Software Supply Chain Security · [supply chain, malware]
   Researchers said attackers tampered with Q-Dir and DesktopOK
   installers on the official SoftwareOK website, delivering
