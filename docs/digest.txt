1. AI HANDS ATTACKERS THE PHP2SHELL BUGS
   Vulnerabilities and Exploits · [vulnerability, ai, patch]
   Latest developments: Wired reported on October 24, 2026 that
   security researchers used AI tools to dig the years-old flaws
   out of the PHP scripting language in the first place, and
   that AI-assisted exploitation attempts followed the patches,
   while Dark Reading walked administrators through assessing
   exposure because the fix takes more than clicking update.
   CVE-2026-109618 and CVE-2026-109619, the pair the industry
   calls PHP2Shell, reach web servers and content management
   systems worldwide, and the PHP Foundation shipped fixes in
   8.5.12, 8.4.27, 8.3.36, and 8.2.35. Identify every PHP
   interpreter in the estate, including those embedded in vendor
   appliances that carry no fixed release yet, and apply the
   mitigation PHP published for the separate unpatched flaw
   CVE-2026-115560.

   Ransomware and Cybercrime · [supply chain, breach, credential
   theft]
   Latest developments: LiteLLM disclosed on Friday, October 23,
   2026 that a configuration file committed to the public

   the release, and anyone who installed it should rotate every

4. BROTLI DECODER FLAW REACHES BUN, PYTHON, AND ENVOY
   Vulnerabilities and Exploits · [vulnerability, patch, supply
   chain]
   Latest developments: Researchers established that
   CVE-2026-111497, the memory-corruption bug behind this week's
   Node.js remote code execution, sits in Google's Brotli
   decoder itself and therefore in Bun, the Python brotli and
   brotlicffi packages, and Envoy proxies configured to
   decompress Brotli.
   Crafted Brotli-compressed data overwrites memory past the end
   of a buffer, and any service that unpacks attacker-supplied
   Brotli streams inherits the flaw. Inventory every runtime,
   package, and proxy that decodes Brotli rather than treating
   the Node.js 22.x, 24.x, and 26.x updates as the end of the
   work.
   - The Hacker News: https://thehackernews.com/2026/10/brotli-decoder-flaw-behind-nodejs-rce.html
   - The Hacker News: https://thehackernews.com/2026/10/researchers-demonstrate-node2shell-rce.html

5. BLACKX BOOTKIT LOADS A DRIVER AGAINST KASPERSKY AND AVAST
   Nation-State Activity · [apt, malware, zero-day]
   Latest developments: BleepingComputer reported on October 24,
   2026 that BlackX, after defeating Secure Boot, loads a
   malicious driver built to interfere with Kaspersky and Avast
   security products, giving the espionage campaign control of
   the machine's defenses from the moment it boots.
   BlackX is a UEFI bootkit that exploits Baton Drop,
   CVE-2022-21894 in the Windows boot manager, to run ahead of
   the operating system; Kaspersky ties the early 2026 campaign
   to the China-linked group APT41 and names diplomatic
   organizations in Tajikistan, Uzbekistan, and Turkmenistan as
   the targets. Fully patched Windows machines stay vulnerable
   until their owners apply the Secure Boot certificate
   revocations for CVE-2022-21894.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/blackx-uefi-bootkit-exploits-baton-drop-flaw-to-bypass-secure-boot/
   - The Hacker News: https://thehackernews.com/2026/10/blackx-uefi-bootkit-bypasses-secure.html
