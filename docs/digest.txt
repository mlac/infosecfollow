   AI Security · [ai, ot, risk]
   Latest developments: Amazon Web Services released Strands

2. CONNECTWISE DISABLES SEVEN APPLICATION IDENTITIES
   Ransomware and Cybercrime · [supply chain, breach, cloud]
   Latest developments: ConnectWise said on October 18, 2026
   that it disabled seven of its application identities, among
   them ConnectWise Cloud Backup under the identifier
   506e08f9-6e9a-4da4-942b-a099a03644ae, as its investigation
   into the unauthorized access continues.
   Unknown attackers took over the Microsoft 365 application
   identities behind ConnectWise Cloud Backup, formerly SkyKick
   Cloud Backup, a service managed service providers run for
   their clients, and one compromised credential signed in to
   173 customer tenants. ConnectWise has cut customer access to
   the service; administrators should audit sign-ins and consent
   grants tied to the seven listed identities.

4. SITEGUARD FIREWALL FLAW HANDS ATTACKERS ROOT
   Vulnerabilities and Exploits · [exploit, rce, patch]
   Latest developments: BleepingComputer reported on October 18,
   2026 that attackers exploit an operating-system command
   injection flaw in SiteGuard Server Edition, running commands
   as root on Linux hosts and as SYSTEM on Windows hosts.
   SiteGuard Server Edition sits in front of web applications
   and filters hostile traffic, so command injection in it gives
   an attacker the highest privileges on the machine that guards
   the site. Teams running the product should apply the vendor
   fix and hunt their logs for commands executed under root or
   SYSTEM.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hackers-exploit-siteguard-waf-flaw-to-run-commands-as-system-root/
