SECURITY | DATA BREACHES
SAP Confirms Attackers Copied Source Code

SAP confirmed suspicious GitHub activity in its information technology environment, and reports say hackers used stolen employee tokens to copy and alter source code.

*Why it matters:* SAP software runs finance and logistics for most large enterprises, so altered code raises the risk of poisoned updates reaching customers.

*What to do:* Rotate GitHub tokens and move developer accounts to short-lived credentials. Track SAP advisories for named repositories and affected builds.

*Flashback:* The case echoes the 1Password breach, where an attacker hijacked an employee's corporate GitHub account and copied private repository code.

Sources: BleepingComputer, SecurityWeek, The Record

SECURITY | VULNERABILITIES AND EXPLOITS
Researchers Detail Cacti and Linux Root Flaws

A public proof-of-concept exploit for the Cacti zero-day 4HTTP2SHELL now gives unauthenticated attackers command execution, and no patch or CVE identifier exists yet.

*Why it matters:* Cacti monitors network devices with broad credentials, and the separate Linux Network File System bug CVE-2026-99362 hands remote attackers root on file servers.

*What to do:* Disable guest access in Cacti and pull the interface off the internet. Patch Linux kernels on every host exporting NFS shares.

*Flashback:* The Network File System flaw sat in the kernel for 12 years before researchers disclosed it this week.

Sources: BleepingComputer, The Hacker News
