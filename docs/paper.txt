SECURITY | NATION-STATE ACTIVITY
Cairn Agents Exploit MONAI Label Zero-Day

Amazon Threat Intelligence pinned the agent-discovered flaw to MONAI Label 0.8.5 and earlier in default setups, where an attacker with no account writes files outside the storage folder.

*Why it matters:* Every internet-exposed MONAI Label server in that configuration offers suspected China-linked operators the same unauthenticated path to root that took a university server.

*What to do:* Locate MONAI Label deployments, move off 0.8.5 and earlier, and pull the servers off the public internet.

Sources: SecurityWeek, The Hacker News, BleepingComputer

SECURITY | AI SECURITY
OpenRouter Drops Three AI Inference Providers

OpenRouter cut three AI inference providers from its routing pool after Dragos found attackers had stolen customer requests from inside them for months.

*Why it matters:* Prompts carry source code, credentials, and customer records, so a breached inference provider leaks the data enterprises assumed disappeared on arrival.

*Between the lines:* Some stolen requests carried the Zero Data Retention flag, the setting that promises a prompt is never stored.

*By the numbers:* Researchers planted 2 million trackable canary prompts into the AI supply chain and watched secret user data leak.

*What to do:* Inventory which downstream providers your AI gateway routes prompts to. Treat retention promises as unverified until the provider proves detection works.

Signal Blocks AI Agents From Screenshotting Chats

Signal will block screenshots on iOS 27 and stop assistants including Apple's Siri and Google's Gemini from capturing conversations on supported Android devices.

*Why it matters:* On-device agents read whatever the screen displays, so end-to-end encryption stops protecting a message the moment it renders.

*Zoom in:* The restriction covers agentic systems built into iOS 27 and Android versions where Signal can detect an assistant trying to read the app.

Sources: The Hacker News, BleepingComputer

SECURITY | VULNERABILITIES AND EXPLOITS
Hackers Exploit GL.iNet Cloud to Plant Backdoors

GL.iNet confirmed that hackers exploited a flaw in its cloud remote management services to install custom malware on customer routers and KVM devices.

*Why it matters:* A compromised router hands attackers a persistent foothold inside home and small-business networks and a view of the traffic passing through.

*Zoom in:* Affected users report backdoors and reverse shells that give remote access to infected devices.

*What to do:* Turn off GL.iNet cloud remote management. Inspect routers and KVM devices for unexpected listeners and outbound connections.

Sources: BleepingComputer

SECURITY | DATA BREACHES
Cleverbridge Breach Exposes Card Numbers and CVVs

Cleverbridge warned that hackers breached its systems and stole customer payment card information, including credit card numbers and CVV security codes.

*Why it matters:* Card numbers paired with CVVs enable immediate card-not-present fraud, and Cleverbridge runs checkout for software vendors worldwide.

*What to do:* Replace cards used on Cleverbridge checkout pages and watch those accounts for fraudulent charges.

Sources: BleepingComputer

SECURITY | VULNERABILITIES AND EXPLOITS
pwn.ai Breaks Ghostscript Sandbox With Uploads

Security firm pwn.ai showed that a crafted file escapes Ghostscript's security sandbox and runs commands on the server that processes it.

*Why it matters:* Linux servers call Ghostscript to convert uploaded PDFs, PostScript files, and images, often without the application knowing, so an ordinary upload form becomes the entry point.

*What to do:* Install the Ghostscript fix. Map which applications hand user-supplied documents to Ghostscript for conversion.

Sources: The Hacker News
