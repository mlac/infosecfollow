SECURITY | VULNERABILITIES AND EXPLOITS
Drupal Patch Gap Leaves Sites Exploitable

Drupal disclosed CVE-2026-136716, a highly critical flaw already exploited in the wild, because its earlier Fail2Install fix left some sites in vulnerable installation states.

*Why it matters:* Site owners who applied the first patch and declared victory still face unauthenticated takeover across government, university, and media deployments.

*What to do:* Update Drupal core a second time. Hunt for unexpected site reinstalls, new administrator accounts, and changes to settings files.

*Flashback:* Attackers have exploited the original bug, CVE-2026-132165, since at least November 19, and CISA set a November 27 deadline for federal agencies.

Sources: The Hacker News, SecurityWeek, Help Net Security

SECURITY | VULNERABILITIES AND EXPLOITS
Attackers Exploit Mitel MiCollab Zero-Days

Accenture said hackers exploited Mitel MiCollab flaws before Mitel published its advisory, likely with AI assistance, in a suspected extortion campaign.

*Why it matters:* MiCollab servers carry voice, chat, and directory data for entire organizations, and the attacks ran while no patch existed.

*By the numbers:* CISA added 10 flaws to its Known Exploited Vulnerabilities catalog on Wednesday, among them five MiCollab bugs plus Juniper, Vates, and Danfoss products.

*What to do:* Patch MiCollab and audit the Audio, Web and Video Conferencing component for uploaded files under CVE-2026-133275. Pull management interfaces off the internet.

Sources: SecurityWeek, The Hacker News, BleepingComputer

SECURITY | DATA BREACHES
1Password Says Attacker Copied Source Code

1Password said the attacker who hijacked an employee's corporate GitHub account copied source code from private repositories plus account records, and the investigation began November 19, 2026.

*Why it matters:* Stolen customer names and emails give phishers a vetted list of password manager users to impersonate 1Password against.

*Zoom in:* The attacker pushed malicious code into backend services before containment. 1Password says customer vaults and other secrets stayed inaccessible.

*What to do:* Verify any 1Password support contact through the company's own site, and review GitHub account protections for developers with production access.

Sources: The Hacker News, Help Net Security, SecurityWeek

SECURITY | AI SECURITY
Italy and Switzerland Flag Autonomous AI Attacks

The Swiss and Italian national cyber agencies warned that attacks driven by autonomous AI agents are hitting critical infrastructure organizations in both countries.

*Why it matters:* Agent-driven attacks compress reconnaissance and exploitation into minutes, outrunning patch cycles and human-speed triage at utilities, transport, and manufacturing operators.

*What to do:* Unit 42 tells teams to baseline normal behavior and push detection to the edge, since agent-speed intrusions leave no room for manual review.

*What to watch:* Cyber insurers now sort clients into AI-defense haves and have-nots and say the current policy model cannot hold.

Sources: BleepingComputer, Unit 42 (Palo Alto), Dark Reading

SECURITY | SOFTWARE SUPPLY CHAIN SECURITY
Fake Job Tests Hide Malicious NuGet Packages

Socket researcher Kush Pandya found 13 malicious NuGet packages posing as WinUI 3 and Windows Presentation Foundation button controls inside fake take-home job assessments.

*Why it matters:* Building or running the sample project hands attackers access to a .NET developer's machine, and from there to source code and credentials.

*What to do:* Treat recruiter-supplied projects as untrusted code. Build them in disposable virtual machines and restrict developers to vetted package feeds.

Sources: The Hacker News, Dark Reading

SECURITY | RANSOMWARE AND CYBERCRIME
Prosecutors Indict Ransomware Recovery Co-Founder

A federal grand jury in the District of Rhode Island indicted Juan Ricardo Palacio Escobar, 52, on three wire fraud counts for secretly paying ransoms.

*Why it matters:* Companies that hire recovery firms may be funding the gangs that attacked them, taking on sanctions and disclosure exposure they never approved.

*Zoom in:* Agents arrested Palacio Escobar, a Colombian national, in Las Vegas on October 22. Each count carries a maximum of 20 years in prison.

*What to do:* Require recovery vendors to state in writing whether they contact or pay attackers, and keep ransom decisions with the general counsel.

Sources: Help Net Security, The Record

SECURITY | VULNERABILITIES AND EXPLOITS
Attackers Exploit Juniper Session Smart Conductor

Attackers are exploiting CVE-2026-103406 in Juniper Session Smart Conductor to run arbitrary commands as root, and CISA added the flaw to its exploited catalog Wednesday.

*Why it matters:* Conductor sits at the center of Session Smart router deployments, so root command execution there exposes the network paths it manages.

*What to do:* Patch Session Smart Conductor now and keep its management interface off the public internet. Review Conductor hosts for unexpected root processes and new accounts.

Sources: SecurityWeek

SECURITY | RANSOMWARE AND CYBERCRIME
SYS010 Malware Hijacks Browser Enterprise Management

A new version of the SYS01 infostealer, SYS010, enrolls victim browsers into enterprise-style management to force-install an extension that steals data.

*Why it matters:* The forced extension reads Gmail and Outlook mail, turning an ad click into persistent mailbox surveillance with no user consent prompt.

*Zoom in:* Operators deliver the malware through Meta ads, the same channel earlier SYS01 campaigns used to reach business account holders.

*What to do:* Alert on new browser cloud management policies and enrollment profiles appearing on endpoints, and block extension installs outside an approved list.

Sources: BleepingComputer

SECURITY | SOFTWARE SUPPLY CHAIN SECURITY
Keenadu Malware Ships Preinstalled on Android Phones

Kaspersky found the Keenadu malware family preinstalled in Android firmware on more than 220,000 devices during the first ten months of 2026.

*Why it matters:* Buyers cannot remove malware that lives in firmware, so these handsets reach employees and customers already compromised.

*By the numbers:* Keenadu and the older Triada family account for 88% of preinstalled infections, and monthly detections grew more than 2.5 times over the past year.

*What to do:* Source Android hardware from vetted suppliers and verify firmware images before issuing devices. Keep unbranded handsets off corporate networks.

Sources: Help Net Security

SECURITY | AI SECURITY
Google Tightens Rules for Workspace AI Agents

Google will require third-party AI agents to reach Workspace data through Model Context Protocol or command-line interfaces starting February 2027.

*Why it matters:* Agents running on employee credentials carry that person's access to company data, and the rule forces an inventory of every AI tool touching Workspace.

*Zoom in:* The package adds dedicated agent identities, human approval for sensitive operations, and prompt injection screening across Google Workspace and Google Cloud.

*What to do:* List the third-party AI tools connected to Workspace now and confirm each one supports Model Context Protocol or command-line access before February 2027.

Sources: Help Net Security
