SECURITY | CRITICAL INFRASTRUCTURE SECURIT
Norway Names Equinor in Azure Token Hunt

Norway's National Security Authority said an unknown actor hunted access tokens, secrets, and named values in Azure API Management, hitting energy firms Equinor and Skagerak Energi.

*Why it matters:* Stolen gateway credentials reach the backend systems an API fronts, turning one cloud flaw into access across Norwegian energy operations and other sectors.

*What to do:* Microsoft closed the flaw in Azure API Management Classic tiers. Rotate every secret, named value, and subscription key stored in the service.

*Yes, but:* The National Security Authority says it remains uncertain how the actor exploited the vulnerability.

Sources: The Hacker News, BleepingComputer, SecurityWeek, Help Net Security

SECURITY | AI SECURITY
OpenAI and Cisco Ship Shirudo Shield

OpenAI and Cisco released Shirudo, an open-source Linux runtime that lets AI agents write dynamic eBPF controls blocking exploit behavior with no restart.

*Why it matters:* Testing and deploying a Linux patch takes days or weeks, and the vulnerable service stays exposed the whole time.

*What to do:* Teams running exposed Linux services can deploy a shield that blocks the specific behavior a vulnerability depends on while they test the vendor fix.

*Yes, but:* The tool is not yet production-ready, SecurityWeek reports.

Sources: The Hacker News, Help Net Security, SecurityWeek, BleepingComputer

SECURITY | VULNERABILITIES AND EXPLOITS
CISA Flags Exploited N-able MailAssure Flaw

CISA added N-able MailAssure flaw CVE-2026-134624, a server-side request forgery rated 9.3, to its Known Exploited Vulnerabilities catalog on Monday, citing active exploitation.

*Why it matters:* The bug sits in the email filtering cloud N-able runs for managed service providers, handing attackers a route to internal systems behind that service.

*Zoom in:* N-able found the flaw while investigating the breach of its Mail Assure and SpamExperts Hosted Cloud. A user with high-level API access could open connections to chosen internal systems.

*What to do:* Apply the N-able patch and audit high-level API accounts. The company restored access to the affected services and continues to monitor those environments.

Sources: The Hacker News, SecurityWeek

Britain's National Cyber Security Centre said it has observed a marked rise since September in cyberattacks assisted by artificial intelligence.

*Why it matters:* The agency says AI lifts attackers' speed, scale, and persistence, shrinking the window defenders get to spot and contain an intrusion.

*Between the lines:* The European Commission found that its October AI-assisted intrusion exposed names and email addresses of EU Academy users.

SECURITY | AI SECURITY
Cairn Agents Reach Root in 11 Minutes

Dark Reading reported that a China-nexus actor's Cairn agents moved from finding the MONAI Label zero-day to root access in 11 minutes at East Asian universities.

*Why it matters:* Agentic tooling collapses the gap between flaw discovery and full compromise to minutes, far inside most patch and detection cycles.

*What to do:* CISA added the MONAI Label flaw to its Known Exploited Vulnerabilities catalog Monday. Patch the medical imaging platform and block unauthenticated file writes outside its storage folder.

*Between the lines:* Amazon says the agents found and exploited the zero-day with little human input, and the same framework now serves defenders.

Sources: Dark Reading, The Hacker News, Ars Technica Security

SECURITY | RANSOMWARE AND CYBERCRIME
Okta Ties ShinyHunters Crew to INCEPTION

Okta's threat intelligence team said the voice phishing cluster it tracks as O-UNC-053, previously tied to ShinyHunters, resurfaced behind a new leak site named INCEPTION.

*Why it matters:* The crew calls employees at technology, healthcare, biotech, financial services, insurance, gaming, and retail firms, then extorts the data it harvests from them.

*What to do:* Train help desks and staff to refuse credential entry and login approvals requested by phone. The cluster has run campaigns since March 2026.

*Flashback:* The ShinyHunters leak site went dark in September 2026.

Sources: The Hacker News, Help Net Security

SECURITY | VULNERABILITIES AND EXPLOITS
Broadcom Patches New Critical vCenter Flaw

Broadcom shipped fixes for 23 vulnerabilities across VMware ESX, vCenter, Workstation, Fusion, and Avi Load Balancer, among them CVE-2026-123903, an authentication bypass rated 9.8.

*Why it matters:* vCenter runs the virtualization layer under most enterprise data centers, and a China-linked group exploited a separate vCenter bypass as a zero-day starting in September 2026.

*Zoom in:* The critical bug sits in the VMware Directory Service, vmdir, which handles authentication for the management stack.

*What to do:* Patch vCenter first, then work through the remaining products. Pull management interfaces off the internet edge.

Sources: The Hacker News

SECURITY | DATA BREACHES
Unsecured Databases Expose 3.5 Billion Records

Wired reported that a pair of unsecured databases exposed 3.5 billion usernames, passwords, and documents tied to hundreds of millions of people.

*Why it matters:* A corpus that size fuels credential stuffing and account takeover, and the mix of logins and documents lets an attacker own a victim's digital life.

*What to do:* Force resets on reused corporate passwords and enforce multi-factor authentication. Watch customer login endpoints for credential stuffing spikes.

Sources: Wired Security
