SECURITY | DATA BREACHES
SAP Confirms Attackers Copied Source Code

SAP confirmed suspicious GitHub activity in its information technology environment, and reports say hackers used stolen employee tokens to copy and alter source code.

*Why it matters:* SAP software runs finance and logistics for most large enterprises, so altered code raises the risk of poisoned updates reaching customers.

*What to do:* Rotate GitHub tokens and move developer accounts to short-lived credentials. Track SAP advisories for named repositories and affected builds.

*Flashback:* The case echoes the 1Password breach, where an attacker hijacked an employee's corporate GitHub account and copied private repository code.

Sources: BleepingComputer, SecurityWeek

SECURITY | AI SECURITY
Switzerland Confirms AI Agents Breached Operators

Switzerland's cybersecurity agency said attackers using AI agents broke in during four of five confirmed cases, including two successful intrusions at critical infrastructure operators.

*Why it matters:* Agent-driven attacks now land on infrastructure operators, shrinking the time defenders get between initial access and damage.

*Zoom in:* Three of the five attacks targeted critical infrastructure operators. The agency reported no major disruptions and named neither the victims nor the attackers.

*Between the lines:* Microsoft Threat Intelligence says China- and North Korea-linked state groups now run ARTEX, the open-source framework whose agents plan and execute attacks.

Sources: The Hacker News, Help Net Security

SECURITY | VULNERABILITIES AND EXPLOITS
Researchers Detail Cacti and Linux Root Flaws

Researchers detailed 4HTTP2SHELL, a Cacti zero-day reaching code execution in four unauthenticated HTTP requests, plus CVE-2026-99362, a 12-year-old Linux NFS server root flaw.

*Why it matters:* Cacti has no patch or CVE identifier yet, and the Network File System bug gives remote attackers root on Linux file servers.

*What to do:* Disable guest access in Cacti and pull the interface off the internet. Patch Linux kernels on every host exporting NFS shares.

Sources: The Hacker News, BleepingComputer

SECURITY | VULNERABILITIES AND EXPLOITS
Drupal Flags Second Exploited Takeover Flaw

The Drupal security team said attackers are exploiting a second critical access bypass flaw that lets them breach and hijack unpatched websites.

*Why it matters:* Site owners who already fixed the Fail2Install bug stay exposed, and a hijacked content management system hands attackers the whole web server.

*What to do:* Install the newest Drupal core security release now and treat internet-facing sites as compromised. CISA's deadline for CVE-2026-132165 hit November 27, 2026.

Sources: BleepingComputer

SECURITY | SOFTWARE SUPPLY CHAIN SECURITY
Hackers Trojanize Official Q-Dir and DesktopOK Downloads

Researchers said attackers tampered with Q-Dir and DesktopOK installers on the official SoftwareOK website, delivering remote access malware through downloads and in-product updates.

*Why it matters:* Administrators who trusted a vendor's own download page and updater installed a backdoor, defeating the standard advice to avoid third-party mirrors.

*What to do:* Inventory Q-Dir and DesktopOK installations, verify file hashes, and reimage any host running remote access tooling.

Sources: The Hacker News
