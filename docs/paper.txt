Armory Castle Owns the vCenter Zero-Day

CISA added CVE-2026-123890 to its Known Exploited Vulnerabilities catalog on November 20, 2026, hours after Google tied the zero-day to the China-nexus group Armory Castle.

*Why it matters:* vCenter manages an organization's ESX hosts and virtual machines, so one authentication bypass rated 9.8 hands an unauthenticated attacker the whole virtual estate.

*What to do:* Broadcom shipped fixed builds for every supported branch and lists no workaround. Patch now, then hunt for intrusion activity reaching back to early September 2026.

*Between the lines:* Dark Reading reports the group likely held this bug in reserve during the last round of major vCenter updates.

SECURITY | VULNERABILITIES AND EXPLOITS
Cisco Expressway Falls to a Public Proof of Concept

CISA added CVE-2026-76466 to its Known Exploited Vulnerabilities catalog on November 20, 2026, labeling the Cisco Expressway flaw rated 9.8 a use of hard-coded credentials.

*Why it matters:* Expressway carries video and collaboration traffic at the network edge, and the attackers breached four clustered devices at a Russian organization and staged tooling for lateral movement.

*What to do:* Patch every node, then inspect clustered peers for attacker tooling, because compromising one cluster member exposes the rest.

*Zoom in:* The same CISA batch added SAP NetWeaver CVE-2025-42884 and Apache Roller CVE-2026-129448 as actively exploited.

Sources: The Hacker News, CISA Advisories

SECURITY | VULNERABILITIES AND EXPLOITS
Linux KVM Hands Guests the Host's Memory

Researchers used CVE-2026-99312 in KVM, the hypervisor built into the Linux kernel, to read about 127 gigabytes of a DigitalOcean server's memory from inside their own virtual machine.

*Why it matters:* On a shared host, that memory can hold other customers' virtual machines, which breaks the tenant boundary cloud customers pay for.

*What to do:* The flaw reaches only AMD hosts with nested virtualization enabled. Roll out the fixed kernels and turn nested virtualization off where no workload needs it.

Sources: The Hacker News
