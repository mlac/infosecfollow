SECURITY | DATA BREACHES
SAP Confirms Attackers Copied Source Code

SAP confirmed suspicious GitHub activity in its information technology environment, and reports say hackers used stolen employee tokens to copy and alter source code.

*Why it matters:* SAP software runs finance and logistics for most large enterprises, so altered code raises the risk of poisoned updates reaching customers.

*What to do:* Rotate GitHub tokens and move developer accounts to short-lived credentials. Track SAP advisories for named repositories and affected builds.

*Flashback:* The case echoes the 1Password breach, where an attacker hijacked an employee's corporate GitHub account and copied private repository code.

Sources: BleepingComputer, SecurityWeek, The Record

SECURITY | VULNERABILITIES AND EXPLOITS
Researchers Detail Cacti and Linux Root Flaws

A public proof-of-concept exploit for the Cacti zero-day 4HTTP2SHELL now gives unauthenticated attackers command execution, and no patch or CVE identifier exists yet.

*Why it matters:* Cacti monitors network devices with broad credentials, and the separate Linux Network File System bug CVE-2026-99362 hands remote attackers root on file servers.

*What to do:* Disable guest access in Cacti and pull the interface off the internet. Patch Linux kernels on every host exporting NFS shares.

*Flashback:* The Network File System flaw sat in the kernel for 12 years before researchers disclosed it this week.

Sources: BleepingComputer, The Hacker News

Drupal Flags Second Exploited Takeover Flaw

CISA added exploited Drupal core flaw CVE-2026-136716 and two OSGeo GeoServer flaws, CVE-2026-120705 and CVE-2026-129243, to its Known Exploited Vulnerabilities catalog Friday.

*Why it matters:* Site owners who already fixed the Fail2Install bug stay exposed, and a hijacked content management system hands attackers the whole web server.

*What to do:* Install the newest Drupal core security release now and treat internet-facing sites as compromised. CISA's deadline for CVE-2026-132165 hit November 27, 2026.

*Zoom in:* The Drupal security team says attackers are exploiting a second critical access bypass flaw to breach and hijack unpatched websites.

Sources: BleepingComputer, CISA Advisories

SECURITY | SOFTWARE SUPPLY CHAIN SECURITY
Attackers Trojanize Signed Windows Utility Downloads

Researchers found tampered Q-Dir and DesktopOK installers on the official SoftwareOK website, and eSentire traced a Microsoft-signed Snipping-Tool.exe installer that delivered Vinci RAT.

*Why it matters:* Trusted vendor download pages and valid Microsoft signatures defeat the checks users and allowlists rely on, handing attackers remote control of workstations.

*Zoom in:* SoftwareOK served malicious files during updates of already installed programs. The Vinci RAT chain began with a redirect to the fake site snipp.codes-team[.]com.

*What to do:* Reinstall Q-Dir and DesktopOK from verified copies. Hunt for Snipping-Tool.exe executions and traffic to the fake sniping tool domain.

Sources: The Hacker News

SECURITY | DATA BREACHES
pCloud Confirms Password Manager Hack

pCloud confirmed a cyberattack on its pCloud Pass password manager after users reported unknown devices connecting to accounts that had two-factor authentication turned on.

*Why it matters:* A password manager holds every other credential, so attackers who reach those vaults can walk into banking, email, and corporate accounts.

*What to do:* Change the pCloud account password, revoke every unrecognized device session, and rotate the credentials stored inside pCloud Pass.

Sources: BleepingComputer
