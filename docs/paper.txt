SECURITY | VULNERABILITIES AND EXPLOITS
Attackers Run Root Commands on Cisco Expressway

Russian security company F6 reported that attackers exploited CVE-2026-76466 in Cisco Expressway gateways to breach organizations and reach their internal networks.

*Why it matters:* Both Expressway and SAP NetWeaver sit at the enterprise network edge, so root-level command execution gives intruders a staging point for internal movement.

*What to do:* Install Cisco's Expressway and SAP's NetWeaver updates now. CISA's Known Exploited Vulnerabilities listing sets a remediation deadline for federal civilian agencies.

Sources: SecurityWeek, BleepingComputer, Help Net Security

SECURITY | VULNERABILITIES AND EXPLOITS
GL.iNet Patches Cloud Flaw After Backdoors

GL.iNet fixed the GoodCloud remote management flaw on Friday and blocked the attacker's access, and says cleaning infected routers and KVM devices requires new firmware.

*Why it matters:* Affected owners reported reverse shells and backdoors on their hardware, so a reboot or factory reset leaves the implant running.

*What to do:* Reflash affected GL.iNet routers and KVM devices with the new firmware. Closing the GoodCloud path stops fresh infections only.

Sources: SecurityWeek, The Hacker News, BleepingComputer

*The big picture:* Amazon Threat Intelligence reported that Cairn agents, given only target addresses and a goal of shell access, found and exploited a medical imaging zero-day.

Sources: The Hacker News, Help Net Security

SECURITY | VULNERABILITIES AND EXPLOITS
Attackers Hijack MSP Technician Hosts

Threat actors exploited ConnectWise ScreenConnect flaw CVE-2026-84869, rated 9.9, against a managed service provider server on November 12, 2026, running payloads on a connecting technician's machine.

*Why it matters:* A hijacked technician host hands intruders remote access to every customer that provider manages, turning one compromise into many.

*What to do:* Patch ScreenConnect clients against CVE-2026-84869. N-able fixed CVE-2026-134624, a server-side request forgery bug in Mail Assure that high-privilege API users could aim at internal systems.

Sources: The Hacker News

HUMAN Disrupts BADBOX 3.0 Ad Fraud

HUMAN's Satori Threat Intelligence and Research Team disrupted BADBOX 3.0, the backdoored low-cost TV box operation that peaked near 40 billion ad bid requests a day.

*Why it matters:* The same backdoors rent out owners' home internet connections as residential proxies, handing criminals clean IP addresses for attacks on other targets.

SECURITY | VULNERABILITIES AND EXPLOITS
Attackers Exploit ASP.NET Anti-CSRF Library Flaw

Researchers told developers to abandon the legacy Idunno.AntiCsrf library after attackers exploited CVE-2026-131914, rated 9.3, for unauthenticated remote code execution.

*Why it matters:* Any ASP.NET application still loading the library hands attackers code execution with no credentials, and the component sits deep inside older web stacks.

*What to do:* Find and remove Idunno.AntiCsrf.dll versions 0.9.1.0 and 0.9.1 Beta. Researchers recommend discontinuing the library rather than waiting for a fix.

Sources: The Hacker News
