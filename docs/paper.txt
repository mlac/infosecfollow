SECURITY | VULNERABILITIES AND EXPLOITS
Hackers Exploit Drupal Flaw Found by Anthropic

Drupal confirmed attackers have exploited CVE-2026-132165, dubbed Fail2Install and rated 9.8, since at least November 19, and CISA set a November 27 patch deadline.

*Why it matters:* Unpatched Drupal sites face full takeover, and an Anthropic AI scanner found the bug, so AI-discovered flaws now reach attackers fast.

*Zoom in:* CISA added two more exploited bugs: CVE-2026-132224 in Optimizely Web Experimentation, used to plant malicious JavaScript on major websites, and CVE-2026-131914 in the Idunno AntiCsrf library.

*What to do:* Update Drupal core immediately. Rip Idunno AntiCsrf out of legacy ASP.NET applications, because the project is defunct and a single crafted web request runs code.

Sources: BleepingComputer, SecurityWeek, The Hacker News, Help Net Security

The Treasury Department's Financial Crimes Enforcement Network took systems offline after a cyberattack that gained unauthorized access to a limited subset of them.

*Why it matters:* FinCEN holds suspicious activity reports from every United States bank, so an intruder inside it sees which people and companies investigators are tracking.

*By the numbers:* Colorado said criminals likely stole data on 150,000 myColorado users and knocked the state's digital identification app offline.

*What's next:* FinCEN extended filing deadlines for institutions the outage hit while its investigation runs.

SECURITY | SOFTWARE SUPPLY CHAIN SECURITY
Attackers Run Commands on Hex.pm Servers

An attacker exploited a flaw rated 10.0 on Monday to run operating system commands on six production servers of Hex.pm, the Elixir and Erlang package registry.

*Why it matters:* Control of a registry lets one attacker poison dependencies for every Elixir and Erlang project that fetches packages from it.

*Zoom in:* The bug had sat in the registry's code since February 2016. Maintainers moved every server to a patched build within about 15 minutes of the first malicious request.

*What to do:* Check WordPress installations for six WP Connect plugins backdoored on November 22, 2026 after a suspected developer account compromise. WordPress blocked the releases before publication.

Iran Sabotages Freezers as Danfoss Flaw Sits Unpatched

France blamed an Iranian military cyber unit for sabotaging hundreds of supermarket freezers, hardening an earlier low-confidence United States assessment into a formal attribution.

*Why it matters:* A state actor now wrecks refrigeration to spoil food and rattle shoppers, which drags grocery operational technology into geopolitical conflict.

SECURITY | VULNERABILITIES AND EXPLOITS
Attackers Exploit Two Patched GeoServer Flaws

watchTowr reported active exploitation of two newly patched GeoServer flaws, CVE-2026-120705 and CVE-2026-129243, which researchers chain into unauthenticated remote code execution.

*Why it matters:* The chain needs no credentials, so any internet-facing GeoServer instance can fall to full server compromise.

*Zoom in:* CVE-2026-120705, rated 8.6, lets an attacker read local text files the GeoServer process can reach.

*What to do:* Install the patched GeoServer releases now and review web logs for file read attempts against the server.

Sources: The Hacker News, SecurityWeek

SECURITY | CLOUD SECURITY
Bots Grab Leaked AWS Keys in Seconds

Stony Brook University researchers Billy Tsouvalas and Nick Nikiforakis planted 300 decoy Docker images and watched bots find and use an embedded cloud access key in under eight seconds.

*Why it matters:* Any secret that reaches a public registry burns instantly, which makes rotation plans measured in hours or days worthless.

*By the numbers:* VulnCheck tracked 694 exploited CVEs from January through November 2026 and found attackers used 127 of them to steal database passwords, cloud keys, API tokens, or SSH keys.

*What to do:* Scan container images for secrets before publishing them, and treat a leaked key as used rather than merely exposed.

Sources: Help Net Security
