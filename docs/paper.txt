SECURITY | AI SECURITY
Cairn Agents Root a MONAI Label Server

Amazon Threat Intelligence named the target software: autonomous Cairn agents found an unauthenticated file-write flaw in MONAI Label and took root on a university server.

*Why it matters:* An AI framework discovered and weaponized an unknown bug in one run, erasing the window defenders rely on between disclosure and exploitation.

*What to do:* Audit MONAI Label installs at version 0.8.5 or earlier, which ship exploitable in the default setup, and take the open-source imaging server off the internet.

*Zoom in:* The flaw lets an attacker with no account write files outside the server's storage folder, which the agents turned into root access.

Sources: SecurityWeek, The Hacker News, BleepingComputer, The Record

SECURITY | VULNERABILITIES AND EXPLOITS
GnuPG and WhatsApp Patch Critical Flaws

GnuPG warned that a malicious OpenPGP key with an unusually long user ID triggers a critical memory bug in GPGME, tracked as CVE-2026-129975, and shipped fixes.

*Why it matters:* Every application built on GPGME, the standard library programs use to work with GnuPG, can leak its data to anyone who supplies a crafted key.

*What to do:* Move to GPGME 2.3.0 or later. Android users need WhatsApp or WhatsApp Business 2.26.17.4 or newer to close CVE-2026-23871.

*Between the lines:* WhatsApp's security team found the ad-reply URL validation bug while disrupting a scam campaign and suspects attackers used it to make scam messages look credible.

Sources: The Hacker News, SecurityWeek

SECURITY | AI SECURITY
Malicious Webpage Hijacks Meta Muse Chats

Researchers showed a single malicious webpage pulling a Meta Muse user's private conversations and stored memories out of the assistant with no approval prompt.

*Why it matters:* The same attack reaches credentials Muse holds for a user's connected accounts, turning one assistant into a silent path to every linked service.

*Zoom in:* Signal will restrict screenshots by default on Android and iOS to stop AI agents from reading chats, and calls the protection incomplete.

*By the numbers:* A researcher planted 2 million tracking canaries in prompts across the AI supply chain and watched secret user data escape at a high rate.

Sources: The Hacker News, Ars Technica Security

SECURITY | VULNERABILITIES AND EXPLOITS
CISA Flags SAP NetWeaver and vCenter Exploits

CISA added four actively exploited flaws to its Known Exploited Vulnerabilities catalog Friday, covering Apache Roller, Cisco Expressway, SAP NetWeaver, and Broadcom VMware vCenter.

*Why it matters:* SAP NetWeaver joins the exploited list, pushing the current espionage campaign into enterprise resource planning estates that run finance and logistics.

*What to do:* Patch all four products on CISA's federal timeline. The Apache Roller deserialization bug, CVE-2026-129448, carries a 9.8 severity score and needs no credentials.

*What to watch:* Dark Reading reported that China-nexus group Armory Castle likely held its next vCenter zero-day ready during the last round of VMware updates.

Sources: The Hacker News, Dark Reading

SECURITY | DATA BREACHES
Rackspace Spot Breach Exposes Kubernetes Secrets

Rackspace told customers that attackers used compromised credentials to breach its Spot cloud platform, deploy unauthorized workloads, and read Kubernetes secrets in customer clusters.

*Why it matters:* Kubernetes secrets hold the keys and tokens customer applications run on, so one platform breach carries attackers into every system those keys unlock.

*What to do:* Rotate every secret stored in Rackspace Spot clusters and review those clusters for workloads nobody on the team authorized.

Sources: BleepingComputer
