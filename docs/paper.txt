Hackers Exploit Drupal Flaw Found by Anthropic

Drupal confirmed attackers have exploited CVE-2026-132165, dubbed Fail2Install and rated 9.8, since at least November 19, and CISA set a November 27 patch deadline.

*Why it matters:* Unpatched Drupal sites face full takeover, and an Anthropic AI scanner found the bug, so AI-discovered flaws now reach attackers fast.

*Zoom in:* CISA added two more exploited bugs: CVE-2026-132224 in Optimizely Web Experimentation, used to plant malicious JavaScript on major websites, and CVE-2026-131914 in the Idunno AntiCsrf library.

*What to do:* Update Drupal core immediately. Rip Idunno AntiCsrf out of legacy ASP.NET applications, because the project is defunct and a single crafted web request runs code.
