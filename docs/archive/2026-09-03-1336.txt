4. WORDPRESS PLUGIN FLAWS DRAW ACTIVE EXPLOITATION
   Vulnerabilities and Exploits · [patch, exploitation,
   wordpress]
   Latest developments: Attackers began exploiting
   CVE-2026-32475, a recently patched critical flaw in the
   Elementor Pro plugin, to plant webshells and run arbitrary
   commands on WordPress hosts, while researchers assigned
   CVE-2026-19949 to the unauthenticated SQL injection in the
   All-in-One WP Migration and Backup plugin and put the exposed
   population above 3 million sites.
   Both plugins sit on millions of WordPress installations, and
   either bug hands an unauthenticated attacker remote code
   execution on the web server. Site owners should update
   Elementor Pro and All-in-One WP Migration and Backup now,
   then hunt for unfamiliar PHP files and new administrator
   accounts.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/critical-elementor-pro-flaw-exploited-to-take-over-wordpress-sites/

5. FALCONFLANK ZERO-DAY HITS CROWDSTRIKE FALCON
   Vulnerabilities and Exploits · [zero-day, patch, endpoint]
   Latest developments: The researcher known as Chaotic Eclipse,
   also called Nightmare Eclipse, published a proof-of-concept
   for FalconFlank, a privilege-escalation zero-day that abuses
   the malicious-macro remediation routine in the CrowdStrike
   Falcon Sensor, the same researcher whose HardBreacher exploit
   forced a Kaspersky patch on August 31, 2026; Cisco meanwhile
   patched CVE-2026-20212, a CVSS 9.8 bug in 10 Silicon
   One-based Nexus 9000 switches that gives an unauthenticated
   remote attacker root code execution, shipped an IOS XR
   hardening release bundling seven CVEs with no workaround for
   any version, and left publicly disclosed S/MIME flaws in
   Secure Email unpatched.
   FalconFlank turns a defensive feature of the Falcon endpoint
   agent into a path from a local account to full control of the
   host. The unpatched Cisco Secure Email defects can expose the
   contents of encrypted mail; apply the Nexus and IOS XR
   updates now and watch for a CrowdStrike sensor release.
   - The Hacker News: https://thehackernews.com/2026/09/researcher-releases-falconflank-poc.html

6. MICROSOFT DETAILS SPRING RING TEAMS IMPERSONATION, NODE.JS
   ABUSED AS LOADER
   Ransomware and Cybercrime · [social-engineering, malware]
   Latest developments: Microsoft Threat Intelligence published
   its own technical writeup of a human-operated intrusion
   campaign, matching the Spring Ring operation Unit 42 first
   disclosed, that abuses Microsoft Teams external collaboration
   to impersonate IT support and deploy a Node.js-based implant
   for lateral movement, while Symantec separately documented a
   distinct campaign running since February 2026 that abuses the
   trusted node.exe runtime to deliver payloads against
   government departments, technology companies, and hotels.
   Both campaigns exploit the fact that node.exe carries
   Microsoft's own code-signing trust, letting malicious
   JavaScript payloads slip past defenses tuned to flag
   unfamiliar executables. Organizations should restrict
   external Teams collaboration requests and treat unexpected
   node.exe network activity as suspicious.

8. IDSCAN.NET TIED TO 153 MILLION LICENSE SCANS
   Data Breaches · [breach, identity-theft]
   Latest developments: SecurityWeek named IDScan.net, the
   Louisiana identity-verification vendor, as the likely source
   of the more than 153 million United States and Canadian
   driver's license images now for sale on a dark-web service,
   and an Ars Technica reporter found their own license in the
   trove within hours of renting a car.
   Businesses scan customer licenses through IDScan.net at
   rental counters, bars, and dispensaries, and the scans
   include the photograph and every field on the card. The FBI's
   New Orleans field office has opened an investigation;
   consumers should freeze credit files and treat license-based
   identity checks as compromised.
   - SecurityWeek: https://www.securityweek.com/153-million-driver-license-images-offered-on-dark-web/
