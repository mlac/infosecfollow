6. TAILSCALE RUSHES TAILWORM PATCHES
   Vulnerabilities and Exploits · [vulnerability, patch,
   privilege escalation]
   Latest developments: Tailscale's security team is building
   fixes for close to a dozen vulnerabilities in Tailscale SSH,
   the set researchers call Tailworm, after someone published
   the details over the weekend without coordinating with the
   company and before any patch existed; the bugs let an
   attacker steal credentials, crash servers, and escalate to
   root on machines reachable across the same network.
   Tailscale runs a WireGuard mesh that companies use as a flat
   private network, and Tailscale SSH authenticates logins
   through that mesh, so one compromised device reaches every
   server its access rules allow. Until the releases land, turn
   off Tailscale SSH and tighten the access control lists that
   decide which devices may connect to which hosts.
   - SecurityWeek: https://www.securityweek.com/tailscale-rushes-patches-after-uncoordinated-disclosure-of-tailworm-flaws/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/tailscale-warns-of-serious-ssh-flaws-allowing-root-privilege-escalation/

7. GHEIST EXPANDS ACROSS 850 GITHUB ACCOUNTS
   Ransomware and Cybercrime · [supply chain, credential theft,
   devops]
   Latest developments: Wiz Research put numbers on the campaign
   on October 27, 2026, recovering more than 13,500 planted
   branches from over 850 compromised GitHub accounts, and
   explained the name Gheist, which comes from the user agent
   the attacker's tool sends with its GitHub API requests.
   The tool takes a stolen GitHub token, enumerates every
   repository that token opens, plants a workflow that prints
   the repository's secrets into a build log, then downloads the
   log and deletes the run. The damage lands inside private
   repositories and GitHub Enterprise environments, so rotate
   tokens and audit Actions run history.
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/27/gheist-github-token-abuse/
   - Dark Reading: https://www.darkreading.com/cyberattacks-data-breaches/gheist-stolen-github-tokens-cloud-secrets

9. OPENAI COMPACTION FLAW LEAKS HIDDEN REASONING
   AI Security · [ai, model theft, vulnerability]
   Latest developments: The security firm Xint showed that
   compaction, the OpenAI feature that shrinks a long
   conversation to save space, returns a model's hidden
   reasoning in plain text, defeating the encryption OpenAI
   wraps around those traces, and the firm demonstrated moving
   reasoning traces between models.
   OpenAI's reasoning models work through a problem before
   answering and normally hand back the chain of thought as an
   encrypted blob the customer cannot read, which protects the
   company's most expensive training signal. Extracted traces
   cut the cost of distilling a rival model, a prospect
   SecurityWeek frames as a lift for Chinese competitors.
   - The Hacker News: https://thehackernews.com/2026/10/openai-compaction-flaw-let-researchers.html
   - SecurityWeek: https://www.securityweek.com/stolen-ai-reasoning-could-help-china-build-cheaper-rivals/
