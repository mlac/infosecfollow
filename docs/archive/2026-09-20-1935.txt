1. MALICIOUS NPM PACKAGES HIDE IN RUNTIME
   Software Supply Chain Security · [supply-chain, npm, malware]
   Latest developments: BleepingComputer detailed an ongoing npm
   campaign on September 20, 2026 built around the package
   indexed-btree, which carries its malicious code inside the
   package's normal runtime behavior and so slips past the
   install-script defenses that registries and enterprises rely
   on.
   npm hardening concentrates on preinstall and postinstall
   hooks, and this campaign leaves those hooks clean, waiting
   instead until an application calls the library. Developers
   should watch what a dependency does at execution time, pin
   versions, and treat a quiet install as no evidence of safety.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/malicious-npm-packages-evade-install-script-defenses-at-runtime/

2. RESEARCHERS ESCAPE THE OPENAI CODEX SANDBOX
   AI Security · [ai, sandbox-escape, patch]
   Latest developments: BleepingComputer reported on September
   20, 2026 that researchers broke out of the sandbox around
   OpenAI's Codex coding agent two separate ways, one of them
   from the agent's most locked-down mode, and ran commands on
   the developer's own machine; OpenAI has patched both routes.
   Codex runs the code it writes inside a sandbox so that a
   hostile repository or a poisoned prompt stops at that
   boundary. Both escapes crossed onto the host, so anyone
   running Codex should take the patched release.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/researchers-escape-openai-codex-sandbox-to-run-commands-on-host/

3. GYAZO SERVER FLAW YIELDS 23.6 MILLION RECORDS
   Data Breaches · [breach, data-theft]
   Latest developments: Gyazo confirmed on September 18, 2026
   that hackers exploited a vulnerability in its server to pull
   out 23.6 million user records, naming the technical cause
   behind the exposure it disclosed earlier in the week.
   Gyazo, the image-sharing service that the Kyoto company
   Helpfeel runs, holds email addresses and password hashes in
   those records. Users should change their Gyazo password along
   with any password they reused elsewhere.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/gyazo-server-flaw-exploited-to-steal-236-million-user-records/

4. AI DEPLOYMENT OUTRUNS ITS CONTROLS
   AI Security · [ai, governance]
   Latest developments: Ernst & Young published a survey of
   senior artificial intelligence executives on September 18,
   2026 showing that their organizations deploy AI and
   autonomous systems faster than they build the processes and
   controls to oversee them.
   The gap leaves agents running with permissions nobody reviews
   and actions nobody logs. Tie every agent deployment to a
   named owner, a bounded permission scope, and an audit trail
   before it touches production.
   - Dark Reading: https://www.darkreading.com/cyberattacks-data-breaches/ey-survey-autonomous-ai-implementation-outpaces-oversight
