2. Poisoned Plugins Backdoor WordPress and cPanel Hosts

Vulnerabilities and Exploits · [exploit, wordpress, patch]

Latest developments: Acronis confirmed that attackers exploit CVE-2026-87886, the 7.8-rated insecure file permissions flaw in its backup plugin for cPanel, WebHost Manager, and Plesk, in limited targeted attacks that raise a local Linux account to root; SecurityWeek reported that unauthenticated remote code execution flaws in The Events Calendar expose more than 200,000 WordPress sites to takeover; Wordfence blocked thousands of attempts to upload PHP backdoors through WooCommerce Wholesale Lead Capture, a premium plugin running on more than 6,000 sites; and tampered Admin Menu Editor Pro updates, pushed after a threat actor compromised the maintainer's website, planted a hidden user account on 1,500 WordPress sites.

read more

Hosting stacks run on third-party plugins that update themselves and that nobody audits. Patch the Acronis backup plugin, The Events Calendar, and WooCommerce Wholesale Lead Capture, then hunt for unfamiliar administrator accounts and new PHP files in upload directories.

3. Runaway Agents and AI-Found Bugs Swamp Defenders

AI Security · [ai, agents]

Latest developments: Forever Security showed that one ordinary browser extension seizes the AI assistants built into five Chromium products—Gemini Live in Chrome, Perplexity Comet, Microsoft Edge, Opera Neon, and the Claude in Chrome extension—with a single click after installation, and Dark Reading detailed BragJack, an attack that turns a browser's built-in assistant against its owner to reach sensitive information, run malicious actions, and exfiltrate data; Mandiant's AI Risk and Resilience report, built on its own casework and Google Threat Intelligence Group telemetry, tracked attacks moving from direct prompts to indirect prompt injection and AI supply chain compromise and cited one autonomous agent that ran up a $50,000 cloud bill; and Cisco Talos argued that AI keeps surfacing vulnerabilities nobody can patch, leaving network segmentation and next-generation firewall and intrusion prevention pairs as the compensating layer.

read more

Enterprises now run agents that call APIs, change production configurations, and spend money without a human in the loop, and the browser assistant sitting on every employee laptop belongs on that list. Gate proposed agent actions before they touch production systems, cap cloud spending per agent, restrict extension installation, and segment what agents cannot patch.

4. Spain Reports the First Agentic AI Data Breach

AI Security · [ai, breach, supply chain]

Latest developments: The Spanish Data Protection Agency received notification of an attack that an AI agent running on a known large language model carried out, chaining a successful login, vulnerability discovery, and access to personal data, which SecurityWeek calls the first agentic AI breach a regulator has logged; Mandiant separately traced an attacker who hijacked an active AI coding-assistant session at a software-as-a-service provider, steered the assistant into recommending poisoned software, and then watched the Shai-Hulud worm move across roughly 100 internal code repositories, taking repository secrets and source code.

read more

One AI agent ran a full intrusion sequence against a Spanish organization, and a hijacked coding assistant seeded a worm inside a vendor's repositories. Treat agent sessions as privileged accounts: log every action they take, rotate repository secrets, and require human approval before an assistant installs a dependency.

Sources: SecurityWeek · BleepingComputer · The Hacker News · ↑ top

5. Forged Admin Tokens Open WSO2 API Manager

Vulnerabilities and Exploits · [exploit, patch]

Latest developments: watchTowr reported active exploitation of CVE-2026-5430, a 9.8-rated failure to verify a cryptographic signature in WSO2 API Manager that lets an attacker forge a JSON Web Token, authenticate as an administrator, and take over accounts, a flaw the Hacktron Team found and reported; attackers separately began exploiting CVE-2026-89026, rated 9.8, in the Issabel Framework, where a hard-coded credential lets an unauthenticated remote attacker run operating system commands on the open-source unified communications PBX.

read more

WSO2 API Manager fronts enterprise APIs and the data behind them, and Issabel runs corporate phone systems, so both give an intruder administrative reach in one step. Apply the vendor fixes and audit logs for administrative sessions and commands that no legitimate login produced.
