   Nation-State Activity · [apt, espionage]
   Latest developments: Kaspersky's GReAT team detailed a new
   Project CAV3RN module that hides command-and-control inside
   Outlook calendar events through the Microsoft Graph API and
   recovers its configuration from DNS AAAA records, extending
   the calendar-hijacking framework that Group-IB tracks as
   HollowGraph and ties to Iranian espionage.
