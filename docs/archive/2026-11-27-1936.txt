2. SAP CONFIRMS ATTACKERS COPIED SOURCE CODE
   Data Breaches · [breach, github, supply chain]
   SAP confirmed suspicious GitHub activity in its information
   technology environment, and reports say hackers used stolen
   employee tokens to copy and alter source code.
   Why it matters: SAP software runs finance and logistics for
   most large enterprises, so altered code raises the risk of
   poisoned updates reaching customers.
   - What to do: Rotate GitHub tokens and move developer
     accounts to short-lived credentials. Track SAP advisories
     for named repositories and affected builds.
   - Flashback: The case echoes the 1Password breach, where an
     attacker hijacked an employee's corporate GitHub account
     and copied private repository code.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/sap-confirms-security-incident-after-suspicious-github-activity/
   - SecurityWeek: https://www.securityweek.com/sap-confirms-cyberattack-source-code-reportedly-compromised/
   - The Record: https://therecord.media/sap-germany-cyberattack-github

3. RESEARCHERS DETAIL CACTI AND LINUX ROOT FLAWS
   Vulnerabilities and Exploits · [zero-day, linux, patch]
   A public proof-of-concept exploit for the Cacti zero-day
   4HTTP2SHELL now gives unauthenticated attackers command
   execution, and no patch or CVE identifier exists yet.
   Why it matters: Cacti monitors network devices with broad
   credentials, and the separate Linux Network File System bug
   CVE-2026-99362 hands remote attackers root on file servers.
   - What to do: Disable guest access in Cacti and pull the
     interface off the internet. Patch Linux kernels on every
     host exporting NFS shares.
   - Flashback: The Network File System flaw sat in the kernel
     for 12 years before researchers disclosed it this week.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/unpatched-cacti-zero-day-with-public-poc-gives-remote-code-execution/
   - The Hacker News: https://thehackernews.com/2026/11/unpatched-cacti-zero-day-enables-rce-in.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/new-nfs2root-linux-flaw-can-let-attackers-gain-root-privileges/

7. ATTACKERS TROJANIZE SIGNED WINDOWS UTILITY DOWNLOADS
   Software Supply Chain Security · [supply chain, malware]
   Researchers found tampered Q-Dir and DesktopOK installers on
   the official SoftwareOK website, and eSentire traced a
   Microsoft-signed Snipping-Tool.exe installer that delivered
   Vinci RAT.
   Why it matters: Trusted vendor download pages and valid
   Microsoft signatures defeat the checks users and allowlists
   rely on, handing attackers remote control of workstations.
   - Zoom in: SoftwareOK served malicious files during updates
     of already installed programs. The Vinci RAT chain began
     with a redirect to the fake site snipp.codes-team[.]com.
   - What to do: Reinstall Q-Dir and DesktopOK from verified
     copies. Hunt for Snipping-Tool.exe executions and traffic
     to the fake sniping tool domain.
   - The Hacker News: https://thehackernews.com/2026/11/hackers-trojanize-official-q-dir-and.html
   - The Hacker News: https://thehackernews.com/2026/11/microsoft-store-app-found-delivering.html

9. PCLOUD CONFIRMS PASSWORD MANAGER HACK
   Data Breaches · [breach, credentials]
   pCloud confirmed a cyberattack on its pCloud Pass password
   manager after users reported unknown devices connecting to
   accounts that had two-factor authentication turned on.
   Why it matters: A password manager holds every other
   credential, so attackers who reach those vaults can walk into
   banking, email, and corporate accounts.
   - What to do: Change the pCloud account password, revoke
     every unrecognized device session, and rotate the
     credentials stored inside pCloud Pass.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/pcloud-confirms-password-manager-hack-after-suspicious-login-alerts/
