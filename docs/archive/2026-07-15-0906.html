4. Cursor and Claude AI Tools Expose Developer Machines

AI Security · [ai, supply-chain, rce]

Latest developments: Researchers showed Cursor on Windows silently runs a git.exe planted in a cloned repository's root with the developer's own privileges and no prompt, a separate two-click Cursor exploit hands attackers a developer's secrets and source, and a Claude for Chrome flaw lets a rogue extension trigger reads of a victim's Gmail, latest Google Doc, and Calendar.

5. ClickFix Industrializes Social Engineering

Ransomware and Cybercrime · [social-engineering, malware]

Latest developments: ReversingLabs reported that ClickFix has grown from a one-off trick into an industrialized, rentable attack ecosystem that skips exploits entirely, outpaces antivirus and endpoint detection, and leaves YARA analysis as the strongest detection option.

read more

ClickFix, which surfaced in late 2023 and drew its name from Proofpoint in mid-2024, uses fake CAPTCHA checks, browser-update notices, or meeting-error pages to trick victims into pasting commands into the Windows Run box. Criminals now rent the kit at scale, so defenders should train users and hunt the run-box behavior directly.
