1. AGENTS GET SPENDING POWER BEFORE CONTROLS CATCH UP
   AI Security · [ai, fraud]
   Latest developments: OpenAI began rolling out ChatGPT Wallet,
   built with American Express, Mastercard, and Visa, which pays
   merchants through a stand-in card number so a user's real
   card details reach neither the agent nor the merchant, and
   Token Security published five enterprise gaps it found while
   testing an invoice-processing agent that a malicious email
   could push into changing a vendor's bank details with no
   alert firing.
   Agents now hold payment authority and finance workflows
   inside companies, and the identity and approval controls
   around them lag the capability. Token Security's guidance and
   OpenAI's stand-in card both aim at the same problem: an agent
   that acts with a person's authority and no bounded
   credential.

4. FBI TIES ARTEX TO A CONNECTWISE SUPPLY-CHAIN BREACH
   AI Security · [ai, supply chain]
   Latest developments: The FBI warned on November 15, 2026 that
   attackers run ARTEX, the open-source AI penetration-testing
   framework, to automate attacks on organizations worldwide,
   and pointed to a recent ConnectWise supply-chain breach that
   compromised customers' Microsoft 365 environments as one
   result.
   ARTEX chains reconnaissance, exploitation, and follow-on
   actions with little operator skill, and the FBI's November
   13, 2026 flash alert clocked some intrusions from first
   targeting to privileged access in under three hours.
   Defenders should hunt for credential attacks running at
   machine speed and audit every remote monitoring and
   management tool, ConnectWise ScreenConnect included.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/fbi-warns-artex-ai-hacking-tool-is-powering-global-cyberattacks/

8. APPLE DETAILS SECURE EXCLAVES FOR CAMERA AND MIC
   Platform Security · [privacy, hardware]
   Latest developments: Apple published the architecture of
   Secure Exclaves, which isolates camera and microphone data
   from the main operating system on HomeView and the newest
   iPhones, so a compromise of iOS alone leaves ambient sensor
   data out of an attacker's reach.
   Secure Exclaves fence off the hardware that watches and
   listens, holding that data inside a separate execution
   environment the general-purpose operating system cannot
   reach. The design matters most for always-on home devices,
   where a single operating system flaw would otherwise open a
   live camera and microphone.
   - SecurityWeek: https://www.securityweek.com/apple-reveals-how-secure-exclaves-shield-camera-and-microphone-data/
