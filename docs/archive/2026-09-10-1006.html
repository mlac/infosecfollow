1. Ransomware Crews Hit WatchGuard, Fortinet, and Cisco Firewalls

Vulnerabilities and Exploits · [ransomware, patch, exploit]

Latest developments: CISA added three flaws to its Known Exploited Vulnerabilities catalog and gave federal civilian agencies until September 12, 2026 to patch them: the maximum-severity Cisco Secure Firewall Management Center authentication bypass CVE-2026-20079, the Citrix NetScaler authentication bypass CVE-2026-19490, which SecurityWeek dates to attacks running since at least September 3, 2026, and the Fortinet code execution flaw CVE-2025-25249, which attackers use to install a remote access trojan called PivotC2; Cisco Talos now tracks a second Secure Firewall Management Center bug, CVE-2026-20316, and puts both state-sponsored and financially motivated crews behind that exploitation; and CISA confirmed that ransomware gangs also exploit the critical WatchGuard Firebox remote code execution flaw it first flagged in December.

read more

Firewall and firewall-management products from WatchGuard, Fortinet, Citrix, and Cisco carry flaws that attackers exploit right now, and all four vendors shipped the fixes months ago. Apply the patches and comb every exposed appliance for accounts and web shells nobody recognizes.

Latest developments: Wiz Research reported that nearly one in ten internet-facing LiteLLM gateways it scanned in February 2026 accepted sk-1234, the example administrator key printed in LiteLLM's own setup guide; Palo Alto Networks' Unit 42 showed how root access on a single Kubernetes node lets an attacker read SPIFFE and SPIRE metadata and impersonate every workload identity sharing that node; and Dark Reading detailed workflow identity hijacking, which reaches enterprise data through an unauthenticated entry point and walks past standard controls.

read more
