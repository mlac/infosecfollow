4. MALICIOUS MCP SERVERS LIFT OAUTH SECRETS
   AI Security · [ai, identity, patch]
   Latest developments: The maintainers of the official Model
   Context Protocol Python SDK disclosed on September 29, 2026
   that affected versions send the client secret, the
   authorization code, and the PKCE proof key to whatever token
   endpoint a server names, so a hostile MCP server collects the
   credentials an application uses to log in to a real service,
   and shipped the fix in version 1.30.0; the same day Palo Alto
   Networks Unit 42 released OperTraitor, which audits the
   role-based access control privileges Kubernetes operators
   hold, and Palo Alto extended its work with Nvidia's Open
   Agent Safety Platform to police what agents reach.
   Agent infrastructure—MCP clients, Kubernetes operators,
   service identities—holds credentials and privileges that
   nobody reviews, and Dark Reading argues those agents now
   function as unmonitored privileged users. Upgrade the MCP
   Python SDK to 1.30.0 or later and inventory the non-human
   identities in your environment.
