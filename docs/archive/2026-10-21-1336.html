1. PHP2Shell Forces an Out-of-Cycle PHP Release

Vulnerabilities and Exploits · [zero-day, patch]

Latest developments: The patches landed at 14:00 UTC on October 21, 2026 in PHP 8.5.12, 8.4.27, 8.3.36, and 8.2.35, closing CVE-2026-109618 and CVE-2026-109619; CISA told organizations to patch immediately, SecurityWeek reported the first exploitation attempts reaching sensors, The Record counted hundreds of websites already taken offline, Brian Krebs put the share of sites needing the update near 70% and warned of a day of error pages, and Cisco Talos shipped Snort rules while Kaspersky added detection for the exploit.

read more

The two flaws, which the PHP security team rates 9.2 under CVSS v4.0, run an attacker's code on a web server with no login and reach every installation that serves web requests, among them PHP-FPM and Apache with mod_php. PHP underpins most of the public web, including WordPress, Drupal, Joomla, and Magento sites, so patch now and hunt for web shells on anything internet-facing.

read more
