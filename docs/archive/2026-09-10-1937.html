1. Ransomware Crews Hit WatchGuard, Fortinet, and Cisco Firewalls

Vulnerabilities and Exploits · [ransomware, patch, exploit]

Latest developments: Cisco Talos now ties exploitation of two Secure Firewall Management Center flaws, the maximum-severity authentication bypass CVE-2026-20079 and CVE-2026-20316, to three separate clusters covering ransomware crews and state-sponsored operators; CISA added CVE-2026-20079 to its Known Exploited Vulnerabilities catalog alongside the Citrix NetScaler authentication bypass CVE-2026-19490, which SecurityWeek dates to attacks running since at least September 3, 2026, and the Fortinet code execution flaw CVE-2025-25249, which attackers use to install a remote access trojan called PivotC2, and gave federal civilian agencies until September 12, 2026 to patch all three; CISA confirmed that ransomware gangs also exploit the critical WatchGuard Firebox remote code execution flaw it first flagged in December; and Check Point patched two 9.8-rated VPN certificate handling flaws in its Security Gateways and Security Management products that give an unauthenticated remote attacker code execution under conditions the company declines to describe.
