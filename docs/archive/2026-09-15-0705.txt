1. CISCO SECURE EMAIL GATEWAY ZERO-DAY HANDS ATTACKERS ROOT
   Vulnerabilities and Exploits · [zero-day, patch, kev]
   Latest developments: Cisco released the patch and confirmed
   active exploitation on September 15, 2026, detailing
   CVE-2026-76461 as a 9.8-rated failure to validate email
   parsing in AsyncOS that lets an unauthenticated remote
   attacker run arbitrary commands as root, a sharper account
   than the SQL injection entry CISA posted to its Known
   Exploited Vulnerabilities catalog a day earlier.
   Cisco Secure Email Gateway appliances handle inbound mail for
   large enterprises, and a crafted message reaches the
   underlying operating system with full privileges.
   Administrators should install the AsyncOS fix immediately and
   audit the appliances for unfamiliar accounts and outbound
   connections.

2. HIJACKED HBO MAX REDDIT ACCOUNT SPREADS CLICKFIX MALWARE
   Ransomware and Cybercrime · [clickfix, infostealer,
   malvertising]
   Latest developments: Attackers seized u/hbomax, the verified
   official Reddit account of HBO Max, and spent 48 hours
   running paid ads from it that sent macOS and Windows users to
   a ClickFix page, which talked them into pasting commands that
   installed information-stealing malware.
   ClickFix cons a victim into running the attacker's command on
   their own machine, and the stolen advertising status of a
   verified brand account supplies the trust the trick needs.
   Reddit users should treat any ad that asks them to run a
   terminal or Run-box command as an attack regardless of who
   posted it.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hackers-hijack-hbo-max-reddit-account-to-push-malware-in-clickfix-ads/
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/15/hbo-max-reddit-account-clickfix-infostealer-malware/

   Nation-State Activity · [apt, zero-day, espionage]
   Latest developments: Volexity reported on September 15, 2026
