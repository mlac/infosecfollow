1. JAVA4SHELL NARROWS TO AVX-512 CHIPS
   Vulnerabilities and Exploits · [zero-day, patch,
   vulnerability]
   Latest developments: Cisco Talos scored Java4Shell at 9.2
   under CVSS 4.0, and researchers pinned down its reach: the
   vulnerable code runs only on Java 17.0.6 and later and only
   on x86-64 Intel and AMD processors that support the AVX-512
   VBMI feature, with Calif demonstrating remote code execution
   against Jira, Jenkins, and Keycloak while VulnCheck says a
   working attack takes per-target engineering and no one has
   yet confirmed a successful intrusion.
   CVE-2026-114938 is an out-of-bounds write in the Base64
   decoder of OpenJDK that hands an unauthenticated attacker
   denial of service or code execution on Jenkins, Atlassian
   Jira, Confluence, Keycloak, and other Java servers reaching
   most of the Fortune 500. Oracle and the OpenJDK project
   released fixes on November 17, 2026, and CISA tells
   organizations to patch immediately.
   - Cisco Talos: https://blog.talosintelligence.com/java4shell/
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/18/java4shell-openjdk-vulnerability-cve-2026-114938/

2. PUPPET AND ROLLER FALL TO LIVE EXPLOITS
   Vulnerabilities and Exploits · [patch, exploited,
   vulnerability]
   Latest developments: CISA added four more exploited
   vulnerabilities to its Known Exploited Vulnerabilities
   catalog on November 18, 2026—CVE-2024-10441 in Synology
   DiskStation Manager, CVE-2026-40217 in BerriAI LiteLLM,
   CVE-2026-90436 in Apache Axis, and CVE-2026-90817 in
   Vanderbilt University's Research Electronic Data Capture
   platform—and the Apache Software Foundation identified the
   Roller bug under attack as CVE-2026-129448, an

   9.8; SecurityWeek spelled out the mechanism behind
   CVE-2026-115731, the Perforce Puppet flaw rated 9.4, in which

   certificate authority runs code on the server.
   Perforce Puppet runs configuration management across
   enterprise fleets, so code execution on the Puppet server
   reaches every managed host; Apache Roller is a Java blog
   server. Patch both now and pull Oracle's November 2026
   critical fixes, 62 of them critical out of 950 total.

3. POISONED AGENT FRAMEWORK STEALS CLOUD KEYS
   Software Supply Chain Security · [supply chain, credential
   theft, ai]
   Latest developments: Attackers published malicious versions
   1.26.1 and 1.26.2 of Microsoft's agent-framework package to
   PyPI 33 minutes apart on November 17, 2026, each one running
   a credential stealer every time Python starts and shipping
   out Azure, Azure DevOps, and GitHub Actions credentials, with
   Aikido, Chainguard, Endor Labs, OX Security, SafeDep, Socket,
   StepSecurity, and Wiz all reporting the compromise.
   agent-framework is Microsoft's Python library for building AI
   agents, and any developer or build pipeline that installed
   the two poisoned releases handed over its cloud and CI
   credentials. Pin and audit package versions, rotate Azure and
   GitHub Actions secrets, and check Docker Hub images for
   exposed keys, which researchers watched attackers extract
   within eight seconds of publication.
   - SecurityWeek: https://www.securityweek.com/microsoft-agent-framework-releases-poisoned-with-credential-stealer/

7. NGINX2ROOT AND F5 BIG-IP OPEN UNAUTHENTICATED ATTACKS
   Vulnerabilities and Exploits · [vulnerability, patch, web]
   Latest developments: F5 disclosed CVE-2026-123007, which
   researchers call nginx2root, a flaw that has sat in NGINX's
   open-source HTTP/2 code since version 1.9.5 shipped on
   September 22, 2015 and lets an attacker who never logs in run
   code on any server with HTTP/2 turned on, and released fixed
   versions 1.31.9 and 1.30.7 on November 18, 2026; the same day
   F5 published six critical BIG-IP bugs that crash the Traffic
   Management Microkernel without authentication and may run
   code, each one needing a virtual server configured with a
   particular iRule command or an Access Policy Manager policy
   carrying two specific agent types; the SANS Internet Storm
   Center explained why Java4Shell, nginx2root, and last week's
   Microsoft 365 outage together still left its Infocon below
   Yellow.
   NGINX serves or fronts a large share of the public web, and
   HTTP/2 ships enabled on many of those hosts, so nginx2root
   reaches far beyond the sites that run it deliberately.
   Upgrade NGINX to 1.31.9 or 1.30.7, inventory BIG-IP virtual
   servers for the iRule commands and APM agents F5 names, and
   apply F5's BIG-IP fixes.
   - The Hacker News: https://thehackernews.com/2026/11/10-year-old-nginx-http2-flaw-lets.html
   - The Hacker News: https://thehackernews.com/2026/11/f5-warns-6-critical-big-ip-flaws-can.html
   - SANS Internet Storm Center: https://isc.sans.edu/diary/rss/33532
