   Vulnerabilities and Exploits · [exploit, patch]
   Latest developments: CISA added three actively exploited
   flaws to its Known Exploited Vulnerabilities catalog on
   September 25, 2026: CVE-2026-65660, the SharePoint Server
   code injection bug that Dinh Ho Anh Khoa of Viettel Cyber
   Security showed gives an authenticated user remote code
   execution, CVE-2026-67279, the RouterOS SSH state-machine
   flaw that CERT Polska chained into the MikroTrick attack, and
   CVE-2026-87902, the WordPress core remote file inclusion

   password and no completed authentication. Federal agencies
   face patch deadlines under Binding Operational Directive
   26-04, and every operator of SharePoint Server 2016, 2019,
   Subscription Edition, RouterOS, WordPress, WSO2, or Magento
   should patch now.

10. STORM-3168 DRIVES AZURE ATTACKS THROUGH SERVICE PRINCIPALS
   AI Security · [apt, cloud, ai-agents]
   Latest developments: Microsoft published an analysis on
   September 25, 2026 attributing agentic cloud attacks to
   Storm-3168, which rides compromised Azure service principals
   to run reconnaissance, reach credentials, and delete
   resources, and tied the activity to the actor Microsoft
   tracks as JADEPUFFER.
   Service principals are the non-human identities Azure
   applications and automation use, and they carry standing
   permissions that survive employee departures and password
   resets. Microsoft's report lists hunting queries and defender
   guidance; tenant administrators should inventory every
   service principal, cut unused ones, and alert on resource
   deletion by application identities.
   - Microsoft Security Blog: https://www.microsoft.com/en-us/security/blog/2026/09/25/storm-3168-agentic-driven-cloud-attacks-using-compromised-service-principals/
