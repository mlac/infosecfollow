1. September Windows Updates Break Remote Desktop and USB Audio

Vulnerabilities and Exploits · [patch, windows, outage]

Latest developments: Microsoft shipped emergency out-of-band Windows updates late on September 14, 2026 that repair the Remote Desktop Services failures its September security updates caused, along with Hyper-V faults and the USB audio breakage that followed the KB5124008 and KB5124012 updates.

read more

The Remote Desktop failures block user connections on Windows Server 2019, 2022, and 2025, and some hosts recover only after a hard reset, fallout from a September rollup that fixed roughly 972 vulnerabilities. Administrators should install the out-of-band updates and retest remote access and audio hardware before they widen the September deployment.

6. Sandworm Chains Cisco Flaws to Deploy Cyclops Blink

Nation-State Activity · [apt, exploited, botnet]

Latest developments: Dark Reading named the operator on September 14, 2026: Russia's Sandworm group chains Cisco Secure Firewall Management Center vulnerabilities to spread an upgraded Cyclops Blink, the botnet malware the FBI disrupted in 2022, and CISA added a separate Cisco Secure Email Gateway SQL injection flaw, CVE-2026-76461, to its Known Exploited Vulnerabilities catalog the same day.

read more

Three intrusion clusters exploit CVE-2026-20079, the 10.0-rated authentication bypass in the Secure Firewall Management Center web interface, and CVE-2026-20316, stealing credentials and in some cases deploying Qilin ransomware. Anyone running Secure Firewall Management Center or Secure Email Gateway should patch now, rotate device credentials, and hunt for modular implants that survive reboots.

Nation-State Activity · [apt, exploited, supply chain]

Latest developments: Acronis Threat Research Unit reported on September 14, 2026 that the Chinese threat actor it tracks as Red Heron turned a recently disclosed Gitea remote code execution flaw against internet-facing servers within days, scanning 1,386 Gitea instances in seven countries, keeping a separate list of 477 systems in Taiwan, and breaking into 13 organizations across six countries.

read more
