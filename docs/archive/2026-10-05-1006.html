1. NetScaler Zero-Day Hits Freshly Patched Appliances

Vulnerabilities and Exploits · [zero-day, patch, exploit]

5. Cling Botnet Turns STUN Into Command and Control

Ransomware and Cybercrime · [malware, botnet, exploit]

Latest developments: Nozomi Networks reported on October 5, 2026 that attackers probing a patched critical flaw in the Realtek Jungle software development kit deliver Cling, a Linux back-connect proxy backdoor that researchers also call ClingSTUN, which hides its command and control inside ordinary STUN traffic and carries exploits for dozens of vulnerabilities to spread on its own.

read more

STUN is the protocol voice and video applications use to find a path through network address translation, and few defenders inspect it, so Cling's beacons pass as call setup.
