1. CISCO SECURE EMAIL GATEWAY ZERO-DAY HANDS ATTACKERS ROOT
   Vulnerabilities and Exploits · [zero-day, patch, kev]
   Latest developments: Cisco released the patch and confirmed
   active exploitation on September 15, 2026, detailing
   CVE-2026-76461 as a 9.8-rated failure to validate email
   parsing in AsyncOS versions 15.5, 16.0, and 16.5 that lets an
   unauthenticated remote attacker run arbitrary commands as
   root, published indicators of compromise for administrators
   to hunt with, and sharpened the SQL injection entry CISA
   posted to its Known Exploited Vulnerabilities catalog a day
   earlier.
   Cisco Secure Email Gateway appliances handle inbound mail for
   large enterprises, and a crafted message reaches the
   underlying operating system with full privileges.
   Administrators should install the AsyncOS fix immediately and
   audit the appliances for unfamiliar accounts and outbound
   connections.

   - The Hacker News: https://thehackernews.com/2026/09/cisco-secure-email-gateway-flaw.html

3. HIJACKED HBO MAX REDDIT ACCOUNT SPREADS CLICKFIX MALWARE
   Ransomware and Cybercrime · [clickfix, infostealer,
   malvertising]
   Latest developments: Attackers seized u/hbomax, the verified
   official Reddit account of HBO Max, and spent 48 hours
   running paid ads from it that sent macOS and Windows users to
   a ClickFix page, which talked them into pasting commands that

   terminal or Run-box command as an attack regardless of who
   posted it.
