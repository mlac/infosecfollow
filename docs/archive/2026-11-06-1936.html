1. Plex2Shell Hits QNAP as a WordPress Fix Opens a Window

Vulnerabilities and Exploits · [exploitation, patch]

Latest developments: SonicWall shipped updates on November 6, 2026 for seven SonicOS firewall flaws, among them CVE-2026-19868, a single-factor authentication weakness in SSL-VPN that attackers already use to walk past multifactor authentication, and CISA added that bug to its Known Exploited Vulnerabilities catalog the same day, binding federal agencies under Binding Operational Directive 26-04; QNAP told customers attackers are breaching its network-attached storage devices through the Plex2Shell vulnerability chain and pressed owners to install the newest Plex Media Server build from the QNAP App Center; and Umut Bayram, a researcher at Picus Security, reported that a WordPress site stays exposed while it installs the fix for the actively exploited core flaw, because the updater unpacks the new files using the site's old, unpatched code.

Internet-facing VPN gateways, storage appliances, and the WordPress patch process all give attackers a live path to code execution. Patch SonicOS at once, update Plex Media Server on QNAP devices, and block web access to WordPress sites for the seconds the core update runs.

2. Attackers Exploit the SSHole Bypass

Vulnerabilities and Exploits · [zero-day, patch, linux]

Latest developments: The threat intelligence firm Previdian warned on November 6, 2026 that attackers already exploit CVE-2026-123158, the OpenSSH flaw Wakefield researcher Ozgun Kultekin nicknamed sshole, hours after its disclosure and one day after OpenSSH shipped version 10.6p2, with one attempt reaching root on a honeypot; D-Link published mitigation steps the same day for multiple unpatched zero-days in its DGS-3130 series managed stackable switches; and Microsoft's fix for CVE-2026-83844, an out-of-bounds read in Windows Paint that allows remote code execution, reaches users only as Microsoft Store build 11.2609.401.0 and never through Windows Update.

read more

Install OpenSSH 10.6p2 or a distribution package built from it immediately, apply D-Link's mitigations for DGS-3130 switches, and update Paint from the Store.
