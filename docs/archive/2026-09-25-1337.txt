1. BITGET LOSES $351.6 MILLION TO SUSPECTED NORTH KOREAN HACKERS
   Nation-State Activity · [breach, apt, cryptocurrency]
   Latest developments: Bitget raised its loss estimate to $387
   million on September 25, 2026, named North Korea as the
   culprit, and said a User Protection Fund holding more than
   $464 million will cover customer losses; SecurityWeek
   reported that investigators froze some wallet addresses tied
   to the attacker, a day after the exchange's systems caught
   unauthorized transfers out of a limited number of hot wallets
   at 18:31 UTC on September 24, 2026.
   Bitget, a cryptocurrency exchange, lost funds from the hot
   and warm wallets it keeps online to serve customer
   withdrawals after attackers compromised its backend, and says
   cold wallets and the overwhelming majority of platform assets
   came through untouched. Exchanges holding warm wallets on
   internet-reachable infrastructure should re-examine signing
   controls and withdrawal limits.

2. FAKE INSTALLERS DELIVER SCREENCONNECT AND MACSYNC
   Ransomware and Cybercrime · [malware, stealer,
   social-engineering]
   Latest developments: Jamf Threat Labs flagged a new
   PamStealer build on September 25, 2026 that keeps its
   JavaScript for Automation dropper, swaps the lure and
   delivery method, and recovers its main payload only through a
   server-side decryption chain, layering persistence on macOS;
   Allure Security reported the same day that an attacker
   advertises desktop applications for three large United States
   payroll and human resources platforms that have never shipped
   one, and the installer plants ScreenConnect configured for
   silent remote control; Kaspersky traced the latest MacSync
   variant to a counterfeit cryptocurrency wallet called Toria,
   which runs its own website and draws traffic from X and
   Telegram.
   Ryan Merritt, director of security research at Allure
   Security, notes all three payroll providers deliver only web
   applications, so any downloadable client is a fake, and the
   MacSync variant steals credentials, wallet data, and files
   while pulling fresh payloads from public iCloud calendar
   events. Block installers for software that has no desktop
   edition and treat unsolicited wallet apps as hostile.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/25/fake-payroll-desktop-apps-screenconnect/
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/25/macsync-info-stealing-malware-for-macos/

3. SHAREPOINT AND MIKROTIK EXPLOITS REACH THE KEV CATALOG
   Vulnerabilities and Exploits · [exploit, patch]
   Latest developments: CISA added two actively exploited flaws
   to its Known Exploited Vulnerabilities catalog on September
   25, 2026: CVE-2026-65660, the SharePoint Server code
   injection bug that Dinh Ho Anh Khoa of Viettel Cyber Security
   showed gives an authenticated user remote code execution, and
   CVE-2026-67279, the RouterOS SSH state-machine flaw that CERT
   Polska chained into the MikroTrick attack; CISA and
   BleepingComputer also detailed attacks on CVE-2026-5430, a
   9.8-rated path traversal in WSO2 API Control Plane, and on
   CVE-2026-71362 in Adobe Commerce and Magento.
   Microsoft originally filed the SharePoint bug as a 6.5-rated
   spoofing issue, and MikroTrick hands an attacker
   administrative control of an internet-exposed router with no
   password and no completed authentication. Federal agencies
   face patch deadlines under Binding Operational Directive
   26-04, and every operator of SharePoint Server 2016, 2019,
   Subscription Edition, RouterOS, WSO2, or Magento should patch
   now.
   - CISA Advisories: https://www.cisa.gov/news-events/alerts/2026/09/25/cisa-adds-two-known-exploited-vulnerabilities-catalog

4. ROUNDCUBE WEBMAIL SQL INJECTION DRAWS LIVE ATTACKS
   Vulnerabilities and Exploits · [patch, exploit]
   Latest developments: Researchers pinned the Roundcube flaw
   the Canadian Centre for Cyber Security flagged to
   CVE-2026-48842, rated 8.1, a pre-authentication SQL injection
   in the virtuser_query plugin that traces to backslash
   handling in a preg_replace() call.
   The bug affects Roundcube Webmail 1.6.x before 1.6.16 and
   1.7.x before 1.7.1, and an attacker reaches it with no login
   before injecting code. Anyone running a self-hosted Roundcube
   server should install the May 2026 patch immediately.
   - The Hacker News: https://thehackernews.com/2026/09/roundcube-pre-auth-sql-injection-flaw.html

   Ransomware and Cybercrime · [supply-chain, malware]
