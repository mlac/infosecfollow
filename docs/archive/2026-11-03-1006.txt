9. STOLEN CLOUD ACCESS PAYS THE ATTACKER'S AI BILL
   AI Security · [ai, cloud, supply-chain]
   Latest developments: Google Threat Intelligence Group and
   Mandiant disclosed on November 3, 2026 that intruders who
   break into corporate cloud accounts run large language models
   at the victim's expense, a practice they call LLMJacking,
   with single-day charges above $100,000 and total bills
   reaching $1 million across incidents Mandiant handled in 2026
   at financial services and retail companies.
   Attackers monetize a stolen cloud credential by billing the
   owner for model inference, which shows up as a sudden spike
   in API requests rather than data theft. Separately, Glow Labs
   reviewed real AI coding sessions and found agents installing
   MCP servers from archived repositories that will never
   receive another patch, a pattern it names MCPhantom. Cap and
   alarm on model API spend, and pin the MCP packages your
   agents may install.

10. LINUX TCP AND ANDROID PATCHES LAND
   Vulnerabilities and Exploits · [patch, zero-day]
   Latest developments: Red Hat shipped fixed kernels on
   November 3, 2026 for CVE-2026-98432, the use-after-free in
   the Linux kernel's IPv4 TCP code rated 9.8 that a remote
   attacker with no credentials can reach, covering Red Hat
   Enterprise Linux 8, 9, and 10, while Ubuntu left its fixes
   for the three newest long-term-support releases in an opt-in
   testing channel with no date for a general update; Google's
   November 2026 Android updates closed more than 200
   vulnerabilities, the worst a critical remote code execution
   flaw in Framework that needs no user interaction.
   Anthropic researchers already built a working root exploit
   for the TCP flaw, which puts every unpatched internet-facing
   Linux server at risk. Administrators should take the Red Hat
   kernels now, watch for Ubuntu's general release, and push the
   Android November level to managed handsets.
