1. MikroTik Routers Fall to Unauthenticated SSH Attacks

Vulnerabilities and Exploits · [exploit, network, zero-day]

Latest developments: CERT Polska published an attack warning on September 5, 2026, reporting that attackers take full administrative control of MikroTik routers whose SSH service answers from the internet, with no authentication required and successful compromises dating to at least September 2, 2026.

read more

MikroTik routers sit at the edge of small-business, hosting, and branch-office networks, so administrative control hands an attacker traffic interception and a pivot into everything behind the device. CERT Polska has released no victim count; pull SSH off the public internet, limit management access to known addresses, and audit routers for added accounts, scripts, and scheduled tasks.

2. REVSTEALER Modules Kill Defender and Mine Crypto

Ransomware and Cybercrime · [malware, cryptomining]

Latest developments: Elastic Security Labs documented four previously unreported programs that ride along with REVSTEALER, an emerging Windows information stealer, and stay on the machine after the stealer deletes itself, among them ProManager, WinUpdate, and SoftManager; one of the four disables Windows Update and Microsoft Defender before launching a cryptocurrency miner.

read more

REVSTEALER harvests credentials and then erases its own binary, which has masked the persistent modules that remain behind on Windows hosts. Treat a REVSTEALER hit as an ongoing compromise, check whether Windows Update and Defender have been turned off, and hunt for the named components.

4. Researchers Catalog 39 Passkey Attacks

Identity and Access Management · [authentication, research]

Latest developments: The authentication vendor Token published 39 documented methods for compromising passkey-based logins, all of which abuse authentication prompts, synced credentials, enrollment, and account recovery while leaving FIDO2 cryptography intact.

read more

Passkeys close off password phishing and credential stuffing, and the surrounding workflows still decide who gets in. Organizations deploying passwordless authentication should harden enrollment and recovery paths, restrict credential syncing across devices, and treat prompt approval as an attackable step.
