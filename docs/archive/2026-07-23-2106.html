3. Chaos Ransomware Routes C2 Through the Victim's Browser

Ransomware and Cybercrime · [ransomware, malware]

Latest developments: Cisco Talos detailed msaRAT, a Rust implant it attributes to the Chaos ransomware group that never opens its own outbound connection but instead launches Chrome or Edge in headless mode, drives them through the Chrome DevTools Protocol, and tunnels command-and-control over a WebRTC channel that hides the attacker's IP from the victim.

read more

Found on a compromised Windows machine ahead of the encryptor, msaRAT enables arbitrary command execution while its traffic blends into ordinary browser activity. Defenders should watch for unexpected headless browser processes and DevTools debugging activity.
