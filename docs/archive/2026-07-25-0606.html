1. GitLab PoC Lets Authenticated Users Run Code as Git

Vulnerabilities and Exploits · [rce, patch, exploit]

Latest developments: Security researcher Yuhang Wu at depthfirst published a working proof-of-concept on July 25 that executes commands as git on an unpatched self-managed GitLab 18.11.3 server, triggered when an ordinary authenticated user commits two crafted Jupyter notebooks and requests their diff.

read more

The chain needs no administrator rights, no continuous-integration runner access, and no victim interaction, so any registered user can reach remote code execution on a vulnerable self-managed instance. Administrators running self-managed GitLab should patch immediately.

Latest developments: A threat actor installed the open-source Hermes AI agent on a rented server, switched off its permission prompts to run it in unattended YOLO mode, and pointed it at Thailand's Ministry of Finance, where it worked through the network on its own checking hosts for root access and hunting file systems.
