3. ClickFix Becomes the Leading Way In

Ransomware and Cybercrime · [phishing, malware, social-engineering]

Latest developments: CTM360 published a global count of 17,000 ClickFix URLs on September 24, 2026 and called the technique the most common route attackers take into enterprise networks, tracing it from a novelty in late 2023 to a subscription product with on-chain infrastructure and state-sponsored customers; Ax Sharma, head of research at Manifold Security, found that third-party.com, the documentation placeholder more than 1,700 code repositories reference, now shows Windows browsers a fake Cloudflare verification page and everyone else a harmless decoy; and researchers traced a campaign that injects the same fake Cloudflare pages into hacked Ukrainian business websites, where the lure copies a Windows Installer command to the clipboard and tells the visitor to paste it, delivering a previously undocumented information stealer called Psychedelic.

read more

ClickFix shows a visitor a fake verification or error prompt and talks them into copying a command into the Windows Run dialog, so the intrusion carries no exploit, no attachment, and no file on disk. CTM360 concludes that blocking malicious domains no longer defends anyone; restrict what users can paste into Run and watch PowerShell launched from explorer.exe.
