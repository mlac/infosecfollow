2. OpenSSL HollowByte Freezes Server Memory

Vulnerabilities and Exploits · [dos, patch]

Latest developments: Okta's Red Team disclosed HollowByte, a denial-of-service flaw that makes an unpatched OpenSSL server reserve up to 131 KB of memory for an 11-byte TLS request that never arrives, memory that stays gone on glibc systems until the process restarts.

read more

OpenSSL shipped the HollowByte fix in June with no CVE, advisory, or changelog note, so many administrators never learned to update, and unauthenticated attackers can exhaust server memory with tiny payloads. Rebuild against the patched OpenSSL.
