1. FRENCH SUPERMARKET FREEZERS DEFROSTED BY ATTACK
   Ransomware and Cybercrime · [ics, incident, retail]
   Latest developments: Attackers remotely shut down
   refrigeration at hundreds of French supermarkets overnight
   into Sunday, October 11, 2026, reaching Danfoss refrigeration
   controllers and spoiling chilled and frozen stock at stores
   run by several of France's largest grocery chains, BFMTV
   reported on October 12, 2026.
   The attack hit the industrial controllers that hold food at
   temperature, turning freezers warm and destroying inventory
   overnight across hundreds of locations. Grocers and
   cold-chain operators running Danfoss controllers should pull
   them off the open internet, rotate controller credentials,
   and alarm on temperature setpoint changes.

   Ransomware and Cybercrime · [supply chain, cryptocurrency,
   hardware]

3. SONICWALL FLAW DRAWS 135 EXPLOIT ATTEMPTS
   Vulnerabilities and Exploits · [exploit, vpn, patch]
   Latest developments: Researchers counted 135 exploitation
   attempts against CVE-2026-102255, the 10.0-rated

   Secure Mobile Access 1000 appliances, within days of the
   October 6, 2026 hotfix that SonicWall shipped while saying it

   appliances should install the hotfix and hunt for outbound
   requests the appliance made to internal hosts.

4. CERTIFICATE CLOCKS TIGHTEN FOR WEB AND WINDOWS
   Identity and Trust Infrastructure · [pki, patch, policy]
   Latest developments: Let's Encrypt said it will issue
   certificates valid for 64 days by default starting February
   10, 2027, down from 90 days and ahead of a later move to 45
   days, with the last 90-day certificate expiring May 11, 2027
   and no revocations during the transition; Microsoft
   separately told customers to patch Windows before the
   certificates that authenticate Windows Update servers expire
   on May 17 or June 19, 2027, depending on the Windows version.
   Shorter web certificate lifetimes make manual renewal
   untenable and force teams onto automated ACME issuance, while
   Windows devices that miss Microsoft's certificate rotation
   updates will lose access to Windows Update and the security
   fixes it delivers. Subscribers already on Let's Encrypt's
   45-day or 6-day certificates see no change; Windows
   administrators should confirm machines take the rotation
   updates well before May 2027.

8. GITLAB REGEX COMPILER OPENS REMOTE CODE EXECUTION
   Vulnerabilities and Exploits · [patch, devops, exploit]
   Latest developments: GitLab told customers on October 12,
   2026 to patch immediately a maximum-severity vulnerability in
   its CI/CD Regular Expression Compiler that lets a remote
   attacker run arbitrary code on a targeted instance.
   The compiler parses regular expressions inside GitLab
   pipeline configuration, so the flaw sits in the path every
   CI/CD job travels and reaches the source code, build secrets,
   and deployment credentials a GitLab instance holds.
   Administrators of self-managed GitLab should apply the fix
   now and review pipeline logs and runner hosts for unexpected
   job execution.
