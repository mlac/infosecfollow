   Vulnerabilities and Exploits · [firmware, patch]
   Latest developments: Firmware security firm Binarly disclosed
   six new flaws July 10, 2026 in the U-Boot bootloader; four
   can crash a device, and two let an attacker who plants a
   malicious image run code before the device boots, opening the
   door to stealthy, persistent firmware implants.
   U-Boot starts the hardware inside home routers, smart
