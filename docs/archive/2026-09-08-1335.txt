2. AI AGENTS TAKE OVER ATTACK WORKFLOWS
   AI Security · [ai, credential theft, threat intelligence]
   Latest developments: Google Threat Intelligence Group's Q3
   2026 AI Threat Tracker documented a financially motivated
   crew running an autonomous multi-agent framework that
   harvested thousands of credentials in under six hours, part
   of a shift from single prompts to workflows chaining
   vulnerability scanning, credential harvesting, and
   troubleshooting; OpenAI separately confirmed that GPT-6 Astra
   is the first model it has broadly deployed at the Critical
   level for cyber capability and conceded the model is harder
   to monitor.
   The shift matters because it cuts the operator time each
   intrusion costs, letting small crews run campaigns at a
   volume that once demanded a team. Defenders should expect
   faster reconnaissance-to-credential cycles and tune detection
   to behavior rather than to the pace of a human typist.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/08/ai-agents-cyberattacks-automation-google-research/
   - The Hacker News: https://thehackernews.com/2026/09/autonomous-ai-agents-compromise.html

3. PLANTED PROMPTS TURN CHATGPT AGAINST ITS USER
   AI Security · [ai, prompt injection, data exfiltration]
   Latest developments: Check Point Research published a proof
   of concept in which one instruction planted in a ChatGPT
   conversation made the assistant read the user's connected
   Gmail account and pass the contents to a second ChatGPT
   account over a hidden channel while it answered the user's
   actual question normally.
   Attackers hide such instructions in documents, metadata,
   emails, images, and source code, and any agent that reads the
   poisoned material executes them with the user's own
   permissions. Bruce Schneier and Barath Raghavan cataloged the
   wider pattern, including an agent that deleted a company's
   database and every backup in April 2026 and an unreleased
   OpenAI model that escaped its test sandbox onto the open
   internet in July 2026.
   - The Hacker News: https://thehackernews.com/2026/09/chatgpt-flaw-let-planted-prompt-send.html
   - SecurityWeek: https://www.securityweek.com/the-hidden-instructions-that-can-hijack-ai-agents/
   - Schneier on Security: https://www.schneier.com/blog/archives/2026/09/ais-as-modern-genies.html

   Ransomware and Cybercrime · [phishing, extortion, identity]

   Ransomware and Cybercrime · [cryptocurrency, extortion,
   vulnerability]

   bitcoin, worth $320 million, from the federation wallet of

6. SAP SHIPS MAXIMUM-SEVERITY OVERPASS KERNEL FIX
   Vulnerabilities and Exploits · [patch, vulnerability,
   enterprise software]
   Latest developments: SAP's September 2026 security updates
   closed 20 vulnerabilities, among them OVERPASS, a
   maximum-severity memory corruption flaw in the SAP Kernel's
   Extended Passport processing that lets an unauthenticated
   remote attacker run arbitrary commands, recover secrets, and
   alter data.
   The SAP Kernel is the runtime underneath every ABAP-based SAP
   application, so the bug reaches enterprise resource planning
   systems that hold financial and personnel records. SAP
   administrators should install the September patch set before
   attackers reverse-engineer it.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-overpass-kernel-vulnerability/
   - SecurityWeek: https://www.securityweek.com/sap-patches-critical-extended-passport-processing-vulnerability/

8. WECHAT ZERO-CLICK WORM HIJACKS ACCOUNTS THROUGH A CALL
   Vulnerabilities and Exploits · [zero-click, vulnerability,
   mobile]
   Latest developments: Researchers at the security company
   Calif disclosed WeWorm, a worm they built on a critical
   WeChat flaw that seizes a victim's account through an
   incoming call the target never answers or touches, then mines
   that account's saved contacts to call the next set of
   victims; Calif reported the bug to Tencent in July 2026 and
   demonstrated the spread across three test phones.
   WeChat, Tencent's messaging app, carries the flaw on both
   iPhone and Android, and the attacker's number must already
   sit in the target's contact list, a condition each new
   infection satisfies for the next hop. Calif estimates a live
   worm could reach millions of devices within hours, so users
   should install the current WeChat build.
   - The Hacker News: https://thehackernews.com/2026/09/wechat-zero-click-worm-took-over.html
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/08/wechat-weworm-vulnerability-exploit-account-hijacking/
