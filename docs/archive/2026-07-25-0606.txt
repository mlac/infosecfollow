1. GITLAB POC LETS AUTHENTICATED USERS RUN CODE AS GIT
   Vulnerabilities and Exploits · [rce, patch, exploit]
   Latest developments: Security researcher Yuhang Wu at
   depthfirst published a working proof-of-concept on July 25
   that executes commands as git on an unpatched self-managed
   GitLab 18.11.3 server, triggered when an ordinary
   authenticated user commits two crafted Jupyter notebooks and
   requests their diff.
   The chain needs no administrator rights, no
   continuous-integration runner access, and no victim
   interaction, so any registered user can reach remote code
   execution on a vulnerable self-managed instance.
   Administrators running self-managed GitLab should patch
   immediately.
   - The Hacker News: https://thehackernews.com/2026/07/researcher-publishes-gitlab-rce-poc.html

   AI Security · [ai, apt, breach]

   Vulnerabilities and Exploits · [zero-day, rce, patch]

   affected workers.
