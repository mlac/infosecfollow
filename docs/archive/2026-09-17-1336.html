4. Unbound and BIND 9 Patch Critical Resolver Flaws

Vulnerabilities and Exploits · [patch, dns, rce]

Latest developments: NLnet Labs disclosed CVE-2026-81642 on September 16, 2026, a critical heap overflow in the DNSSEC validator that every Unbound release before 1.26.1 carries, which an attacker who controls a malicious zone and queries the resolver turns into remote code execution, and shipped 1.26.1 the same day; the Internet Systems Consortium released BIND 9.20.29 and 9.21.26 to fix 14 flaws, one of which lets a sender with no credentials crash the named process with a single DNS-over-HTTPS request carrying an invalid SIG record.

read more

Unbound and BIND 9 resolve DNS queries for internet service providers, enterprises, and hosting companies worldwide, and a crash or code execution there takes down name resolution for everything behind it. Operators should upgrade to Unbound 1.26.1 and the current BIND 9 releases now.
