1. PHP2SHELL FORCES AN OUT-OF-CYCLE PHP RELEASE
   Vulnerabilities and Exploits · [zero-day, patch]
   Latest developments: The PHP security team scheduled an
   emergency release for 14:00 UTC on October 21, 2026 to close
   CVE-2026-109618 and CVE-2026-109619, each rated 9.2 under
   CVSS v4.0, after details of both flaws leaked ahead of the
   planned disclosure and an unconfirmed report described a
   working exploit, nicknamed PHP2Shell, that runs code on a PHP
   site without credentials.
   PHP's maintainers have withheld any description of the two
   bugs and the affected version numbers until the release
   lands, so administrators should treat every installation they
   run as vulnerable and stand ready to patch the moment the
   advisory publishes. PHP underpins the majority of the public
   web, including WordPress, Drupal, and Magento deployments.
   - SecurityWeek: https://www.securityweek.com/php2shell-mass-exploitation-looms-for-leaked-critical-php-flaws/
   - The Hacker News: https://thehackernews.com/2026/10/php2shell-two-unpatched-critical-php.html

   rotate every secret stored on that machine, and WordPress
   administrators should revoke and reissue Updraft keys.

4. EMUDHRA KEYS FELL TO WEAK CRYPTOGRAPHY
   Vulnerabilities and Exploits · [certificates, patch]
   Latest developments: The explanation arrived: researchers
   found the private keys behind eight eMudhra intermediate
   certificates weak enough to recover almost instantly, which
   would let anyone mint a trusted certificate for any website,
   and the Indian certificate authority revoked all eight.
   Google, Mozilla, Apple, and the Go project blocked the eight
   keys on October 20, 2026, and Go releases 1.27.3 and 1.26.10
   reject any chain that passes through them. Organizations
   running their own trust stores, pinning, or older Go binaries
   should push the blocks and the updated releases themselves.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/mozilla-google-apple-block-compromised-emudhra-ca-certificates/
   - Ars Technica Security: https://arstechnica.com/security/2026/10/the-internet-goes-on-high-alert-after-discovery-of-8-compromised-tls-certs/

6. LAZARUS AND CYBER PARTISANS RIDE TRUSTED SOFTWARE
   Nation-State Activity · [apt, backdoor]
   Latest developments: Kaspersky detailed Operation FlashHole
   on October 21, 2026, a North Korean Lazarus campaign that
   pairs watering-hole compromises with abuse of CrossWeb EX,
   the financial security software South Korean banking
   customers install to transact; separately, the Russian firm
   Solar reported that the Belarus-aligned hacktivist group
   Partisan Zmiy, also called Cyber Partisans, spent nearly two
   years inside a Russian healthcare organization's network
   hiding a backdoor named Vasilek inside VMware Tools.
   Both crews hid their malware in software that security teams
   whitelist by default, a pattern Cisco Talos quantified the
   same week in counting abuse of more than 25 legitimate
   collaboration, file-sharing, and payment platforms as malware
   delivery channels over the past year. Defenders should watch
   signed and sanctioned software for unexpected child processes
   and outbound connections.
