2. AI-FOUND REJETTO HFS FLAW UNDER ATTACK
   Vulnerabilities and Exploits · [exploit, ai, patch]
   Latest developments: VulnCheck reported on October 5, 2026
   that attackers are probing CVE-2026-61500, the 9.3-rated
   session forgery flaw in Rejetto HTTP File Server that an AI
   system discovered, where a weak pseudo-random number
   generator hands an attacker a predictable session-cookie
   signing key.
   Rejetto HFS is a small Windows file server that
   administrators and hobbyists expose straight to the internet.
   Whoever recovers the signing key forges an administrator
   session and runs code on the host, so upgrade the software or
   take the server off the internet.
   - SecurityWeek: https://www.securityweek.com/exploitation-hits-rejetto-hfs-vulnerability-discovered-by-ai/
   - The Hacker News: https://thehackernews.com/2026/10/attackers-target-rejetto-hfs-flaw-that.html

3. GOOGLE FREEZES ITS OPEN-SOURCE BUG BOUNTY
   AI Security · [ai, bug-bounty, policy]
   Latest developments: Google's rules page states that as of
   October 1, 2026 the Open Source Software Vulnerability
   Rewards Program accepts no further product vulnerability
   reports, a pause the company blames on a surge of automated,
   AI-generated submissions that swamped the engineers and
   open-source maintainers who triage them.
   OSS VRP pays researchers for flaws in Google's open-source
   projects and the ecosystem around them. Volunteer maintainers
   now absorb the triage cost of machine-written reports that
   amount to noise, and legitimate researchers lose a payout
   channel while the pause holds.
   - BleepingComputer: https://www.bleepingcomputer.com/news/google/google-halts-open-source-bug-bounty-program-amid-ai-spam-surge/
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/05/google-ai-generated-vulnerability-reports-pause/

4. OUT-OF-BAND EXCHANGE FIX FOR CVE-2026-96940
   Vulnerabilities and Exploits · [patch, vulnerability]
   Latest developments: Microsoft shipped an out-of-band update
   on October 5, 2026 for CVE-2026-96940, a high-severity
   Exchange Server flaw that lets an authenticated attacker read
   the email and attachments of other users in the same
   organization; the Exchange Server Team found the bug
   internally and sees no active exploitation.
   The flaw stops at tenant boundaries, so an attacker reaches
   mailboxes only inside an organization where they already hold
   an account. Microsoft considers the risk high enough to break
   its patch schedule, and administrators should install the
   update now.
