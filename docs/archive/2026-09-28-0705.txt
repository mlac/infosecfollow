1. CITRIX NETSCALER ZERO-DAYS DRAW A WEDNESDAY DEADLINE
   Vulnerabilities and Exploits · [zero-day, patch, kev]
   Latest developments: Help Net Security reported on September
   28, 2026 that attackers exploited CVE-2026-88771 and
   CVE-2026-88772 for weeks before the disclosure, planting
   webshells on the appliances they reached; warnings from the
   Dutch National Cyber Security Center reached IT suppliers and
   surfaced as Reddit rumors on Friday, September 25, 2026, and
   CISA ordered federal agencies to patch by Wednesday,
   September 30, 2026.
   CVE-2026-88771, an improper input validation flaw rated 9.5,
   and CVE-2026-88772, a memory buffer flaw, each give an
   unauthenticated attacker remote code execution on NetScaler
   ADC and NetScaler Gateway. Citrix shipped fixes for both plus
   six more bugs running through CVE-2026-88778; anyone running
   an affected version should patch and hunt for webshells.
