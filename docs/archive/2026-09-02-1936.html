1. SonicWall SMA1000 Zero-Days Chained in Attacks

Vulnerabilities and Exploits · [zero-day, vpn, patch]

Latest developments: SonicWall shipped updates for two zero-days its own researchers William Perry and Adam Babis found in Secure Mobile Access 1000 appliances—CVE-2026-83548, a pre-authentication server-side request forgery in the Appliance Management Console rated a perfect 10.0, and CVE-2026-83549—and confirmed attackers already chain the pair for unauthenticated remote code execution, a finding Sophos corroborated.

read more

SMA 1000 appliances serve as SSL VPN gateways for medium and large enterprises, government agencies, and managed security service providers, putting the flaws directly on the network edge. Administrators should patch immediately and hunt for compromise on any internet-facing instance.

Sources: The Hacker News · BleepingComputer · Sophos News · Help Net Security · ↑ top

2. Switchvox, Cleo, and GeoNetwork Flaws Open Servers

Vulnerabilities and Exploits · [exploitation, patch, rce]

Latest developments: A threat actor began exploiting CVE-2026-9586, a critical unauthenticated SQL injection in Sangoma Switchvox SMB Edition 8.3 rated 9.3, to plant reverse shells on internet-exposed VoIP systems; CISA added that bug to its Known Exploited Vulnerabilities catalog alongside six others, among them JFrog Artifactory's CVE-2026-82329, which attackers now abuse to forge administrative tokens, LiteLLM's CVE-2026-59822, Kestra OSS command injection CVE-2026-49869, and Starlette request smuggling CVE-2026-48710; and an SQL injection hole in the All-in-One WP Migration and Backup plugin left millions of WordPress sites open to unauthenticated remote code execution.

read more

These products sit on the internet edge at small businesses, file-transfer operations, hosting providers, and government agencies. Switchvox operators should hunt for compromise now, WordPress administrators should update the migration plugin, Cleo Harmony users should apply the vendor fix for the authentication bypass a public exploit now targets, and GeoNetwork administrators should move to version 4.4.12 or 4.2.17, released July 8, 2026.

3. BGP Hijack Poisons Virtualizor and Softaculous Updates

Vulnerabilities and Exploits · [supply-chain, bgp, malware]

Latest developments: Virtualizor disclosed that attackers hijacked Border Gateway Protocol routing for Softaculous's update servers, presented a technically valid TLS certificate for the domains, and delivered a booby-trapped Virtualizor package that planted persistent root access, with one hosting provider finding 5 of 34 checked hypervisors compromised in a window that opened August 28, 2026, at 20:57.

read more

Virtualizor is VPS management software from Softaculous that runs on hypervisors, and the routing attack turned its update channel into a malware delivery pipe; operators should audit hypervisors for compromise and rebuild affected hosts.

4. Sality Botnet Disrupted After 23 Years

Ransomware and Cybercrime · [botnet, takedown, malware]

Latest developments: The Justice Department announced that authorities in the United States, Bulgaria, Hungary, and Romania, working with CrowdStrike and the Shadowserver Foundation, executed a takedown on August 31, 2026, manipulating Sality's peer lists and seizing its payload URLs to sever more than 15,000 infected machines from their operator.

read more

Sality surfaced in 2003 as a file-infecting virus and grew into a peer-to-peer botnet that rented infected Windows machines for further malware delivery. Owners of affected computers should scan for and remove file-infector remnants, since the sinkhole stops new payloads without cleaning hosts.

Sources: The Record · The Hacker News · Help Net Security · BleepingComputer · ↑ top

9. Malicious Git Configs Hijack AI Coding Agents

AI Security · [ai, supply-chain, agentic]

Latest developments: Manifold Security disclosed eight flaws across seven command-line AI coding agents, among them Claude, Codex, and Cursor, in which a repository's own Git configuration names a command that the agent executes as the user, outside its sandbox and without an approval prompt, and four of the eight remained unpatched at publication.

read more

Cloning an attacker-controlled repository is enough to trigger the code execution, so the risk lands on any developer who points an agent at untrusted source. Teams should update agents where fixes exist and treat repository clones as untrusted input.
