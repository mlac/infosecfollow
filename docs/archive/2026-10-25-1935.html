2. PHP2Shell Reaches a European Government

Vulnerabilities and Exploits · [zero-day, patch, ai]

Latest developments: The Hacker News reported on October 25, 2026 that attackers exploited CVE-2026-109618 and CVE-2026-109619 against a government entity in Europe and then drove agentic AI platforms through the post-exploitation work, reaching password hashes and multifactor authentication material within two hours of the initial break-in, while global scanning for both flaws continues.

read more

The two PHP2Shell flaws, each rated 9.2 under CVSS v4, run an attacker's code on web servers, and the PHP Foundation patched them on October 21, 2026 in PHP 8.5.12, 8.4.27, 8.3.36, and 8.2.35. Anyone still running an unpatched interpreter should patch now and hunt for credential access and new authentication factors rather than wait for scanning to turn into a confirmed compromise.

3. Agents Watching Agents Draw Doubts

AI Security · [ai, insider threat]

Latest developments: Dark Reading examined Microsoft's Project Perception on October 23, 2026, which adds Guardian Agents that monitor and contain AI agents behaving anomalously, and reported the objection that policing unpredictable agents with other agents may compound the very risk it aims to contain; SecurityWeek separately reported that banks have begun spotting rogue AI agents inside their own environments.

Microsoft treats an AI agent as an insider and tightens its permissions the moment its activity strays from its assigned job. 4. A Downloads Folder File Hijacks Coding Agents

AI Security · [ai, supply chain]

Latest developments: Researchers found a malicious AGENTS.md instruction file sitting in a customer's Downloads folder that steered an AI coding agent into installing a rogue npm package, BleepingComputer reported on October 25, 2026.

read more

Coding agents read AGENTS.md files as standing instructions, so any such file an attacker places on disk—through a download, an email attachment, or a cloned repository—becomes a command the agent follows without a prompt from its owner. Teams running coding agents should restrict which directories an agent reads instructions from and require human approval before any package install.

Vulnerabilities and Exploits · [vulnerability, privilege escalation]

Latest developments: A researcher published findings this week, covered by The Hacker News on October 25, 2026, showing that one compromised device on a Tailscale network can take root on other servers it reaches, and Tailscale has shipped no fix.

read more

The attack needs Tailscale SSH configured to allow port forwarding plus control of a single device that the network's access rules already permit to connect to the target.
