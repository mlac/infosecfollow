1. HOLLOWBYTE FREEZES OPENSSL SERVER MEMORY
   Vulnerabilities and Exploits · [vulnerability, dos, patch]
   Latest developments: Okta's Red Team, which found and named
   the denial-of-service bug, published HollowByte's details on
   July 17, 2026, revealing that OpenSSL had quietly shipped the
   fix in June with no CVE, advisory, or changelog entry.
   HollowByte lets an unauthenticated attacker send an 11-byte
   TLS request that makes an OpenSSL server reserve up to 131 KB
   of memory for a message that never arrives, and on glibc
   systems that memory stays gone until the process restarts.
   Any organization running an unpatched OpenSSL server faces
   denial of service and should apply the June fix.
   - The Hacker News: https://thehackernews.com/2026/07/openssl-hollowbyte-flaw-could-freeze.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hollowbyte-ddos-flaw-bloats-openssl-server-memory-with-11-byte-payload/

3. SPIRALS RANSOMWARE ENCRYPTS IN UNDER 24 HOURS
   Ransomware and Cybercrime · [ransomware]
   Latest developments: Symantec's Threat Hunter Team disclosed
   Spirals, a previously unknown Rust ransomware that attackers
   deployed last month against an IT services company in South
   Asia, moving from initial access to data theft and full
   encryption in under 24 hours.
   Spirals encrypts each file with a separate AES-128 key
   wrapped by an attacker-controlled ECDH key, making recovery
   without the operator impossible. The speed leaves defenders
   little time to detect and respond.
   - Help Net Security: https://www.helpnetsecurity.com/2026/07/17/spirals-ransomware-south-asia/
