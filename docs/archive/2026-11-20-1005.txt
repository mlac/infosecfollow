1. ARMORY CASTLE OWNS THE VCENTER ZERO-DAY
   Nation-State Activity · [zero-day, apt, patch]
   Latest developments: Google Threat Intelligence Group
   attributed the zero-day exploitation of CVE-2026-123890 to
   Armory Castle, the suspected China-nexus espionage group
   formerly tracked as UNC5221, which has used the
   authentication bypass since at least early September
   2026—more than two months before Broadcom released a fix—to
   take administrative sessions on vCenter Server and steal
   data.
   CVE-2026-123890, rated 9.8, lets a remote, unauthenticated
   attacker bypass authentication in the VMware Directory
   Service and seize vCenter, the console that manages an
   organization's ESX hosts and virtual machines. Broadcom has
   shipped fixed builds for every supported branch and lists no
   workaround, so patch now and hunt for September activity.
   - The Hacker News: https://thehackernews.com/2026/11/china-linked-hackers-exploit-critical.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/vmware-patches-vcenter-zero-day-exploited-in-attacks-since-september/

3. F5, RUBY, AND SONICWALL FORCE AN EDGE PATCH CYCLE
   Vulnerabilities and Exploits · [patch, zero-day, end-of-life]
   Latest developments: F5 issued emergency patches for five
   critical BIG-IP flaws that attackers can drive into denial of
   service or remote code execution, Ruby fixed CVE-2026-132825,
   a heap-based buffer overflow that researchers call Ruby2Shell
   and that can carry an attacker to code execution, and
   SonicWall told every Gen 6 firewall owner to retire the
   hardware immediately because automated, AI-assisted scanning
   finds unsupported edge devices faster than ever.
   BIG-IP sits in front of corporate applications, Ruby runs the
   web stack behind many of them, and SonicOS 6.x now receives
   no firmware or security updates at any severity. Patch BIG-IP
   and Ruby, and pull Gen 6 and Gen 6.5 appliances off the
   internet edge.

5. CISCO EXPRESSWAY FALLS TO A PUBLIC PROOF OF CONCEPT
   Vulnerabilities and Exploits · [exploitation, patch]
   Latest developments: Attackers exploited CVE-2026-76466, the
   Cisco Expressway flaw rated 9.8, within days of a public
   proof of concept, breaching four clustered devices at a
   Russian organization, reaching the internal network, and
   staging tooling for lateral movement.
   Expressway carries video calls and collaboration traffic at
   the network edge, and the bug hands an unauthenticated
   attacker with network access a way past authentication. Patch
   every node, then inspect clustered peers for attacker
   tooling, because compromising one member of a cluster exposes
   the rest.
   - The Hacker News: https://thehackernews.com/2026/11/hackers-exploit-critical-cisco.html

6. LINUX KVM HANDS GUESTS THE HOST'S MEMORY
   Vulnerabilities and Exploits · [cloud, patch]
   Latest developments: Researchers used CVE-2026-99312, a flaw
   in KVM, the hypervisor built into the Linux kernel, to read
   roughly 127 gigabytes of a DigitalOcean server's memory from
   inside a virtual machine of their own, which on a shared host
   can include other customers' virtual machines.
   The flaw reaches only hosts running AMD processors with
   nested virtualization turned on, and fixed kernels have
   shipped. Cloud operators and anyone running their own KVM
   hypervisors should roll out the patched kernels and turn off
   nested virtualization where no workload needs it.
   - The Hacker News: https://thehackernews.com/2026/11/new-linux-kvm-flaw-cve-2026-99312-lets.html

8. FASTUNLOCK RUNS PROGRAMS ON A LOCKED WINDOWS PC
   Vulnerabilities and Exploits · [zero-day, windows,
   physical-access]
   Latest developments: A researcher who uses the handles
   MSNightmare and Nightmare Eclipse published FastUnlock on
   November 19, 2026, an unpatched technique that lets anyone
   holding a locked Windows computer start programs without
   signing in, and the endpoint security firm ThreatLocker
   confirmed the method works.
   FastUnlock needs physical access and yields only a limited
   account rather than administrator control, so it suits a
   thief or an insider with a stolen laptop. The same researcher
   published the SignDrop Windows zero-day a week earlier;
   Microsoft has no fix out for either, which leaves full-disk
   encryption and device-recovery procedures carrying the
   weight.
   - The Hacker News: https://thehackernews.com/2026/11/new-unpatched-windows-0-day-fastunlock.html

9. ROMULUS CLICKFIX DELIVERS A NEW REMOTE ACCESS TROJAN
   Ransomware and Cybercrime · [malware, social-engineering,
   rat]
   Latest developments: Blackpoint researchers reported that the
   ROMULUS ClickFix platform now drops a previously undocumented
   remote access trojan that spies on users and controls their
   PCs, and that ROMULUS runs as a delivery service pushing
   CNCMachineRMS and Legion Loader through separate chains.
   ClickFix lures a user into pasting a command that supposedly
   fixes a broken page, and ROMULUS pairs that trick with signed
   binary sideloading to get its payloads past endpoint
   controls. The new trojan resembles CNCMachineRMS; defenders
   should block clipboard-to-run-dialog behavior and audit which
   signed binaries load unexpected libraries.
   - The Hacker News: https://thehackernews.com/2026/11/romulus-clickfix-attacks-deliver-rat.html
