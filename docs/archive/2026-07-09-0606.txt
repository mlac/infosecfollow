1. AI CODING AGENTS TURNED INTO ATTACK SURFACE
   AI Security · [ai, supply-chain, zero-day]
   Latest developments: Wiz disclosed GhostApproval on July 9, a
   symlink flaw across six AI coding assistants—Amazon Q
   Developer, Anthropic's Claude Code, Augment, Cursor, Google
   Antigravity, and Windsurf—that redirects an approved write
   onto a sensitive file and hands a booby-trapped repository
   control of the developer's machine, the same day the AI Now
   Institute's Friendly Fire proof-of-concept tricked Claude
   Code and OpenAI's Codex into running attacker code while
   scanning it and researchers unveiled HalluSquatting, which
   pre-registers the fake package names AI assistants reliably
   invent to serve botnet malware.
   AI coding agents load skills, packages, and whole
   repositories with little vetting, and every channel now
   carries an exploit; teams running these tools in autonomous
   mode should restrict file writes, pin dependencies, and treat
   agent self-approvals as untrusted.
