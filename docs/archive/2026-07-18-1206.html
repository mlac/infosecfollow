Vulnerabilities and Exploits · [dos, patch, vulnerability]

Latest developments: Okta's Red Team disclosed HollowByte, showing an 11-byte TLS request forces an unpatched OpenSSL server to reserve up to 131 KB of memory for a message that never arrives, memory that stays gone on glibc systems until the process restarts.
