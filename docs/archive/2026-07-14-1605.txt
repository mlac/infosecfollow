6. OLD SIGNED SHIMS REOPEN THE UEFI SECURE BOOT BYPASS
   Vulnerabilities and Exploits · [vulnerability, patch]
   Latest developments: ESET researchers disclosed on July 14,
   2026 that 11 old Microsoft-signed Linux UEFI shims, all
   version 0.9 or below, let attackers run untrusted code during
   boot and plant bootkits on most Secure Boot systems;
   Microsoft revoked them in its June update.
   A shim is a small first-stage loader Microsoft signs so Linux
   and boot tools launch under Secure Boot. Because nearly every
   UEFI machine trusts that certificate, the vulnerable shims
   undo the protection; the number of systems still carrying
   them is unknown, so administrators should apply the
   revocation and firmware updates.
   - The Hacker News: https://thehackernews.com/2026/07/11-old-microsoft-signed-linux-uefi.html
   - Help Net Security: https://www.helpnetsecurity.com/2026/07/14/eset-uefi-secure-boot-bypass/
