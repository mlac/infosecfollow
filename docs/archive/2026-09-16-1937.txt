   AI Security · [ai, breach, supply chain]

   received notification of an attack that an AI agent running
   on a known large language model carried out, chaining a
   successful login, vulnerability discovery, and access to
   personal data, which SecurityWeek calls the first agentic AI

   assistant installs a dependency.

10. KREMLIN TOOLKIT FORCE-INSTALLS BROWSER EXTENSIONS
   Ransomware and Cybercrime · [malware, credential theft]
   Latest developments: BleepingComputer detailed KREMLIN on
   September 16, 2026, a toolkit a banking malware operation has
   run since mid-2025 that walks past browser installation
   checks to force malicious Chrome and Edge extensions onto
   infected machines, where the extensions steal credentials,
   session tokens, and other sensitive data; Palo Alto Networks'
   Unit 42 published fresh Atomic macOS Stealer activity in
   which deceptive setup guides talk Mac users into surrendering
   credentials; and Bruce Schneier flagged a fake CAPTCHA
   variant that persuades people to download and run the
   malicious program themselves.
   Stolen session tokens survive a password reset and skip the
   multi-factor prompt, which is why extension-based theft pays.
   Block unmanaged extension installation through browser
   policy, revoke sessions after any infostealer detection, and
   tell staff that a CAPTCHA asking them to paste a command into
   a terminal is an attack.
