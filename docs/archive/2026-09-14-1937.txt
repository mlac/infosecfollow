   Nation-State Activity · [apt, exploited, botnet]
   Latest developments: Dark Reading named the operator on
   September 14, 2026: Russia's Sandworm group chains Cisco

   disrupted in 2022, and CISA added a separate Cisco Secure

10. CONNECTWISE PATCHES WORMABLE SCREENCONNECT FLAW
   Vulnerabilities and Exploits · [patch, rmm, exploited]
   Latest developments: ConnectWise released the fix on
   September 14, 2026 for the ScreenConnect file transfer flaw
   it had covered with temporary mitigations a week earlier,
   closing a hole that lets an attacker send files through an
   active remote session and execute them without authorization.
   Huntress traced three unrelated intrusions in which
   backdoored ScreenConnect instances pushed a four-stage Visual
   Basic Script payload to every newly connected host, a spread
   that started with a Quick Assist tech-support scam, a
   phishing-delivered MSI installer, and a fake update. The flaw
   reaches both the ConnectWise cloud service and on-premises
   installations, so every operator should apply the patch and
   audit recent session file transfers.
