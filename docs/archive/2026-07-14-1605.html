6. Old Signed Shims Reopen the UEFI Secure Boot Bypass

Vulnerabilities and Exploits · [vulnerability, patch]

Latest developments: ESET researchers disclosed on July 14, 2026 that 11 old Microsoft-signed Linux UEFI shims, all version 0.9 or below, let attackers run untrusted code during boot and plant bootkits on most Secure Boot systems; Microsoft revoked them in its June update.

read more

A shim is a small first-stage loader Microsoft signs so Linux and boot tools launch under Secure Boot. Because nearly every UEFI machine trusts that certificate, the vulnerable shims undo the protection; the number of systems still carrying them is unknown, so administrators should apply the revocation and firmware updates.
