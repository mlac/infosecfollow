1. RESEARCHERS ESCAPE THE OPENAI CODEX SANDBOX
   AI Security · [ai, sandbox-escape, patch]
   Latest developments: BleepingComputer reported on September
   20, 2026 that researchers broke out of the sandbox around
   OpenAI's Codex coding agent two separate ways, one of them
   from the agent's most locked-down mode, and ran commands on
   the developer's own machine; OpenAI has patched both routes.
   Codex runs the code it writes inside a sandbox so that a
   hostile repository or a poisoned prompt stops at that
