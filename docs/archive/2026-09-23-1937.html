1. F5 BIG-IP APM Zero-Day Lands Amid an Edge Appliance Rout

Vulnerabilities and Exploits · [zero-day, patch, exploit]

Latest developments: Check Point confirmed on September 23, 2026 that attackers now exploit CVE-2026-85102, the pre-authentication remote code execution flaw in the VPN certificate-handling code of its Quantum Security Gateway, and said probing began days after the September 9, 2026 patch; CERT Polska detailed MikroTrick the same day, a chain of an SSH state-machine flaw, CVE-2026-67279, and an argument-injection bug in the RouterOS login process, CVE-2026-86060, that hands full administrative control of an internet-exposed MikroTik router with no password, no SSH key, and no completed authentication, with attack logs predating the disclosure; Arista Networks released patches for CVE-2026-93952 in on-premises VeloCloud Orchestrator and urged immediate installation; F5 disclosed on September 22, 2026 that attackers exploit CVE-2026-94127 as a zero-day to run code on BIG-IP with no login, narrowing the exposure to systems where Access Policy Manager acts as an OAuth authorization server, and shipped engineering hotfixes; and InfraTrust reported attackers concentrating on the systems that manage enterprise infrastructure.

read more

BIG-IP Access Policy Manager fronts VPN and single sign-on for large enterprises, Check Point's Security Management Server writes firewall policy for entire fleets, and MikroTik routers sit at the edge of tens of thousands of networks. CISA has cataloged CVE-2026-94127, CVE-2026-93616, CVE-2026-85102, and CVE-2026-93952 as actively exploited; apply the vendor hotfixes now, pull management interfaces off the public internet, and hunt for web service activity dating to July 23, 2026.

3. Next.js, Bifrost, and WordPress Hand Over Server Code

Vulnerabilities and Exploits · [patch, rce, web]

Latest developments: Attackers moved from probing WordPress sites for CVE-2026-87902 to exploiting it on September 23, 2026, writing files to disk that run shell commands when someone requests them, one day after WordPress assigned the identifier to the path traversal it fixed in 7.1.2 and listed every release from 4.7.0 through 7.1.1 as affected; Vercel patched a Next.js flaw on September 22, 2026 in which ImageResponse, the feature that renders Open Graph preview images, runs attacker code on the server when an application feeds it values pulled from the request URL, and Maxim Labs' Bifrost AI gateway carries CVE-2026-90898, rated 9.8, which hands an unauthenticated attacker arbitrary commands through one HTTP request on every HTTP transport release before 2.1.0 that leaves management authentication off.

read more

Three widely deployed pieces of the developer stack now reach server code execution from an unauthenticated request: the Next.js image renderer, an open-source gateway that routes to more than 20 large language model providers, and the WordPress theme loader. Upgrade Next.js, move Bifrost to 2.1.0 or enable management authentication, and take WordPress to 7.1.2 or the patched release on your branch.
