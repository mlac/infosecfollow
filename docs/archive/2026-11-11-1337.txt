4. TEN NEURONS BACKDOOR AN AI AGENT
   AI Security · [ai, backdoor, research]
   Latest developments: Microsoft Research published a technique
   it calls Lazarus that implants a hidden backdoor in a capable
   agent model by editing fewer than ten rarely used neurons,
   with no retraining; when a chosen trigger appears, the model
   emits the attacker's command and the agent runs it with the
   agent's own permissions, and the edited model behaves
   normally through standard safety evaluations. Microsoft says
   frontier agents can detect the anomalous weight edits and
   that it has observed no threat actor using the method;
   separately, Microsoft's FORGE Lab reported that its MDASH
   project turned AI-generated Linux kernel findings into 59
   upstream bug reports, 33 assigned CVEs, 38 merged fixes, and
   eight demonstrated local root privilege-escalation exploits.
   The attack requires write access to a model's weights, which
   puts model registries, fine-tuning pipelines, and insiders in
   the threat path for any organization that grants agents real
   permissions. Verify provenance and checksums of every model
   you load, and screen weights for anomalous edits rather than
   relying on behavioral safety tests.
   - Microsoft Security Blog: https://www.microsoft.com/en-us/security/blog/2026/11/10/detecting-sleeper-agents-hiding-in-ai-model-neurons/
   - The Hacker News: https://thehackernews.com/2026/11/microsoft-researchers-show-ai-agents.html
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/11/microsoft-hidden-ai-backdoors-lazarus/

   Latest developments: Krebs on Security reported on November
   11, 2026 that Qilin has become the world's most active
   ransomware affiliate program, claiming at least 365 victim
   organizations in the past three months, and that a decade of
   operational security mistakes by its administrator all point
   to a 36-year-old man living in St. Petersburg, Russia;

   rival program. Companies should hunt for the initial-access
   routes Qilin affiliates favor, and acquirers should treat
   inherited legacy systems as unmonitored attack surface until
   they prove otherwise.

   browser extension inventories to catch Falcon C2's delivery
