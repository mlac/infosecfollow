4. Brotli Decoder Flaw Reaches Bun, Python, and Envoy

Vulnerabilities and Exploits · [vulnerability, patch, supply chain]

Latest developments: Researchers established that CVE-2026-111497, the memory-corruption bug behind this week's Node.js remote code execution, sits in Google's Brotli decoder itself and therefore in Bun, the Python brotli and brotlicffi packages, and Envoy proxies configured to decompress Brotli.

read more

Crafted Brotli-compressed data overwrites memory past the end of a buffer, and any service that unpacks attacker-supplied Brotli streams inherits the flaw. Inventory every runtime, package, and proxy that decodes Brotli rather than treating the Node.js 22.x, 24.x, and 26.x updates as the end of the work.

Sources: The Hacker News · The Hacker News · ↑ top
