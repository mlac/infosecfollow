   for the Remote Desktop regression and for Windows 11 24H2

6. CISCO PATCHES EXPLOITED SECURE EMAIL GATEWAY ZERO-DAY
   Vulnerabilities and Exploits · [zero-day, patch]
   Latest developments: Cisco's advisory on Wednesday, October
   14, 2026 identifies the exploited flaw as CVE-2026-76519, a
   relative path traversal bug: a sender holding no credentials
   mails a crafted attachment through the gateway, writes files
   to the appliance's operating system, and then runs commands
   as root, and CISA added the bug to its Known Exploited
   Vulnerabilities catalog the same day.
   Secure Email Gateway appliances filter an organization's mail
   for spam and malware, so root on one hands an attacker every
   message that passes through it along with a foothold inside
   the network. Administrators should install the fix
   immediately and inspect the appliances for web shells, new
   accounts, and configuration changes.

   AI Security · [ai, vulnerability]
