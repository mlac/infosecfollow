1. CIRCUIT BOARD UNDER THE LEDGER SCREEN
   Ransomware and Cybercrime · [crypto, hardware, supply chain]
   Latest developments: SecurityWeek described the implant's
   construction on October 13, 2026: a small circuit board sat
   hidden under the screens of the Ledger signers, read user
   data, and transmitted it to the attackers, who drained
   roughly $86 million from wallets created on devices the
   Southeast Asian reseller CryptoBilis sold; Ledger says the
   implant captured recovery phrases, and Kim Zetter reported
   the same day that the scheme reached legitimate resellers in
   both Asia and Europe and put the total theft near $100
   million.
   Ledger, the Paris-based hardware wallet maker, has paused
   sales through CryptoBilis and ties every confirmed theft to a
   device from that reseller. Anyone holding a Ledger signer
   bought through a third-party reseller should verify the
   device and move funds to a seed generated on hardware bought
   direct.

6. NPM TRUSTED PUBLISHING OPENED 1,500 PACKAGES
   Vulnerabilities and Exploits · [supply chain, patch]
   Latest developments: GitHub tightened the feature on October
   13, 2026, expiring any unvalidated npm trusted publishing
   configuration 48 hours after someone creates it, with a
   configuration becoming permanent only after its first
   successful publish; Bloom Security had disclosed that the
   feature let an attacker publish new versions of another
   maintainer's package by registering a GitHub repository name
   the maintainer had abandoned, with no stolen credential
   anywhere in the chain, across more than 1,500 packages
   carrying over 10 million downloads.
   Trusted Publishing ties publish rights to a GitHub repository
   instead of a token, so a renamed or deleted repository leaves
   the claim open to whoever registers that name next.
   Maintainers should audit the repositories their npm packages
   trust and reclaim any name they have retired.
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/13/slugfest-npm-trusted-publishing-flaw/
   - The Hacker News: https://thehackernews.com/2026/10/github-tightens-npm-publishing-after.html

9. DOCKER HUB TOKEN FLAW LET ATTACKERS POSE AS OWNERS
   Vulnerabilities and Exploits · [supply chain, patch,
   containers]
   Latest developments: Docker disclosed CVE-2026-105445 on
   October 13, 2026, a critical Docker Hub flaw that let an
   attacker hold a personal access token, reach another user's
   container repositories, impersonate that user, and tamper
   with images.
   Docker Hub distributes the base images most container builds
   pull, so a hijacked identity there carries altered layers
   straight into production deployments. Teams should rotate
   personal access tokens, pin image digests, and review recent
   pushes to their own repositories.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/docker-hub-flaw-let-attackers-impersonate-users-tamper-with-images/
