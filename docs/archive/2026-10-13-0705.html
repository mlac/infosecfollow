Vulnerabilities and Exploits · [patch, zero-day, devops]

Latest developments: GitLab's maximum-severity bug now carries an identifier and a mechanism: CVE-2026-97229 is an integer overflow in the CI/CD Regular Expression Compiler, it affects both Community Edition and Enterprise Edition, and an unauthenticated attacker reaches arbitrary code execution on the server through a specially crafted regular expression in a CI/CD configuration.

Critical Infrastructure Security · [ics, breach]

Latest developments: The attack ran hotter than first reported: on the night of October 11, 2026 the attackers warmed refrigerators and freezers at hundreds of French supermarkets to 50 degrees Celsius, retail chains including Les Mousquetaires confirmed the losses, and the entry point was the single Danfoss controller that runs every cooling unit in a store, a device maintenance firms manage remotely.

3. Circuit Board Under the Ledger Screen

Ransomware and Cybercrime · [crypto, hardware, supply chain]

Latest developments: SecurityWeek described the implant's construction on October 13, 2026: a small circuit board sat hidden under the screens of the Ledger signers, read user data, and transmitted it to the attackers, who drained roughly $86 million from wallets created on devices the Southeast Asian reseller CryptoBilis sold.

read more

Ledger, the Paris-based hardware wallet maker, has paused sales through CryptoBilis and ties every confirmed theft to a device from that reseller. Anyone holding a Ledger signer bought through a third-party reseller should verify the device and move funds to a seed generated on hardware bought direct.

4. npm Trusted Publishing Opened 1,500 Packages

Vulnerabilities and Exploits · [supply chain, patch]

Latest developments: Bloom Security disclosed on October 13, 2026 that npm's Trusted Publishing feature let an attacker publish new versions of another maintainer's package by registering a GitHub repository name the maintainer had abandoned, with no stolen credential anywhere in the chain; Bloom counted more than 1,500 exposed packages carrying over 10 million downloads in total, and GitHub, which owns npm, says it has shipped fixes.

read more

Trusted Publishing ties publish rights to a GitHub repository instead of a token, so a renamed or deleted repository leaves the claim open to whoever registers that name next. Maintainers should audit the repositories their npm packages trust and reclaim any name they have retired.

Sources: Help Net Security · ↑ top

5. Frontier AI Clears Every Goal in Booz Allen's OT Lab

AI Security · [ai, ics]

Latest developments: Booz Allen reported on October 13, 2026 that frontier AI models it set against an isolated industrial control testbed in its Chantilly, Virginia lab met all eight attack objectives the firm had defined: the models mapped the network, matched equipment to known weaknesses, wrote working exploits, pivoted into the systems that run production, and in the final test found a robotic arm, took administrative control, and moved it.

read more

The test puts a measured floor under claims that general-purpose models can run operational technology intrusions end to end, against the very equipment that moves physical things. Plant operators should assume exploit development against their known-vulnerable gear now costs an attacker hours instead of weeks and prioritize segmentation between business networks and production control.

Vulnerabilities and Exploits · [patch, privilege escalation]

Latest developments: Progress Software published 31 vulnerabilities in MarkLogic Server on October 12, 2026 and rated five of them critical; two let an account holding only partial management privileges seize administrator control of the database server and keep it.
