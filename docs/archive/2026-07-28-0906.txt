1. EXPOSED SERVER BMCS LEAK PASSWORD HASHES
   Vulnerabilities and Exploits · [vulnerability, exposure]
   Latest developments: New research disclosed July 28, 2026
   found more than 24,000 internet-exposed baseboard management
   controllers that hand out a user's password hash over UDP
   port 623 before any login, abusing a weakness baked into the
   IPMI 2.0 authentication handshake since 2004.
   A baseboard management controller runs beneath the host
   operating system and can power-cycle the server, mount
   virtual media, open a remote console, and flash firmware, so
   an attacker who cracks a leaked hash gains control that host
   security tools never see; administrators should pull IPMI
   interfaces off the public internet and lock down port 623.
