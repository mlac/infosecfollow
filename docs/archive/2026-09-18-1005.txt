1. PLUGIN4SHELL OPENS FOUR AI CODING AGENTS
   AI Security · [ai, supply-chain, zero-day]
   Latest developments: Air Security disclosed on September 18,
   2026 that Claude Code, Codex, GitHub Copilot, and Gemini CLI
   share one zero-click remote code execution flaw it calls
   Plugin4Shell, the first supply-chain vulnerability of the AI
   agent ecosystem: whoever controls a plugin's source
   repository swaps the code an agent installs even when the
   agent pins that plugin to a specific reviewed version.
   Anthropic fixed it in Claude Code 2.1.179 and OpenAI in Codex
   0.146.0, and GitHub Copilot and Gemini CLI still carry it.
   Anyone whose coding agent installs plugins from a marketplace
   is exposed, and a successful attacker gains the same access
   to company systems and data as the employee running the
   agent. Palo Alto Networks' Unit 42 separately showed that
   default settings in Amazon's AgentCore Harness let prompt
   injection pull credentials out, and Hush Security found
   hardcoded API keys and access tokens in 12 percent of
   credential slots across roughly 82,000 public MCP
   configuration files on GitHub.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/18/plugin4shell-ai-coding-agents-vulnerability/
   - The Hacker News: https://thehackernews.com/2026/09/plugin4shell-lets-repository-owners.html
   - Unit 42 (Palo Alto): https://unit42.paloaltonetworks.com/securing-aws-agentcore-harness-credentials/
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/18/hush-security-mcp-credential-exposure-report/

2. CHECK POINT MANAGEMENT SERVERS YIELD ROOT
   Vulnerabilities and Exploits · [patch, rce]
   Latest developments: Check Point Software shipped a fix
   through its LivePatch channel for a critical flaw that lets
   an attacker with no credentials run code as root over the
   network on Security Management and Log Servers, and says it
   sees no sign of exploitation; Kaspersky and Tanium patched
   product flaws the same day, and Microsoft closed 18
   vulnerabilities across Azure and its AI-branded products,
   among them CVE-2026-85889, a 10.0-rated missing
   authentication for a critical function in Azure AI Foundry
   that hands an unauthorized attacker elevated privileges over
   a network and that Microsoft fixed with no customer action
   required.
   The Security Management Server controls firewall policy and
   administrator access, so root on that box hands an intruder
   the rules governing every gateway it manages. Check Point
   customers should take the LivePatch update immediately.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/check-point-warns-critical-flaw-lets-hackers-execute-code-as-root/
   - The Hacker News: https://thehackernews.com/2026/09/critical-check-point-management-server.html
   - SecurityWeek: https://www.securityweek.com/check-point-kaspersky-tanium-patch-product-vulnerabilities/

3. HACKTRON USES CLAUDE TO REACH OPENAI EMPLOYEE ACCOUNTS

5. ATTACKERS EXPLOIT ORKES CONDUCTOR AS DOCKER SANDBOXES LEAK
   MACOS HOSTS
   Vulnerabilities and Exploits · [exploit, patch, rce]
   Latest developments: SecurityWeek reported on September 18,
   2026 that attackers exploit CVE-2026-58138 in Orkes
   Conductor, an unauthenticated remote code execution flaw they
   reach through inline workflow definitions, and Docker warned
   in a September 15 announcement that CVE-2026-77179, rated
   critical, lets malicious code inside a Docker Sandboxes
   virtual machine on macOS escape the shared project directory
   and read or change any file on the host.
   Orkes Conductor orchestrates microservice workflows, and the
   flaw gives an unauthenticated caller code execution on the
   orchestrator. The Docker escape runs with the rights of the
   host account that started the virtual machine, collapsing the
   isolation developers rely on when they run untrusted code.
   - SecurityWeek: https://www.securityweek.com/critical-orkes-conductor-vulnerability-exploited-in-attacks/

6. LLM-WRITTEN STEALERS RIDE NPM PACKAGES
   Software Supply Chain Security · [supply-chain, malware, apt]
   Latest developments: Researchers at OpenSourceMalware
   identified 13 npm packages delivering WeaselBiscuit, a
   previously undocumented JavaScript stealer that harvests
   Chrome extension storage and overlaps functionally with
   BeaverTail and a second strain from North Korea's Contagious
   Interview campaign; separately, analysts tied a financially
   motivated actor claiming to be a bug bounty hunter to the
   PhantomRaven stealer on npm and judged with high confidence
   that a large language model wrote it, citing verbose
   comments, placeholder code, and token-analysis patterns.
   Both families reach developers through the npm registry and
   take browser-held credentials and wallet data off the
   machines that build software. Development teams should pin
   dependencies, audit recently added packages, and treat Chrome
   extension storage as credential material.
   - The Hacker News: https://thehackernews.com/2026/09/weaselbiscuit-stealer-spreads-via-13.html
   - The Hacker News: https://thehackernews.com/2026/09/claimed-bug-bounty-hunter-likely-used.html

8. ABANDONED APPS AND A RESURRECTED CDN DOMAIN
   Software Supply Chain Security · [supply-chain, iot,
   vulnerability]
   Latest developments: Researchers at the University of
   Massachusetts Amherst analyzed 61,500 abandoned Android smart
   home and internet-of-things companion apps drawn from the
   AndroZoo archive and found nearly three in four carrying
   software dependencies with documented vulnerabilities, while
   The Hacker News traced a domain that once served a wound-down
   content delivery network: the owner let it expire, someone
   re-registered it in July 2025, and thousands of websites,
   code repositories, and documentation pages still hard-code
   hostnames beneath it.
   Millions of people still run companion apps for smart plugs,
   cameras, and thermostats that stopped receiving updates years
   ago, and those apps keep sending data to servers nobody
   maintains. Whoever controls a re-registered CDN domain can
   answer every one of those stale requests with code of their
   own choosing, so teams should grep their repositories and
   pages for third-party hostnames and verify who owns each one
   today.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/18/abandoned-iot-apps-data-security-risks/
   - The Hacker News: https://thehackernews.com/2026/09/an-abandoned-cdn-domain-was-re.html

9. SYNTHID WATERMARKING ERODES MODEL REFUSALS
   AI Security · [ai, research]
   Latest developments: Researchers found that turning on
   SynthID text watermarking changes how large language models
   answer harmful prompts, and the watermarking can push a model
   to follow instructions it would otherwise refuse.
   Watermarking exists to mark machine-generated text for
   provenance, and this work shows the same mechanism shifting
   the token choices that safety training depends on. Anyone
   deploying watermarked models should re-run refusal testing
   with the watermark enabled.
   - Ars Technica Security: https://arstechnica.com/security/2026/09/ai-text-watermarking-can-make-models-more-vulnerable-to-adversarial-prompts/
   - Schneier on Security: https://www.schneier.com/blog/archives/2026/09/are-ais-still-struggling-with-captchas.html

10. CISA RETIRES ITS WEEKLY VULNERABILITY BULLETIN
   Policy and Regulation · [policy, patch]
   Latest developments: The Cybersecurity and Infrastructure
   Security Agency ended its weekly vulnerability summary, the
   long-running roundup of newly published flaws, following
   Binding Operational Directive 26-04, which orders federal
   agencies to rank vulnerabilities by real-world risk instead
   of working down a list by severity score.
   Federal agencies and the many private teams that read the
   bulletin lose a standing catalog of new CVEs and gain a
   mandate to prioritize what attackers actually exploit.
   Security teams that built processes around the weekly summary
   should shift to the Known Exploited Vulnerabilities catalog
   and exploitation telemetry.
   - SecurityWeek: https://www.securityweek.com/cisa-retires-weekly-vulnerability-bulletin-in-risk-based-pivot/
   - Dark Reading: https://www.darkreading.com/cyber-risk/cisa-ditches-weekly-vuln-roundups-risk-based-focus
