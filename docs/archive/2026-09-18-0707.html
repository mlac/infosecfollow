2. Plugin4Shell Opens Four AI Coding Agents

AI Security · [ai, supply-chain, zero-day]

Latest developments: AIR researchers disclosed on September 18, 2026 that Claude Code, Codex, GitHub Copilot, and Gemini CLI all share one zero-click remote code execution flaw, which they call the first supply-chain vulnerability of the AI agent ecosystem, and two of the four agents remain unpatched.

read more

Anyone whose coding agent installs plugins from a marketplace is exposed, and a successful attacker gains the same access to company systems and data as the employee running the agent. Palo Alto Networks' Unit 42 separately showed that default settings in Amazon's AgentCore Harness let prompt injection pull credentials out, and Hush Security found hardcoded API keys and access tokens in 12 percent of credential slots across roughly 82,000 public MCP configuration files on GitHub.

Latest developments: Researchers flagged RatHat on September 17, 2026, Android malware that China-based operators spread through targeted smishing and malvertising to deceptive third-party download portals, which carries an AI-powered subsystem that navigates and controls a compromised handset and abuses the Android Debug Bridge to keep shell access after the victim uninstalls the app.

7. CISA Retires Its Weekly Vulnerability Bulletin

Policy and Regulation · [policy, patch]

Latest developments: The Cybersecurity and Infrastructure Security Agency ended its weekly vulnerability summary, the long-running roundup of newly published flaws, following Binding Operational Directive 26-04, which orders federal agencies to rank vulnerabilities by real-world risk instead of working down a list by severity score.

read more

Federal agencies and the many private teams that read the bulletin lose a standing catalog of new CVEs and gain a mandate to prioritize what attackers actually exploit.
