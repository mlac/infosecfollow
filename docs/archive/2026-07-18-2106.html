1. HollowByte Freezes OpenSSL Server Memory

Vulnerabilities and Exploits · [vulnerability, dos, patch]

Latest developments: Okta's Red Team, which found and named the denial-of-service bug, published HollowByte's details on July 17, 2026, revealing that OpenSSL had quietly shipped the fix in June with no CVE, advisory, or changelog entry.

read more

HollowByte lets an unauthenticated attacker send an 11-byte TLS request that makes an OpenSSL server reserve up to 131 KB of memory for a message that never arrives, and on glibc systems that memory stays gone until the process restarts. Any organization running an unpatched OpenSSL server faces denial of service and should apply the June fix.

3. Spirals Ransomware Encrypts in Under 24 Hours

Ransomware and Cybercrime · [ransomware]

Latest developments: Symantec's Threat Hunter Team disclosed Spirals, a previously unknown Rust ransomware that attackers deployed last month against an IT services company in South Asia, moving from initial access to data theft and full encryption in under 24 hours.
