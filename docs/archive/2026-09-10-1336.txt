1. RANSOMWARE CREWS HIT WATCHGUARD, FORTINET, AND CISCO
   FIREWALLS
   Vulnerabilities and Exploits · [ransomware, patch, exploit]
   Latest developments: Cisco Talos now ties exploitation of two
   Secure Firewall Management Center flaws, the maximum-severity
   authentication bypass CVE-2026-20079 and CVE-2026-20316, to
   three separate clusters covering ransomware crews and
   state-sponsored operators; CISA added CVE-2026-20079 to its
   Known Exploited Vulnerabilities catalog alongside the Citrix
   NetScaler authentication bypass CVE-2026-19490, which
   SecurityWeek dates to attacks running since at least
   September 3, 2026, and the Fortinet code execution flaw
   CVE-2025-25249, which attackers use to install a remote
   access trojan called PivotC2, and gave federal civilian
   agencies until September 12, 2026 to patch all three; CISA
   confirmed that ransomware gangs also exploit the critical
   WatchGuard Firebox remote code execution flaw it first
   flagged in December; and Check Point patched two 9.8-rated
   VPN certificate handling flaws in its Security Gateways and
   Security Management products that give an unauthenticated
   remote attacker code execution under conditions the company
   declines to describe.
   Firewall and firewall-management products from WatchGuard,
   Fortinet, Citrix, Cisco, and Check Point carry flaws that
   attackers exploit right now, and the vendors shipped most of
   the fixes months ago. Apply the patches and comb every
   exposed appliance for accounts and web shells nobody
   recognizes.

4. FAKE IT CALLS REACH EMPLOYEES' PERSONAL PHONES
   Ransomware and Cybercrime · [phishing, identity, cloud]
   Latest developments: Microsoft Security Research said it has
   tracked a campaign since May 2026 in which callers and
   texters pose as internal IT staff, reach employees on their
   personal phones, talk them into handing over access to
   corporate cloud accounts, and then pull files and mail out of
   Microsoft 365, SharePoint, OneDrive, and inboxes for weeks;
   Microsoft Threat Intelligence documented passkey-themed lures
   in the same vein that persuade targets to enroll an
   attacker's authentication method, and Barracuda found
   phishing that routes victims through genuine Microsoft OAuth
   and Teams infrastructure, then assembles the fake login page
   inside the victim's own browser from a blob URL that never
   touches a web server.

   phone, email, and web controls have no visibility. Tell staff
   that IT never calls personal numbers to request codes or
   approvals, and force help desk verification back through an
   internal channel.

5. DEFAULT KEYS AND SPOOFED WORKLOADS IN AI PLUMBING
   AI Security · [ai, identity, cloud]
   Latest developments: Wiz Research reported that nearly one in
   ten internet-facing LiteLLM gateways it scanned in February
   2026 accepted sk-1234, the example administrator key printed
   in LiteLLM's own setup guide; Palo Alto Networks' Unit 42
   showed how root access on a single Kubernetes node lets an
   attacker read SPIFFE and SPIRE metadata and impersonate every
   workload identity sharing that node; and Dark Reading
   detailed workflow identity hijacking, which reaches
   enterprise data through an unauthenticated entry point and
   walks past standard controls.
   An AI gateway sits between a company's applications and the
   model providers it pays, and its administrator key opens
   every request, budget, and provider credential behind it.
   Rotate the default keys, pull gateways off the public
   internet, and treat a compromised node as a compromise of
   every workload identity on it.
   - The Hacker News: https://thehackernews.com/2026/09/nearly-1-in-10-exposed-litellm-gateways.html
   - Unit 42 (Palo Alto): https://unit42.paloaltonetworks.com/kubernetes-spiffe-spire-identity-spoofing/
