6. DECADE-OLD SECURE BOOT BYPASS EXPOSED
   Vulnerabilities and Exploits · [vulnerability, patch]
   Latest developments: Researchers revealed on July 14, 2026
   that Microsoft failed for roughly a decade to revoke old,
   forgotten signed shims, leaving Secure Boot trivially
   bypassable on most systems, and separately catalogued 11 old
   Microsoft-signed Linux UEFI applications that let an attacker
   run untrusted code during boot and plant bootkits.
   Secure Boot verifies that only trusted code loads at startup;
   the stale Microsoft-signed components let attackers defeat
   that check and install malware that survives reinstalls.
   Affected systems need the revoked-certificate and firmware
   updates.
   - Ars Technica Security: https://arstechnica.com/security/2026/07/microsoft-secure-boot-has-been-broken-for-most-of-its-existence/
