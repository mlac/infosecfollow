1. CLOSEDQUORUM RUNS ITS OWN COMMAND AND CONTROL
   AI Security · [ai, malware, threat-intel]
   Latest developments: Cisco Talos released CAIRN, a research
   toolkit that classifies AI-integrated malware entirely from
   file metadata such as submitter, import hash, domain, and AI
   provider, with no download and no detonation, and used it on
   September 22, 2026 to surface CLOSEDQUORUM, a Windows binary
   that drives its entire command and control loop through AI
   chatbots with no operator involvement; BleepingComputer named
   the four models it queries for post-compromise decisions,

   own next actions through a language model instead of waiting
   on a human handler, which moves large stretches of the attack
   chain off the attacker's keyboard. Talos published CAIRN so
   defenders can hunt for the same pattern in their own
   telemetry.

6. MALICIOUS NPM PACKAGES STEAL CREDENTIALS AND REPOSITORIES
   Ransomware and Cybercrime · [supply-chain, npm,
   credential-theft]
   Latest developments: Checkmarx detailed indexed-btree on
   September 22, 2026, a package that impersonates the
   legitimate sorted-btree indexing utility, hides its loader in
   a prototype method inside ordinary runtime code to dodge
   install-script defenses, and collected millions of downloads
   before npm pulled it; The Hacker News described a second
   package, tw-pkgprobe-7731, which the npm account
   twdepprobe7731 uploaded in mid-August 2026 posing as a Twilio
   bug-bounty security tool while harvesting credentials, and
   Dark Reading traced CrowdSec's loss of 170 private GitHub
   repositories to an OAuth token the Shai-Hulud worm lifted
   from a former employee's computer through the TanStack npm
   compromise.
   Attackers now bury malicious logic in the code a package runs
   during normal use, which slips past the registry and
   enterprise controls built to inspect install scripts.
   Development teams should pin dependencies, review new
   packages that mimic popular utility names, and revoke OAuth
   tokens belonging to departed employees.
