1. Citrix NetScaler Zero-Days Under Active Exploitation

Vulnerabilities and Exploits · [zero-day, exploitation, patch]

Latest developments: Citrix confirmed on September 27, 2026 that attackers exploit CVE-2026-88771, an improper input validation flaw, and CVE-2026-88772, a memory buffer flaw, for remote code execution on NetScaler ADC and NetScaler Gateway, released fixes for those two plus six more vulnerabilities running through CVE-2026-88778, and CISA added both exploited bugs to its Known Exploited Vulnerabilities catalog; one of the two reaches every deployment on an affected version, including appliances in the default configuration.

read more

NetScaler ADC and Gateway terminate remote access and load-balance applications for enterprises worldwide, and remote code execution on one hands an attacker the network edge. Install the Citrix updates now and hunt for signs of compromise on any appliance that sat exposed before the patch.

Latest developments: Cloudflare fixed a vulnerability in its Containers and Sandboxes products, BleepingComputer reported on September 27, 2026, that let any customer holding a Workers Paid account recover residual data from other customers' containers sharing the same physical host.

read more
