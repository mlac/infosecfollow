6. Ten Neurons Backdoor an AI Agent

AI Security · [ai, backdoor, research]

Latest developments: Microsoft Research published a technique it calls Lazarus that implants a hidden backdoor in a capable agent model by editing fewer than ten rarely used neurons, with no retraining; when a chosen trigger appears, the model emits the attacker's command and the agent runs it with the agent's own permissions, and the edited model behaves normally through standard safety evaluations. Microsoft says frontier agents can detect the anomalous weight edits and that it has observed no threat actor using the method; separately, Microsoft's FORGE Lab reported that its MDASH project turned AI-generated Linux kernel findings into 59 upstream bug reports, 33 assigned CVEs, 38 merged fixes, and eight demonstrated local root privilege-escalation exploits.

read more

The attack requires write access to a model's weights, which puts model registries, fine-tuning pipelines, and insiders in the threat path for any organization that grants agents real permissions. Verify provenance and checksums of every model you load, and screen weights for anomalous edits rather than relying on behavioral safety tests.

Sources: Microsoft Security Blog · The Hacker News · Help Net Security · Microsoft Security Blog · ↑ top
