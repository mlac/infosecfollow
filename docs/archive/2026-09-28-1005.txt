3. NVIDIA AND AWS MOVE TO FENCE IN AI AGENTS
   AI Security · [ai, governance]
   Latest developments: Nvidia introduced its Open Agent Safety

   watchdog in a hardware reference design that monitors agent
   activity from separate silicon, the same day Amazon Web

6. A 16-YEAR-OLD READS 17 TRILLION ROWS INSIDE MICROSOFT
   Vulnerabilities and Exploits · [vulnerability, cloud]
   Latest developments: A 16-year-old researcher who goes by
   Faav disclosed on September 28, 2026 that Titan, an internal
   Microsoft analytics service, never verified the signature on
   login tokens, which let him pose as the service's
   administrator and run SQL queries against 17 connected
   databases holding an estimated 17.3 trillion rows.
   Titan aggregates data inside Microsoft, and the reachable
   records covered employee information and Bing search
   analytics. The missing signature check handed anyone who
   crafted a token full administrative reach; engineering teams
   should confirm that internal services validate token
   signatures, not merely parse them.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/28/microsoft-titan-jwt-signature-flaw/

8. THE NEW RSA ATTACK FORGES SIGNATURES
   Vulnerabilities and Exploits · [cryptography, research]
   Latest developments: Bruce Schneier wrote on September 28,
   2026 that the RSA attack Ars Technica covered implements
   research from 2007, forges digital signatures, leaves the
   private key beyond reach of the public key, and works only
   against pure signatures that carry no padding or formatting.
   Ars Technica reported on September 24, 2026 that
   cryptographers found a way to break RSA outside the factoring
   problem that every prior attack targeted. Deployed systems
   pad and format their signatures, which keeps ordinary RSA use
   out of range of this technique.
   - Schneier on Security: https://www.schneier.com/blog/archives/2026/09/new-attack-against-rsa.html
