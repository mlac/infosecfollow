3. CLICKFIX BECOMES THE LEADING WAY IN
   Ransomware and Cybercrime · [phishing, malware,
   social-engineering]
   Latest developments: CTM360 published a global count of
   17,000 ClickFix URLs on September 24, 2026 and called the
   technique the most common route attackers take into
   enterprise networks, tracing it from a novelty in late 2023
   to a subscription product with on-chain infrastructure and
   state-sponsored customers; Ax Sharma, head of research at
   Manifold Security, found that third-party.com, the
   documentation placeholder more than 1,700 code repositories
   reference, now shows Windows browsers a fake Cloudflare
   verification page and everyone else a harmless decoy; and
   researchers traced a campaign that injects the same fake
   Cloudflare pages into hacked Ukrainian business websites,
   where the lure copies a Windows Installer command to the
   clipboard and tells the visitor to paste it, delivering a
   previously undocumented information stealer called
   Psychedelic.
   ClickFix shows a visitor a fake verification or error prompt
   and talks them into copying a command into the Windows Run
   dialog, so the intrusion carries no exploit, no attachment,
   and no file on disk. CTM360 concludes that blocking malicious
   domains no longer defends anyone; restrict what users can
   paste into Run and watch PowerShell launched from
   explorer.exe.
   - The Hacker News: https://thehackernews.com/2026/09/17000-urls-reveal-how-clickfix-turns.html

8. PROMPT INJECTION HITS MANUS AS AI COMMITS LEAK SECRETS
   AI Security · [ai, prompt-injection, credentials]
   Latest developments: Dark Reading reported on September 24,
   2026 that Manus, the agentic artificial intelligence
   application valued at $4 billion, carries a prompt-injection
   flaw that lets whoever controls the external data the agent
   reads steer what the agent does, and described Salesbleed
   later the same day, an attack that smuggles instructions off
   the open web through Salesforce agents and across
   applications into Slack, turning a trusted internal channel
   into a phishing delivery system; GitGuardian's 2026 State of
   Secrets Sprawl Report found that commits marked as
   AI-assisted leak credentials at roughly twice the rate of
   human-written commits, with the fastest-growing categories of
   leaked keys tied to AI services.
   Any agent that reads attacker-reachable text treats that text
   as instruction unless the developer filters it hard, and
   coding agents ship credentials into repositories faster than
   review catches them. Scan repositories for secrets
   continuously, scope agent tokens narrowly, and treat every
   external document an agent ingests as untrusted input.
