1. ORACLE SHIPS 800 FIXES AS GOOGLE PATCHES AN EXPLOITED PIXEL
   ZERO-DAY
   Vulnerabilities and Exploits · [patch, zero-day]
   Latest developments: Oracle's September 2026 security update
   closed more than 800 vulnerabilities across 17 product
   families, over 100 of them critical; Google patched
   CVE-2026-58704, an 8.0-rated permission bypass in the Pixel
   cellular modem that a logic error opens and that attackers
   already use in limited targeted attacks, as part of 110 Pixel
   fixes released September 15, 2026; and Google and Mozilla
   together closed 115 browser flaws, 42 in Chrome and 73 in
   Firefox.
   The Oracle batch spans databases, middleware, and business
   applications, which makes it the heaviest scheduling problem
   for enterprise administrators this quarter. Pixel owners
   should update first, since the modem flaw sits under active
   exploitation.

2. POISONED PLUGINS BACKDOOR WORDPRESS AND CPANEL HOSTS
   Vulnerabilities and Exploits · [exploit, wordpress, patch]
   Latest developments: Acronis confirmed that attackers exploit
   CVE-2026-87886, the 7.8-rated insecure file permissions flaw
   in its backup plugin for cPanel, WebHost Manager, and Plesk,
   in limited targeted attacks that raise a local Linux account
   to root; SecurityWeek reported that unauthenticated remote
   code execution flaws in The Events Calendar expose more than
   200,000 WordPress sites to takeover; Wordfence blocked
   thousands of attempts to upload PHP backdoors through
   WooCommerce Wholesale Lead Capture, a premium plugin running
   on more than 6,000 sites; and tampered Admin Menu Editor Pro
   updates, pushed after a threat actor compromised the
   maintainer's website, planted a hidden user account on 1,500
   WordPress sites.
   Hosting stacks run on third-party plugins that update
   themselves and that nobody audits. Patch the Acronis backup
   plugin, The Events Calendar, and WooCommerce Wholesale Lead
   Capture, then hunt for unfamiliar administrator accounts and
   new PHP files in upload directories.
   - SecurityWeek: https://www.securityweek.com/unauthenticated-rce-flaws-could-expose-200000-wordpress-sites-to-takeover/
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/16/acronis-backup-plugin-vulnerability-exploited-cve-2026-87886/

3. RUNAWAY AGENTS AND AI-FOUND BUGS SWAMP DEFENDERS
   AI Security · [ai, agents]
   Latest developments: Mandiant's AI Risk and Resilience
   report, built on its own casework and Google Threat
   Intelligence Group telemetry, tracked attacks moving from
   direct prompts to indirect prompt injection and AI supply
   chain compromise and cited one autonomous agent that ran up a
   $50,000 cloud bill; Cisco Talos argued that AI keeps
   surfacing vulnerabilities nobody can patch, leaving network

   systems, cap cloud spending per agent, and segment what
   agents cannot patch.

4. NEW MALWARE KITS REACH WINDOWS, LINUX, AND MACOS
   Ransomware and Cybercrime · [malware, cybercrime]
   Latest developments: Researchers named four operations in a
   day: BambooToken, running since at least February 2023,
   carries its command channel over the MQTT messaging protocol
   to control Windows and Linux machines at organizations across
   Asia and South America; Elastic Security Labs detailed
   KREMLIN, a Brazilian banking toolkit it tracks as REF9334
   that impersonates a dozen banks and installs a Chrome and
   Edge extension to lift credentials and session tokens; Dark
   Reading priced VectraRAT, a malware-as-a-service platform
   bundling a Windows implant, command-and-control
   infrastructure, and an operator panel, at $250 a month; and
   Palo Alto Networks' Unit 42 traced Atomic macOS Stealer
   campaigns that talk victims through fake setup guides.
   Each kit lowers the cost of full remote access and credential
   theft for operators with little skill. Block MQTT traffic
   leaving corporate networks, inventory browser extensions, and
   treat macOS installation instructions copied from a website
   as hostile.
   - The Hacker News: https://thehackernews.com/2026/09/bambootoken-malware-uses-mqtt-to.html

7. FORGED ADMIN TOKENS OPEN WSO2 API MANAGER
   Vulnerabilities and Exploits · [exploit, patch]
   Latest developments: watchTowr reported active exploitation
   of CVE-2026-5430, a 9.8-rated failure to verify a
   cryptographic signature in WSO2 API Manager that lets an
   attacker forge a JSON Web Token, authenticate as an
   administrator, and take over accounts; the Hacktron Team
   found and reported the flaw.
   WSO2 API Manager fronts enterprise APIs and the data behind
   them, so a forged administrator token reaches customer
   records and internal services directly. Apply the vendor fix
   and audit API Manager logs for administrative sessions that
   no legitimate login produced.
   - The Hacker News: https://thehackernews.com/2026/09/active-exploitation-attempts-target.html
   - SecurityWeek: https://www.securityweek.com/enterprises-warned-of-attacks-exploiting-wso2-vulnerability/

   Vulnerabilities and Exploits · [exploit, patch]
   Latest developments: The Cybersecurity and Infrastructure
   Security Agency warned on September 16, 2026 that attackers
   exploit a critical ConnectWise ScreenConnect vulnerability in
   the wild, two days after ConnectWise shipped the fix for the
