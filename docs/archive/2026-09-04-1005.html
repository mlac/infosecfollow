9. AI Coding Agents Fetch Unregistered Packages

AI Security · [supply-chain, ai, developer-tools]

Latest developments: Researchers at a stealth Israeli startup scanned 6,214 live domains belonging to defense contractors, Fortune 500 companies, and Big Tech firms, pulled 8,265 llms.txt and llms-full.txt files, and found 120 of them, each on a separate site, naming code packages or domains that nobody has registered.

read more

The llms.txt convention tells AI coding agents where to find a vendor's libraries and documentation, and an agent that follows a dangling pointer installs whatever the first person to claim that package name publishes. Security teams should inventory their own llms.txt files and register or remove every name they reference.
