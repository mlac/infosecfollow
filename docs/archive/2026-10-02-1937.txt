1. FORTIMAIL ZERO-DAY RUNS AHEAD OF A PATCH
   Vulnerabilities and Exploits · [zero-day, patch,
   exploitation]
   Latest developments: Fortinet told customers on October 2,
   2026 to apply a workaround because fixes for CVE-2026-104286
   do not yet exist, and researchers pinned the 9.8-rated bug to
   a path traversal that also mishandles NULL bytes, letting an
   unauthenticated attacker write arbitrary files on the
   appliance and run code or commands.
   FortiMail screens inbound mail for enterprises, so a file
   write on the gateway hands an attacker the device that sees
   every message. CISA added the flaw to its Known Exploited
   Vulnerabilities catalog on October 1, 2026 under Binding
   Operational Directive 26-04, which starts a remediation clock
   for federal agencies.

3. MICROSOFT COUNTS THE YEAR ATTACKERS GOT AI FIRST
   AI Security · [ai, report]
   Latest developments: Microsoft published its 2026 Digital
   Defense Report, covering July 2025 through June 2026, which
   argues that attackers now discover and weaponize bugs, build
   malware, and run post-compromise operations faster than
   defenders close the gap, and says "AI is changing the physics
   of cybersecurity"; PwC, which surveyed 3,934 business and
   technology leaders in 71 countries between May and July 2026,
   found half of the security and technology executives ranking
   attacks on AI systems among their top five preparedness gaps,

   place.
   The two reports measure the same gap from opposite ends:
   attackers compress the time from vulnerability to working
   exploit, and buyers name botnets, adversarial attacks, and
   data poisoning as the threats they are least ready for.
   Security leaders should fund detection of AI-assisted
   intrusion now and start the post-quantum inventory rather
   than treat either as a 2027 project.
