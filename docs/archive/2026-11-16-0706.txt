1. NOISYTCP CRASHES LINUX SERVERS
   Vulnerabilities and Exploits · [patch, dos, linux]
   Latest developments: Researchers published NoisyTCP, an
   11-year-old Linux kernel flaw that reaches almost every
   distribution and lets an attacker crash hosts running Nginx,
   Apache, and SSH servers in their default configurations;
   SecurityWeek confirmed that attackers now exploit
   CVE-2026-114713 in UnrealIRCd to execute commands with server
   and IRC operator privileges; the Tor Project shipped 0.4.9.17
   to close several issues, among them a gap in how its built-in
   denial-of-service defenses handle IPv6, while relay attacks
   continue; and Rspamd 4.3.0 fixed bugs that let an
   unauthenticated attacker crash the spam filter's workers with
   one HTTP request, a header line carrying no colon, or an
   empty Deliver-To header, and let forged authentication
   results pass.
   All four fixes land on infrastructure organizations run and
   forget: the kernel, the web server, the IRC daemon, and the
   mail filter. Patch the kernel and Rspamd, move UnrealIRCd to
   the fixed build, and update Tor relays.
   - BleepingComputer: https://www.bleepingcomputer.com/news/linux/new-noisytcp-linux-kernel-flaw-lets-attackers-crash-servers/
   - SecurityWeek: https://www.securityweek.com/recent-unrealircd-vulnerability-exploited-in-attacks/
   - SecurityWeek: https://www.securityweek.com/tor-updates-dos-defenses-again-as-relay-attacks-continue/
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/16/rspamd-4-3-0-released/

2. CRYPTOJACKERS ENTER THROUGH GEOVISION CAMERAS
   Ransomware and Cybercrime · [cryptojacking, malware]
   Latest developments: Huntress warned that attackers exploited
   unpatched GeoVision camera management software to reach
   Windows machines at 13 organizations and turn them into
   cryptocurrency miners, with most of the intrusions falling
   between November 8 and November 10, 2026 and every one
   starting from a service that belongs to GeoVision's software;
   researchers tracking the financially motivated cluster
   REF3364 detailed SANSAR, a Rust orchestrator that takes
   commands over Tor, manages CPU and GPU miners, and loads a
   modified NVIDIA library that falsifies the readings
   administrators use to spot heavy GPU workloads; and Kaspersky
   found a new version of CoffeeLoader spreading through
   Retadup, the USB worm whose infrastructure law enforcement
   seized in 2019.
   GeoVision, the Taiwanese surveillance and access control
   company, sells into 110 countries and has issued no fix, so
   defenders should pull its management software off the network
   and hunt for miner processes that GeoVision services spawn.
   The SANSAR toolkit defeats the GPU-utilization check many
   Linux operators rely on, which means billing anomalies and
   Tor-bound traffic make better detections.
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/16/geovision-camera-software-vulnerabilities/
   - The Hacker News: https://thehackernews.com/2026/11/sansar-linux-cryptomining-malware-uses.html
   - Securelist (Kaspersky): https://securelist.com/retadup-delivers-coffeeloader/121908/

3. ATTACKER AGENTS HUNT AI PROVIDER KEYS
   AI Security · [ai, credentials]
   Latest developments: Amazon's threat intelligence team ran
   decoy servers that captured the attack agents' own records,
   which show the agents probing internet-exposed LiteLLM, One
   API, and Dify installations for stored AI provider keys and
   then using the stolen keys to run the models that powered the
   search for more keys; Anthropic separately shipped Claude
   Fable 5.2 to regular users and Claude Mythos 5.2 to selected
   partners, and Fable 5.2 refuses fewer security tasks than
   earlier versions while Mythos 5.2 finds bugs better.
   LiteLLM, One API, and Dify are self-hosted gateways that hold
   the API keys an organization uses to reach commercial AI
   models, which makes each exposed console a wallet. Anyone
   running one on the public internet should rotate every key,
   require authentication on the management interface, and cap
   spending per key.
   - The Hacker News: https://thehackernews.com/2026/11/amazon-uncovers-ai-agent-campaign.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/artificial-intelligence/anthropics-claude-fable-52-blocks-fewer-security-tasks-while-mythos-gets-better-at-finding-bugs/

4. UBER BREACH REACHES 150,000 PEOPLE
   Data Breaches · [breach, third-party]
   Latest developments: Hackers compromised a third-party
   services provider Uber uses and took the names, addresses,
   and driver's license numbers of 150,000 people, and Coles
   Group Limited, Australia's second-largest retailer, opened an

   Driver's license numbers paired with names and addresses hold

   to service providers should confirm what each provider stores
   and warn the named individuals to watch for fraud.
   - SecurityWeek: https://www.securityweek.com/uber-data-breach-impacts-150000-people/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/australian-retail-giant-coles-investigates-cybersecurity-incident/

5. PROJECT ZERO DROPS ITS PATCH GRACE PERIOD
   Policy and Regulation · [policy, disclosure, patch]
   Latest developments: Google's Project Zero will publish the
   vulnerabilities it finds 90 days after it reports them to a
   vendor whether or not a fix exists, ending the 90-plus-30
   rule the team has followed since 2021, and the deadline falls
   to 60 days on February 2, 2027 and to 30 days on January 3,
   2028 under a policy the team calls Full X; Forescout
   researchers, running generally available AI models on a
   limited budget against both source code and compiled
   binaries, confirmed 99 vulnerabilities across 10 TCP/IP
   stacks, 66 of them previously unknown, and found many in
   discontinued devices whose vendors will never issue a patch.
   Vendors now get a hard 90 days before Project Zero publishes
   technical detail, shrinking to 30 days by January 2028.
   Security teams should expect public bug detail on products
   nobody maintains and build compensating controls, network
   segmentation among them, around end-of-life equipment.
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/16/google-project-zero-disclosure-policy/
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/16/forescout-ai-models-vulnerability-research/

6. HACKERS PROBE 14 NEW COPELAND CONTROLLER FLAWS
   Vulnerabilities and Exploits · [ics, vulnerability]
   Latest developments: Vulncheck disclosed 14 vulnerabilities
   in Copeland XWEB EVO controllers, and threat actors moved
   quickly against two of them.
   Copeland XWEB EVO controllers run refrigeration at
   supermarkets and cold storage sites, and attackers already
   hijacked internet-exposed Copeland XWeb units this autumn for
   a suspected spam botnet and proxy service, and in the October
   2026 attacks that spoiled food and set at least 15 fires
   across more than 700 French retail locations. Operators
   should take these controllers off the public internet and
   install Copeland's updates.
   - SecurityWeek: https://www.securityweek.com/hackers-probe-newly-disclosed-flaws-in-copeland-refrigeration-controllers/
