1. Cairn Agents Root a MONAI Label Server

AI Security · [ai, zero-day, apt]

Amazon Threat Intelligence named the target software: autonomous Cairn agents found an unauthenticated file-write flaw in MONAI Label and took root on a university server.

Why it matters: An AI framework discovered and weaponized an unknown bug in one run, erasing the window defenders rely on between disclosure and exploitation.

  • What to do: Audit MONAI Label installs at version 0.8.5 or earlier, which ship exploitable in the default setup, and take the open-source imaging server off the internet.
  • Zoom in: The flaw lets an attacker with no account write files outside the server's storage folder, which the agents turned into root access.

2. GnuPG and WhatsApp Patch Critical Flaws

Vulnerabilities and Exploits · [patch, vulnerability]

GnuPG warned that a malicious OpenPGP key with an unusually long user ID triggers a critical memory bug in GPGME, tracked as CVE-2026-129975, and shipped fixes.

Why it matters: Every application built on GPGME, the standard library programs use to work with GnuPG, can leak its data to anyone who supplies a crafted key.

  • What to do: Move to GPGME 2.3.0 or later. Android users need WhatsApp or WhatsApp Business 2.26.17.4 or newer to close CVE-2026-23871.
  • Between the lines: WhatsApp's security team found the ad-reply URL validation bug while disrupting a scam campaign and suspects attackers used it to make scam messages look credible.

Why it matters: SAP NetWeaver joins the exploited list, pushing the current espionage campaign into enterprise resource planning estates that run finance and logistics.
