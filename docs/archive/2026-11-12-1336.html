1. AI Agents Enter State Espionage Campaigns

AI Security · [apt, ai, espionage]

Latest developments: Unit 42, the Palo Alto Networks research group, reported on November 12, 2026 that Chinese-speaking attackers ran 25 operations through Cairn, an open-source AI agent framework, against at least 19 organizations in August and September 2026, gained unauthorized access or pulled data at 10 of them after typing little more than a domain name and a one-line goal, and aimed seven of those operations at the semiconductor and advanced manufacturing supply chain; researchers reported that suspected Kazakhstan-linked hackers ran an AI agent to spy on Central Asian governments, steal sensitive documents, and work their way into critical infrastructure networks; Dark Reading detailed a Chinese Communist Party big data project that scrapes open information to profile people abroad and scout recruits inside Taiwan's chip industry; and Romania's intelligence service said it halted a cyber-espionage campaign by Russian state-linked hackers against government email accounts before the group moved data out.

read more

Agentic tooling compresses the reconnaissance, document theft, and lateral movement of an espionage operation into machine-speed work, and the targets are chip makers, defense suppliers, foreign ministries, and government mail systems. Government, semiconductor, and defense organizations should audit mailbox access, watch for agent-driven traffic patterns, and brief employees who face recruitment approaches.

2. ScreenConnect and N-central Attacks Reach Customer Endpoints

Vulnerabilities and Exploits · [zero-day, msp, exploit]

Latest developments: Blackpoint Cyber's Adversary Pursuit Group traced the ScreenConnect campaign to CVE-2026-84869, an already-patched flaw rated 9.9, and to an attacker toolkit it calls SCKit, which rules out a new vulnerability in the remote access software; ConnectWise disabled five third-party ScreenConnect extensions in partner environments after attackers exploited a flaw in one legitimate extension to walk past ScreenConnect authentication and push rogue remote-access clients onto at least 288 endpoints across 48 organizations, and the company sees no compromise of its own infrastructure; N-able opened a second investigation on November 12, 2026 into a fresh public disclosure of more flaws in on-premises N-central 2026.4.1 HF2, the already-hotfixed release, with exploits that claim root remote code execution and Windows SYSTEM access, and the company says the server issue depends on a non-default configuration in which an administrator turns the Legacy API on and exposes it to the public internet.

read more

Both products are remote monitoring and management platforms that managed service providers use to administer client machines, which gives one compromised instance reach into every customer it serves. Administrators should apply N-able's hotfixes, take the Legacy API off the internet, patch ScreenConnect against CVE-2026-84869, check which extensions their environment loads, and hunt for unexpected remote-access clients on managed endpoints.

3. HTTP/2 and Pre-Auth Flaws Hit Core Server Software

Vulnerabilities and Exploits · [patch, rce, open-source]

Latest developments: Citrix patched 12 flaws in NetScaler ADC, NetScaler Gateway, and NetScaler Console, among them CVE-2026-120868, a memory overflow in Packet Engine rated 9.3, plus an authentication bypass and denial-of-service bugs; the Apache Software Foundation fixed CVE-2026-119618, a mod_http2 race condition that researchers at Anthropic and Google found, in HTTP Server 2.4.71 on November 11, 2026, and Red Hat says only hosts running 2.4.55 through 2.4.70 with HTTP/2 enabled face exposure; Node.js closed 16 flaws in versions 22.23.5, 24.22.3, and 26.13.1, two of them in built-in HTTP/2 support that let an unauthenticated client crash a 24.x or 26.x server or pull back pieces of server memory holding other connections' responses; Red Hat shipped fixed builds for eight Quay versions to close a flaw that lets an attacker read and overwrite private container images in every repository, with no account needed while Quay's default anonymous access stays on; MongoDB patched CVE-2026-118383, which lets an unauthenticated attacker send two requests that crash a lagging replica set member once it takes over as primary; and PTC patched CVE-2026-126325, an improper input validation and untrusted deserialization flaw rated 9.2 in Windchill and FlexPLM that hands an attacker remote code execution.

read more

These are the web servers, load balancers, runtimes, databases, registries, and engineering platforms sitting under most enterprise applications, and several of the flaws need no credentials at all. Inventory internet-facing Apache and Node.js hosts with HTTP/2 turned on, patch to 2.4.71 and the fixed Node.js lines, and update NetScaler appliances, Windchill, FlexPLM, MongoDB replica set members, and Quay registries.

4. Windows Updates Stumble as Browsers Patch 180 Flaws

Vulnerabilities and Exploits · [patch, cloud]

Latest developments: Security researcher Abdelhamid Naceri, who goes by Nightmare Eclipse, published SignDrop, a working Windows zero-day exploit that abuses the log-authentication feature Microsoft added to the Common Log File System driver last year, redirecting the companion files clfs.sys creates when a privileged process opens a prepared log and handing a local user SYSTEM privileges; Microsoft confirmed on November 12, 2026 that the November 2026 security updates fail to install on Windows 11 machines carrying the October preview update, throwing 0x80070306, 0x800f0989, and 0x800f0993 errors, and separately confirmed that Windows updates shipped since the October 2026 Patch Tuesday degrade SQL Server performance and stability; Google released Chrome 157 with 83 fixes and Mozilla released Firefox 160 with 99; and Google Cloud told customers running virtual machines on AMD Turin processors to patch the guest operating system and stop and start each instance to close three side-channel flaws that let code sharing a processor core infer data from other processes or the kernel inside the same virtual machine.

read more

The largest patch month on record now carries its own failures, which leaves Windows 11 fleets unpatched and SQL Server instances slow, and a fresh local privilege escalation exploit circulates with no fix. Sequence the October preview update out of the way before deploying November's, benchmark SQL Server hosts, roll Chrome 157 and Firefox 160, and schedule the stop-and-start that AMD Turin guests need.

5. Stolen GitHub Accounts Seed a Secret Stealer

Software Supply Chain Security · [supply-chain, breach, credentials]

Latest developments: SecurityWeek put the reach of the wfx-loot campaign at roughly 60,000 GitHub repositories, extending Aikido Security's account of an attacker who holds stolen credentials for 4,837 GitHub accounts, pushed a credential-stealing payload into tens of thousands of repositories starting Tuesday, November 10, 2026, and ran it in at least 1,806 of them, shipping GitHub Actions secrets and cloud credentials back out; the compromised accounts also opened probe pull requests across the repositories they could write to.

read more

GitHub Actions workflows carry the secrets that reach cloud accounts, container registries, and production systems, so every secret the malware touched counts as burned. Anyone whose repositories accepted commits or workflow runs since November 10, 2026 should rotate Actions secrets and cloud credentials, revoke tokens, and audit recent pull requests and commit authors.

7. GSocket Keeps Linux Servers Owned After Patching

Ransomware and Cybercrime · [linux, malware, persistence]

Latest developments: Microsoft Threat Intelligence documented multiple threat actors planting GSocket, a legitimate open-source remote access tool, on compromised Linux servers to hold encrypted command and control after the victim patches the vulnerability that let the attacker in, and published detection, investigation, and remediation steps; the threat intelligence company Flare reported separately that underground forums now trade eBPF rootkit source code, tutorials, and exploits that hide activity on Linux without loading a kernel module.

read more

Patching an exploited flaw closes the door the attacker used and leaves the attacker inside, because GSocket rides outbound encrypted connections that look like administrative traffic. After any Linux server compromise, hunt for GSocket processes, unexpected cron and systemd persistence, and eBPF programs loaded outside your own tooling.

8. Stolen Claude Keys Turn Claude Code Into an Implant

Latest developments: Darktrace researchers showed in a lab test that an attacker holding a stolen Claude API key can run Claude Code as a remote-controlled implant, steering the coding agent through the memory stores feature of Anthropic's platform and pulling a one-gigabyte file out through the Claude Files API, with every task and every result traveling to api.anthropic.com, the same endpoint the agent already calls for inference; Anthropic opened a private beta on November 12, 2026 of a self-hosted Claude Managed Agents that keeps the agent harness, sandboxes, credentials, and session history inside a customer's own cloud or data center; and Unit 42, the Palo Alto Networks research group, published mitigations for attacker use of AI red team tools including ARTEX.

read more

A coding agent already installed and trusted on a developer workstation becomes the command channel, and its traffic blends into ordinary agent activity that network monitoring treats as benign. Treat Claude API keys as production credentials, rotate exposed ones, and watch for agent sessions that no developer started.
