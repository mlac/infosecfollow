1. CLAUDE OPUS 5 CHAINS TWO FLAWS INTO OPENAI
   AI Security · [ai, exploit, bug-bounty]

   September 19, 2026 as Anthropic's Claude Opus 5 and traced
   the chain's starting point to a bug in the software running

   joined to a weakness in OpenAI's login system; Wired reported

   demonstration. The work shows a commercial chatbot carrying

3. SOLARWINDS AND ORKES CONDUCTOR YIELD PRE-AUTH RCE
   Vulnerabilities and Exploits · [patch, zero-day, rce]
   Latest developments: SolarWinds shipped updates on September
   19, 2026 for CVE-2026-28326, an 8.8-rated hard-coded key in
   Access Rights Manager that hands an unauthenticated attacker
   remote code execution and affects every release through
   2026.2, and Fortinet confirmed active exploitation of
   CVE-2026-58138, the unauthenticated remote code execution
   flaw rated 9.8 that covers Orkes Conductor 3.21.21 through
   3.30.1.
   Access Rights Manager governs Active Directory and file
   server permissions, and Orkes Conductor orchestrates
   microservice workflows, so both sit at the center of the
   environments they serve. Administrators should install the
   SolarWinds update and move Conductor to 3.30.2 or later.
   - The Hacker News: https://thehackernews.com/2026/09/solarwinds-patches-arm-hard-coded-key.html
   - The Hacker News: https://thehackernews.com/2026/09/critical-pre-auth-rce-in-orkes.html

4. SHINYHUNTERS BREACHES CLOP'S LEAK SITE
   Ransomware and Cybercrime · [ransomware, extortion, breach]
   Latest developments: BleepingComputer reported on September
   19, 2026 that the ShinyHunters extortion gang broke into the
   data leak site of the Clop ransomware operation, defaced the
   Tor page, and claims to hold both server data and the private
   keys to the onion service, which it now threatens to use to

   Ransomware and Cybercrime · [apt, cryptocurrency,
   social-engineering]

6. BRAGJACK HIJACKS BROWSER AI ASSISTANTS
   AI Security · [ai, browser, exploit]
   Latest developments: BleepingComputer credited BragJack on
   September 19, 2026 to Gal Weizman of Forever Security and
   reported that his Prompt Forcing technique has drawn more
   than $20,000 in bug bounties and two CVE assignments, with a
   single malicious extension seizing the assistants in Chrome,
   Microsoft Edge, Opera Neon, Perplexity Comet, and the Claude
   in Chrome extension.
   Prompt Forcing feeds instructions straight into a browser's
   built-in assistant, which then reads sensitive pages, runs
   actions, and ships data out under the user's own session.
   Security teams should govern extension installation the way
   they govern software installation, because one extension now
   reaches every assistant in the browser.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/bragjack-attacks-hijack-ai-browser-agents-through-malicious-extensions/

   Software Supply Chain Security · [supply-chain, breach, npm]
   Latest developments: CrowdSec, the French security company,
   disclosed on September 18, 2026 that an attacker copied
   roughly 170 of its private GitHub repositories on May 22,
   2026, using the account of an employee who had just left and
   whose GitHub access the company had left open.
   The departing employee's laptop fell in May 2026's supply

8. CLICK2SHELL FORCES THEME INSTALLS ON WORDPRESS
   Vulnerabilities and Exploits · [patch, wordpress, web]
   Latest developments: WordPress released core patches on
   September 18, 2026 for a set of flaws reported by the
   security firm pwn.ai, one of which lets a crafted web link,
   opened by a logged-in administrator, install a theme from the
   official WordPress.org directory with nobody clicking
   Install.

   their inboxes accordingly.
