1. EXPOSED SERVER BMCS LEAK IPMI PASSWORD HASHES
   Vulnerabilities and Exploits · [exposure, patch]
   Latest developments: Researchers reported on July 28, 2026
   that 24,650 of 36,872 internet-exposed baseboard management
   controllers hand out password-derived authentication hashes
   before login, through a flaw in the IPMI 2.0 handshake built
   on an authentication protocol introduced in 2004.
   An attacker who reaches UDP port 623 on a server's controller
   asks for a hash and receives one without logging in. The BMC
   runs beneath the operating system, power-cycling the host,
   mounting virtual media, opening a remote console, and
   flashing firmware, where host security tools never watch, so
   administrators should pull these interfaces off the public
   internet.
   - The Hacker News: https://thehackernews.com/2026/07/24650-internet-exposed-bmcs-disclose.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/over-24-000-exposed-server-bmcs-leak-password-hash-via-decades-old-flaw/

   AI Security · [ai, cryptography]
   Latest developments: Anthropic reported on July 28, 2026 that

6. AGENTIC BROWSER FLAWS REOPEN OLD WEB ATTACKS
   AI Security · [ai, browser]
   Latest developments: Dark Reading reported on July 27, 2026
   that a class of flaws it calls PleaseFix makes agentic
   browsers easy to socially engineer and exposes weaknesses in
   how they handle cross-origin requests, effectively rolling
   web security back two decades.
   Agentic browsers act on a user's behalf across sites, and the
   PleaseFix pattern lets an attacker plant instructions that
   the agent follows across origins, bypassing the same-origin
   protections that guard ordinary browsers. The finding widens
   the attack surface as AI agents take over routine web tasks.
   - Dark Reading: https://www.darkreading.com/endpoint-security/agentic-browsers-rewind-web-security-20-years
