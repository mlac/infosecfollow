3. PROMPT INJECTION BECOMES THE WEB AGENT'S XSS
   AI Security · [ai, prompt-injection]
   Latest developments: UC Berkeley researchers framed
   Cross-Site Prompting, or XSP, as the web-agent version of
   cross-site scripting and built Prismata to sit between an
   agent and the pages it reads, as BleepingComputer detailed a
   Claude for Chrome extension flaw that lets a malicious
   extension simulate clicks to trigger Claude's authenticated
   access to Gmail, Google Docs, Calendar, and Salesforce.

   listings, ads, rogue extensions—as instructions, letting any
   of it steer the agent; enterprises deploying agentic AI
   should isolate untrusted content and constrain what connected
   services an agent can touch.
