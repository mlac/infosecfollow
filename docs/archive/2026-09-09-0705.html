5. F5 BIG-IP Rootkit Hides Web Shell in Memory

Vulnerabilities and Exploits · [rootkit, apt, network-appliance]

Latest developments: Sophos published an analysis on September 7, 2026 of a Linux rootkit tied to break-ins at F5 BIG-IP Access Policy Manager appliances that intercepts PHP file loading: when Apache loads any of three of the appliance's own PHP scripts, the rootkit appends a web shell to the copy in memory, so the file on disk still checks out clean.

read more

The technique gives attackers a fileless backdoor on internet-facing remote-access appliances that survives disk scanning and file integrity checks. F5 BIG-IP APM operators need memory-level inspection and should treat compromised appliances as unrecoverable without a rebuild.
