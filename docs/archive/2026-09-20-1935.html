1. Malicious npm Packages Hide in Runtime

Software Supply Chain Security · [supply-chain, npm, malware]

Latest developments: BleepingComputer detailed an ongoing npm campaign on September 20, 2026 built around the package indexed-btree, which carries its malicious code inside the package's normal runtime behavior and so slips past the install-script defenses that registries and enterprises rely on.

read more

npm hardening concentrates on preinstall and postinstall hooks, and this campaign leaves those hooks clean, waiting instead until an application calls the library. Developers should watch what a dependency does at execution time, pin versions, and treat a quiet install as no evidence of safety.
