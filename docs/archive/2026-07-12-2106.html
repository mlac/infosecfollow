Latest developments: Debian released 13.6 'trixie' on July 12, 2026, bundling more than a hundred security advisories and routing a fix for the now-expired 2013 UEFI Secure Boot certificate through an updated fwupd.

read more

Most PCs ship a UEFI Secure Boot certificate authority installed by default since 2013 that signs the bootloaders letting machines start with Secure Boot on; that certificate has expired, and Debian's point release patches the trust chain via fwupd. Administrators running Debian 13 should apply 13.6 and update firmware to keep Secure Boot functioning.
