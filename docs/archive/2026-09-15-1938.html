1. Cisco Secure Email Gateway Zero-Day Hands Attackers Root

Vulnerabilities and Exploits · [zero-day, patch, kev]

Latest developments: Cisco released the patch and confirmed active exploitation on September 15, 2026, detailing CVE-2026-76461 as a 9.8-rated failure to validate email parsing in AsyncOS versions 15.5, 16.0, and 16.5 that lets an unauthenticated remote attacker run arbitrary commands as root, published indicators of compromise for administrators to hunt with, and sharpened the SQL injection entry CISA posted to its Known Exploited Vulnerabilities catalog a day earlier.

read more

Cisco Secure Email Gateway appliances handle inbound mail for large enterprises, and a crafted message reaches the underlying operating system with full privileges. Administrators should install the AsyncOS fix immediately and audit the appliances for unfamiliar accounts and outbound connections.

2. Poisoned Plugins Backdoor WordPress and cPanel Hosts

Vulnerabilities and Exploits · [supply-chain, wordpress, exploit]

Latest developments: A threat actor compromised the website of the developer who maintains Admin Menu Editor Pro and pushed tampered updates to more than 200 customers, planting a hidden administrator account on 1,500 WordPress sites; hackers separately exploit a critical flaw in the WooCommerce Wholesale Lead Capture premium plugin to upload a PHP backdoor; Acronis disclosed a high-severity Linux privilege escalation bug in its backup plugin for cPanel, WebHost Manager, and Plesk that attackers may already exploit; and cPanel warned on September 14, 2026 that a LiteSpeed Web Server Enterprise flaw lets the holder of one low-privilege hosting account take root on a shared server and reach every other site on the machine.

read more

Shared hosting stacks pack thousands of customer sites onto single machines, and the plugins and control panels that manage them update automatically from vendor servers. Site owners should audit WordPress installs for administrator accounts nobody created, update the named plugins, and press hosting providers for their LiteSpeed and cPanel patch status.
