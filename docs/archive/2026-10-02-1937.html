Vulnerabilities and Exploits · [zero-day, patch, exploitation]

Latest developments: Fortinet told customers on October 2, 2026 to apply a workaround because fixes for CVE-2026-104286 do not yet exist, and researchers pinned the 9.8-rated bug to a path traversal that also mishandles NULL bytes, letting an unauthenticated attacker write arbitrary files on the appliance and run code or commands.
