1. HACKERS EXPLOIT DRUPAL FLAW FOUND BY ANTHROPIC
   Vulnerabilities and Exploits · [patch, exploit, zero-day]
   The Drupal security team confirmed attackers have exploited
   critical remote code execution flaw CVE-2026-132165 since at
   least Thursday, and CISA gave federal agencies three days to
   patch.
   Why it matters: Unpatched Drupal sites face full takeover,
   and an Anthropic AI scanner found the bug, so AI-discovered
   flaws now reach attackers fast.
   - Zoom in: CISA added two more exploited bugs:
     CVE-2026-132224 in Optimizely Web Experimentation, used to
     plant malicious JavaScript on major websites, and
     CVE-2026-131914 in the Idunno AntiCsrf library.
   - What to do: Update Drupal core immediately. Rip Idunno
     AntiCsrf out of legacy ASP.NET applications, because the
     project is defunct and a single crafted web request runs
     code.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hackers-now-exploit-critical-drupal-rce-flaw-to-hijack-sites/
   - SecurityWeek: https://www.securityweek.com/drupal-flaw-found-by-anthropic-scanner-exploited-in-attacks/

4. ATTACKERS RUN COMMANDS ON HEX.PM SERVERS
   Software Supply Chain Security · [supply-chain, exploit]
   An attacker exploited a flaw rated 10.0 on Monday to run
   operating system commands on six production servers of
   Hex.pm, the Elixir and Erlang package registry.
   Why it matters: Control of a registry lets one attacker
   poison dependencies for every Elixir and Erlang project that
   fetches packages from it.
   - Zoom in: The bug had sat in the registry's code since
     February 2016. Maintainers moved every server to a patched
     build within about 15 minutes of the first malicious
     request.
   - What to do: Check WordPress installations for six WP
     Connect plugins backdoored on November 22, 2026 after a
     suspected developer account compromise. WordPress blocked
     the releases before publication.
   - The Hacker News: https://thehackernews.com/2026/11/hackers-exploited-cvss-100-hexpm-rce.html
   - The Hacker News: https://thehackernews.com/2026/11/wordpress-blocks-six-backdoored-wp.html

5. BOTS GRAB LEAKED AWS KEYS IN SECONDS
   Cloud Security · [cloud, credentials]
   Stony Brook University researchers Billy Tsouvalas and Nick
   Nikiforakis planted 300 decoy Docker images and watched bots
   find and use an embedded cloud access key in under eight
   seconds.
   Why it matters: Any secret that reaches a public registry
   burns instantly, which makes rotation plans measured in hours
   or days worthless.
   - By the numbers: VulnCheck tracked 694 exploited CVEs from
     January through November 2026 and found attackers used 127
     of them to steal database passwords, cloud keys, API
     tokens, or SSH keys.
   - What to do: Scan container images for secrets before
     publishing them, and treat a leaked key as used rather than
     merely exposed.
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/25/docker-aws-key-exposure-bots/
   - Help Net Security: https://www.helpnetsecurity.com/2026/11/25/vulncheck-credential-harvesting-exploitat-records/

6. PALO ALTO PATCHES FIREWALL-ROOTING FRAGNESIA FLAW
   Vulnerabilities and Exploits · [patch, apt, exploit]
   Palo Alto Networks patched Fragnesia after a China-linked
   group chained it with PHP2Shell in AI-assisted attacks that
   took root on 25 servers.
   Why it matters: Firewalls see all traffic crossing the
   network edge, so root access hands an espionage group a
   trusted vantage point inside victim networks.
   - What to do: Apply the Palo Alto Networks fix on
     internet-facing firewalls, then hunt for PHP2Shell
     artifacts and unexplained root processes on the appliances.
   - SecurityWeek: https://www.securityweek.com/palo-alto-networks-patches-fragnesia-flaw-used-to-root-firewalls/
