1. OPENCODE CONSOLE BREACH EXPOSES AI PROVIDER KEYS
   AI Security · [breach, ai, credentials]
   Latest developments: OpenCode said an intruder reached a
   legacy system on the night of October 16, 2026 and may have
   exposed the third-party OpenAI, Anthropic, and Google API
   keys its users saved in OpenCode Console.
   OpenCode Console is the company's optional hosted service: a
   workspace stores its own provider key there, and Console uses
   that key to call the models so teammates share access. Anyone
   who saved a key should revoke and reissue it at the provider
   and read the provider's usage and billing records for calls
   nobody on the team made.
   - The Hacker News: https://thehackernews.com/2026/10/opencode-console-breach-may-have.html

2. BROADCOM WI-FI FLAW HANDS OVER HOME ROUTERS
   Vulnerabilities and Exploits · [zero-day, patch]
   Latest developments: Security researcher Quentin Kaiser
   disclosed on October 16, 2026 an unpatched flaw in Broadcom's
   Wi-Fi setup software that runs code as root on Broadcom-based
   routers from within radio range, demanding neither the
   network password nor any pairing step.
   Kaiser ran the attack against home gateways that three
   Belgian internet providers supply, and in one case read the
   Wi-Fi password straight off the device. Broadcom has shipped
   no fix, so carriers and enterprises running Broadcom-based
   gateways need to press their hardware vendor for patched
   firmware and treat the wireless perimeter as reachable by
   anyone nearby.
   - The Hacker News: https://thehackernews.com/2026/10/unpatched-broadcom-wi-fi-flaw-lets.html
