2. OPENROUTER DROPS THREE AI INFERENCE PROVIDERS
   AI Security · [ai, breach, supply-chain]
   OpenRouter cut three AI inference providers from its routing
   pool after Dragos found attackers had stolen customer
   requests from inside them for months.
   Why it matters: Prompts carry source code, credentials, and
   customer records, so a breached inference provider leaks the
   data enterprises assumed disappeared on arrival.
   - Between the lines: Some stolen requests carried the Zero
     Data Retention flag, the setting that promises a prompt is
     never stored.
   - By the numbers: Researchers planted 2 million trackable
     canary prompts into the AI supply chain and watched secret
     user data leak.
   - What to do: Inventory which downstream providers your AI
     gateway routes prompts to. Treat retention promises as
     unverified until the provider proves detection works.
   - The Hacker News: https://thehackernews.com/2026/11/openrouter-drops-3-providers-after.html
   - Ars Technica Security: https://arstechnica.com/security/2026/11/a-leaky-ai-supply-chain-is-exposing-secret-user-data-at-an-alarming-rate/

3. PWN.AI BREAKS GHOSTSCRIPT SANDBOX WITH UPLOADS
   Vulnerabilities and Exploits · [rce, patch, open-source]
   Security firm pwn.ai showed that a crafted file escapes
   Ghostscript's security sandbox and runs commands on the
   server that processes it.
   Why it matters: Linux servers call Ghostscript to convert
   uploaded PDFs, PostScript files, and images, often without
   the application knowing, so an ordinary upload form becomes
   the entry point.
   - What to do: Install the Ghostscript fix. Map which
     applications hand user-supplied documents to Ghostscript
     for conversion.
   - The Hacker News: https://thehackernews.com/2026/11/researchers-demonstrate-ghostscript.html

4. CAIRN AGENTS EXPLOIT MONAI LABEL ZERO-DAY
   Nation-State Activity · [zero-day, ai, apt]
   Amazon Threat Intelligence pinned the agent-discovered flaw
   to MONAI Label 0.8.5 and earlier in default setups, where an
   attacker with no account writes files outside the storage
   folder.
   Why it matters: Every internet-exposed MONAI Label server in
   that configuration offers suspected China-linked operators
   the same unauthenticated path to root that took a university
   server.
   - What to do: Locate MONAI Label deployments, move off 0.8.5
     and earlier, and pull the servers off the public internet.
   - SecurityWeek: https://www.securityweek.com/amazon-china-linked-hackers-ai-agents-exploited-medical-software-zero-day/
   - The Hacker News: https://thehackernews.com/2026/11/attackers-ai-agents-found-zero-day-in.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hackers-use-autonomous-ai-tool-cairn-to-find-zero-day-take-over-server/
