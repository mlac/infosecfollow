1. ARMORY CASTLE OWNS THE VCENTER ZERO-DAY
   Nation-State Activity · [zero-day, apt, patch]
   Google Threat Intelligence Group pinned zero-day exploitation
   of CVE-2026-123890 on Armory Castle, the China-nexus group
   formerly tracked as UNC5221, which took vCenter administrator
   sessions since early September 2026.
   Why it matters: vCenter manages an organization's ESX hosts
   and virtual machines, so one authentication bypass rated 9.8
   hands an unauthenticated attacker the whole virtual estate.
   - What to do: Broadcom shipped fixed builds for every
     supported branch and lists no workaround. Patch now, then
     hunt for intrusion activity reaching back to September.
   - The Hacker News: https://thehackernews.com/2026/11/china-linked-hackers-exploit-critical.html

9. LINUX KVM HANDS GUESTS THE HOST'S MEMORY
   Vulnerabilities and Exploits · [cloud, patch]
   Researchers used CVE-2026-99312 in KVM, the hypervisor built
   into the Linux kernel, to read about 127 gigabytes of a
   DigitalOcean server's memory from inside their own virtual
   machine.
   Why it matters: On a shared host, that memory can hold other
   customers' virtual machines, which breaks the tenant boundary
   cloud customers pay for.
   - What to do: The flaw reaches only AMD hosts with nested
     virtualization enabled. Roll out the fixed kernels and turn
     nested virtualization off where no workload needs it.
   - The Hacker News: https://thehackernews.com/2026/11/new-linux-kvm-flaw-cve-2026-99312-lets.html
