1. AI TOOLS DRIVE A RANSOMWARE BOOM
   Ransomware and Cybercrime · [ransomware, ai]
   Latest developments: Wired reported on November 14, 2026 that
   low-skill attackers already wreak havoc with AI tools, with
   fully automated ransomware still ahead of them, and Cisco
   Talos mapped how AI-enabled penetration testing and red team
   frameworks chain reconnaissance, vulnerability testing, and
   follow-on actions to cut the skill a break-in demands.
   The same agentic frameworks security teams use for red team
   work now run intrusions for criminals, and the FBI measured
   ARTEX operations moving from initial targeting to privileged
   access in under three hours. Defenders should assume
   machine-speed reconnaissance and credential attacks against
   every internet-facing service and compress their own
   detection and response timelines to match.

4. CURSOR BREACH PLANTS A MALICIOUS CLAUDE CODE EXTENSION
   AI Security · [supply chain, ai]
   Latest developments: Cursor confirmed on November 14, 2026
   that attackers stole credentials from Fireworks AI, the AI
   infrastructure provider, and used them to distribute a
   malicious Claude Code extension through Cursor's own
   marketplace.
   Cursor sells an AI coding editor and ships third-party
   extensions to developers through that marketplace, so a
   poisoned extension runs inside the environment where
   engineers hold source code and cloud keys. Fireworks AI is
   the same provider whose breach exposed Notion AI chat
   transcripts earlier this month; developers should check which
   Claude Code extension versions they installed and rotate the
   credentials those machines touched.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/

5. IMPLANTS RIDE TREZOR SAFE 5 WALLETS FROM A RESELLER
   Ransomware and Cybercrime · [supply chain, crypto]
   Latest developments: Trezor confirmed that three Safe 5
   devices sold by CryptoBilis, a Southeast Asian reseller,
   carry an extra circuit board that reads the wallet's recovery
   phrase off its screen and sends the phrase over the cellular
   network to a server the attackers control, and the company
   released a fix.
   Trezor examined one of the wallets in its lab and identified
   the other two. Anyone holding a Safe 5 bought through
   CryptoBilis should apply Trezor's fix and move funds to a new
   recovery phrase generated on a device bought direct.
   - BleepingComputer: https://www.bleepingcomputer.com/news/cryptocurrency/trezor-confirms-crypto-stealing-implants-in-three-wallets-releases-fix/
   - The Hacker News: https://thehackernews.com/2026/11/trezor-confirms-hidden-hardware.html

7. MIOR AND SKYFALL CRACK AMD SEV-SNP
   Vulnerabilities and Exploits · [cloud, hardware]
   Latest developments: Researchers published two attacks this
   week, Mior and Skyfall, that let the operator of a server
   read data inside AMD SEV-SNP virtual machines, with Mior also
   modifying a guest's memory and forging the signed attestation
   report that tells a customer which software the machine runs.
   AMD SEV-SNP underpins confidential computing at the major
   clouds, where it promises that the host cannot see a tenant's
   data. Both attacks require control of the hypervisor and Mior
   also requires control of the BIOS, which places the risk on
   malicious or compromised hosting providers.
   - The Hacker News: https://thehackernews.com/2026/11/new-mior-and-skyfall-attacks-let-rogue.html
