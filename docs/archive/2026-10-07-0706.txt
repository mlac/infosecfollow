2. CHROME, ANDROID, AND SONICWALL SHIP FIXES
   Vulnerabilities and Exploits · [patch, vulnerability]
   Latest developments: Google released Chrome 155 with 247
   vulnerability fixes, four of them critical use-after-free
   defects in Chromecast, Browser, Navigation, and Track, and
   its October 2026 Android updates closed 25 flaws including a
   critical privilege escalation in the System component;
   SonicWall patched four bugs in its Secure Mobile Access 1000
   series appliances, among them CVE-2026-102255, which lets an
   unauthenticated remote attacker direct the appliance to issue
   requests on the attacker's behalf and reach internal
   functionality; and X.Org fixed 12 flaws in xorg-server
   21.1.25 and xwayland-24.1.14, nine of which carry arbitrary
   code execution.
   SonicWall says it sees no evidence that anyone exploits the
   SMA 1000 bugs yet, and those appliances sit at the network
   edge where attackers have hunted all year. Administrators
   should restart Chrome to take the update, push the October
   Android patch level, and rebuild X servers on Linux desktops
   and workstations.

6. NINJA FORMS FLAW BACKDOORS WORDPRESS SITES
   Vulnerabilities and Exploits · [exploit, patch]
   Latest developments: Attackers exploit stored cross-site
   scripting vulnerabilities in two unrelated WordPress plugins,
   Ninja Forms and WPC Product Bundles for WooCommerce, to
   install backdoors and create rogue administrator accounts,
   BleepingComputer reported on October 6, 2026.
   Both plugins run on large numbers of lead-capture and
   WooCommerce storefronts, and a stored script lands in the
   database where any visiting administrator executes it. Site
   owners should update both plugins, delete administrator
   accounts they cannot account for, and hunt for injected
   JavaScript in posts, forms, and product data.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/ninja-forms-plugin-flaw-exploited-to-hack-wordpress-sites/
