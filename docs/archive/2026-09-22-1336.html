1. CLOSEDQUORUM Runs Its Own Command and Control

AI Security · [ai, malware, threat-intel]

Latest developments: Cisco Talos released CAIRN, a research toolkit that classifies AI-integrated malware entirely from file metadata such as submitter, import hash, domain, and AI provider, with no download and no detonation, and used it on September 22, 2026 to surface CLOSEDQUORUM, a binary that drives its entire command and control loop through AI chatbots with no operator involvement.

read more

CLOSEDQUORUM is the first reported implant that decides its own next actions through a language model instead of waiting on a human handler, which moves large stretches of the attack chain off the attacker's keyboard. Talos published CAIRN so defenders can hunt for the same pattern in their own telemetry.

2. VeloCloud Orchestrator and D-Link Routers Under Fire

Vulnerabilities and Exploits · [zero-day, exploit, patch]

Latest developments: Arista said on September 22, 2026 that attackers exploit CVE-2026-93952, a 10.0-rated flaw in on-premises VeloCloud Orchestrator that lets a remote attacker with no login reach internal functions and the orchestrator host; D-Link warned the same day of CVE-2026-86296, a maximum-severity zero-day in legacy DIR-822A dual-band Wi-Fi routers that carries public proof-of-concept code and no patch; and Dinh Ho Anh Khoa of Viettel Cyber Security published details showing that CVE-2026-65660, which Microsoft first filed as a 6.5 spoofing bug, gives an authenticated user remote code execution on SharePoint Server 2016, 2019, and Subscription Edition.

VeloCloud Orchestrator manages the Edge devices in a VeloCloud SD-WAN, and only orchestrators that authenticate their Edges with certificates carry the flaw. Microsoft has shipped SharePoint patches, D-Link owners of DIR-822A hardware have no fix and should retire the devices.

3. Chinese-Speaking Crew Loots 996 Zyxel Switches

Vulnerabilities and Exploits · [exploit, patch, kev]

Latest developments: GreyNoise reported on September 21, 2026 that a Chinese-speaking threat actor has exploited CVE-2026-7273 since August to pull sensitive data off 996 unpatched Zyxel GS1900 Smart Managed Switches in 48 countries, and CISA added the flaw to its Known Exploited Vulnerabilities catalog the same day with a federal patch deadline of Thursday, September 24, 2026.

read more

CVE-2026-7273 is a stack-based buffer overflow rated 8.8 in the Zyxel GS1900 line of Gigabit Ethernet switches that yields arbitrary operating system command execution; the compromised devices sit mostly in Italy, the United States, Taiwan, South Korea, and other European Union countries. Zyxel has shipped fixes, and CISA cataloged a Veeam flaw granting SYSTEM access alongside it.

5. WordPress Core Yields Two Paths to Server Code

Vulnerabilities and Exploits · [patch, rce, cms]

Latest developments: Researchers published technical details and a working proof-of-concept exploit for Click2Shell on September 21, 2026, and a second core flaw surfaced the same week: Comment2Shell, CVE-2026-93485, which WordPress fixed on September 17, 2026 in version 7.1.1.

read more

Click2Shell is a cross-site request forgery bug in WordPress core that installs and previews a theme when a logged-in administrator opens a crafted link, ending in remote code execution; Comment2Shell lets an anonymous visitor leave a comment carrying a hidden script that runs code on the server once an administrator views the page. Site owners should move to WordPress 7.1.1 now.
