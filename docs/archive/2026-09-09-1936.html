1. Chrome 153 Patches Seventh Zero-Day of 2026

Vulnerabilities and Exploits · [zero-day, patch, browser]

Latest developments: CISA added CVE-2026-87491, the out-of-bounds write in Chrome's V8 JavaScript and WebAssembly engine that attackers already exploit, to its Known Exploited Vulnerabilities catalog on September 9, 2026, a day after Google shipped Chrome 153.0.8010.36 and .37 for Windows and macOS and 153.0.8010.36 for Linux with fixes for 230 flaws; researchers separately named BlueMoon, a previously undocumented exploit kit that chains Windows and Chrome bugs, and counted four espionage clusters running it within a single week, the China-aligned APT31 first among them, a sharing pattern Ars Technica attributes to the patch gap and to faster AI-assisted vulnerability discovery.

read more

Google rates CVE-2026-87491 medium severity and says the exploit runs code inside the browser sandbox, and it withheld technical detail while users update. Every Chrome and Chromium-based browser deployment needs the update now.

2. Ivanti, cPanel, and ICS Vendors Ship Critical Fixes

Vulnerabilities and Exploits · [patch, ics, remote-code-execution]

Latest developments: Cisco confirmed on September 9, 2026 that attackers exploit CVE-2026-20079, a maximum-severity authentication bypass in Secure Firewall Management Center software that Cisco Talos had flagged hours earlier, and CISA added that bug to its Known Exploited Vulnerabilities catalog alongside the Citrix NetScaler authentication bypass CVE-2026-19490, the Fortinet heap overflow CVE-2025-25249, and the Chrome V8 zero-day; Ivanti patched six critical remote code execution flaws in Neurons for ITSM plus authentication bypass bugs in Sentry and Endpoint Manager Mobile; cPanel disclosed that an account holder with mail privileges can write arbitrary files through EmailTrack and run code as root on every supported cPanel and WHM version; Fortinet closed critical unauthenticated flaws in FortiMonitorOnSight and its Chrome extension; Google's September Android updates fixed 180 vulnerabilities; Schneider Electric, Siemens, AVEVA, and Rockwell Automation released industrial control system patches alongside advisories from Nvidia, AMD, and Arm; and BleepingComputer counted more than 36,000 internet-exposed Plex Media Server installations still unpatched.

read more

3. US Agencies Accuse China of Distilling Frontier AI Models

AI Security · [ai, nation-state, policy]

Latest developments: The Cybersecurity and Infrastructure Security Agency, the National Security Agency, and the Federal Bureau of Investigation named six Chinese AI companies that have extracted billions of tokens from American frontier models since at least late 2024, listing Anthropic's Claude, OpenAI's GPT, Google's Gemini, and xAI's Grok as the targets and calling that capture of reasoning, coding, and other restricted capabilities the core of those firms' development strategy; Google Threat Intelligence Group warned the same day that AI now hands lesser-resourced criminal and state crews the automation and scale of a nation-state operation; separately, a flaw in DeepSeek Harness, DeepSeek's open-source tool for running AI coding agents on a developer's machine, let a sandboxed agent turn off its own sandbox with a single command, and researchers found information stealers such as Lumma Stealer and Vidar harvesting replayable session tokens that open AI accounts at Google and Anthropic without a second factor.

read more

Knowledge distillation trains a new model on the outputs of a stronger one, a standard technique the three agencies say Chinese companies run at scale to capture capabilities they cannot license. Model providers should hunt for high-volume output harvesting, and developers running DeepSeek Harness should move to a patched build.

5. DoppelCart Runs 119,000 Fake Storefronts

Ransomware and Cybercrime · [phishing, fraud, malware]

Latest developments: Microsoft Threat Intelligence documented passkey-themed social engineering that talks targets into enrolling an attacker's authentication method, which gives the intruder multi-factor persistence, then queries Microsoft Graph for reconnaissance and pulls data out of SharePoint, OneDrive, and email; earlier today researchers named DoppelCart, a card-skimming operation running more than 119,000 domains as fake online shops, documented a phishing method that assembles the malicious page inside the victim's browser from Microsoft services and blob URLs, and Palo Alto Networks' Unit 42 traced a pay-per-install network that used YouTube gaming lures and search engine poisoning to push multi-payload malware into enterprise networks.

read more

All four operations lean on scale and on infrastructure that reputation-based defenses trust, whether that is a fresh domain among 119,000, a Microsoft-hosted blob URL, a YouTube video, or the enrollment flow of a passkey. Blocklists alone will not hold, so defenders need content inspection at the browser and endpoint plus stricter identity verification when a user adds an authentication method.

9. F5 BIG-IP Rootkit Hides Web Shell in Memory

Vulnerabilities and Exploits · [rootkit, apt, network-appliance]

Latest developments: Sophos published an analysis on September 7, 2026 of a Linux rootkit tied to break-ins at F5 BIG-IP Access Policy Manager appliances that intercepts PHP file loading: when Apache loads any of three of the appliance's own PHP scripts, the rootkit appends a web shell to the copy in memory, so the file on disk still checks out clean.

read more

The technique gives attackers a fileless backdoor on internet-facing remote-access appliances that survives disk scanning and file integrity checks. F5 BIG-IP APM operators need memory-level inspection and should treat compromised appliances as unrecoverable without a rebuild.
