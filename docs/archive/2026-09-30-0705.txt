1. NETSCALER EXPLOITATION YIELDS WHIPSHOT AND SLAPSHOT
   Vulnerabilities and Exploits · [zero-day, patch, exploit]
   Latest developments: Mandiant Consulting and Google Threat
   Intelligence Group named the tooling on September 30,
   2026—web shells they call WHIPSHOT and tunneling malware they
   call SLAPSHOT—and placed the victims in government, financial
   services, technology, education, and legal and professional
   services across North America and Europe, while researchers
   published the mechanics of CVE-2026-88772, a 9.5-rated memory
   overflow in the way NetScaler handles Datagram Transport
   Layer Security that carries an attacker from zero credentials
   to shellcode, on the day CISA's deadline for federal agencies
   to patch arrives.
   Citrix fixed CVE-2026-88771 and CVE-2026-88772 in NetScaler
   ADC and NetScaler Gateway after weeks of zero-day attacks
   that reach appliances running the default configuration.
   Attackers take root, harvest credentials, and pivot into
   internal networks, so patch the appliances, rotate secrets,
   and hunt for web shells and new accounts.

2. ATTACKERS POISON OPENINFRA'S ARTIFACTORY AND 101 NPM PACKAGES
   Software Supply Chain Security · [supply chain, npm, breach]
   Latest developments: OpenInfra Europe, the regional hub of
   the OpenInfra Foundation, posted a notice on its homepage on
   September 30, 2026 saying an attacker compromised the
   self-hosted JFrog Artifactory instance it runs at
   artifactory.nordix.org, and told anyone who downloaded or
   installed artifacts from that server between August 28 and
   September 15, 2026 to stop using them, pull them out of their
   pipelines, and treat the packages as compromised; OX Security
   researchers Nir Zadok, Moshe Siman Tov Bustan, and Vitalii
   Chepurko separately counted 101 malicious npm packages that
   abuse the open-source Baileys WhatsApp project to add
   developers to WhatsApp groups without consent, a campaign
   they call PhantomSub.
   Both attacks target the registries developers pull from
   rather than the code they write, so a single poisoned
   artifact reaches every build that fetched it. Audit
   dependency caches and continuous integration logs for the
   Nordix window and remove the flagged npm packages.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/30/openinfra-jfrog-artifactory-instance-compromised/
   - The Hacker News: https://thehackernews.com/2026/09/101-malicious-npm-packages-add.html

4. OPENSSL AND WOLFSSL CLOSE HIGH-SEVERITY HOLES
   Vulnerabilities and Exploits · [patch, vulnerability]
   Latest developments: OpenSSL shipped fixes on September 29,
   2026 for a high-severity bug in its Datagram Transport Layer
   Security code that hands unencrypted heap memory to the far
   side of a connection or crashes the program when a handshake
   retransmission begins while a larger handshake message sits
   half-sent, and SecurityWeek counted roughly a dozen patched
   vulnerabilities in each of OpenSSL and wolfSSL.
   The two libraries sit underneath VPNs, embedded devices, and
   anything speaking TLS over UDP, so the flaw reaches far past
   the projects themselves. Rebuild and redeploy every product
   that statically links either library.
   - The Hacker News: https://thehackernews.com/2026/09/openssl-fixes-high-severity-dtls-flaw.html
   - SecurityWeek: https://www.securityweek.com/high-severity-vulnerabilities-patched-in-openssl-wolfssl/
