1. Plugin4Shell Opens Four AI Coding Agents

AI Security · [ai, supply-chain, zero-day]

Latest developments: Air Security disclosed on September 18, 2026 that Claude Code, Codex, GitHub Copilot, and Gemini CLI share one zero-click remote code execution flaw it calls Plugin4Shell, the first supply-chain vulnerability of the AI agent ecosystem: whoever controls a plugin's source repository swaps the code an agent installs even when the agent pins that plugin to a specific reviewed version. Anthropic fixed it in Claude Code 2.1.179 and OpenAI in Codex 0.146.0, and GitHub Copilot and Gemini CLI still carry it.

read more

Anyone whose coding agent installs plugins from a marketplace is exposed, and a successful attacker gains the same access to company systems and data as the employee running the agent. Palo Alto Networks' Unit 42 separately showed that default settings in Amazon's AgentCore Harness let prompt injection pull credentials out, and Hush Security found hardcoded API keys and access tokens in 12 percent of credential slots across roughly 82,000 public MCP configuration files on GitHub.

Sources: Help Net Security · The Hacker News · Unit 42 (Palo Alto) · Help Net Security · ↑ top

2. Check Point Management Servers Yield Root

Vulnerabilities and Exploits · [patch, rce]

read more

The Security Management Server controls firewall policy and administrator access, so root on that box hands an intruder the rules governing every gateway it manages. Check Point customers should take the LivePatch update immediately.

3. LLM-Written Stealers Ride npm Packages

Software Supply Chain Security · [supply-chain, malware, apt]

Latest developments: Researchers at OpenSourceMalware identified 13 npm packages delivering WeaselBiscuit, a previously undocumented JavaScript stealer that harvests Chrome extension storage and overlaps functionally with BeaverTail and a second strain from North Korea's Contagious Interview campaign; analysts tied a financially motivated actor claiming to be a bug bounty hunter to the PhantomRaven stealer on npm and judged with high confidence that a large language model wrote it, citing verbose comments, placeholder code, and token-analysis patterns; and BleepingComputer traced a third campaign that ranks SEO-optimized GitHub repositories impersonating LastPass Authenticator and other well-known software to push a new stealer called Rapuncel.

read more

All three families reach developers through the registries and repositories they trust and take browser-held credentials and wallet data off the machines that build software. Development teams should pin dependencies, audit recently added packages, verify the publisher behind any GitHub download, and treat Chrome extension storage as credential material.

4. CISA Retires Its Weekly Vulnerability Bulletin

Policy and Regulation · [policy, patch]

Latest developments: The Cybersecurity and Infrastructure Security Agency ended its weekly vulnerability summary, the long-running roundup of newly published flaws, following Binding Operational Directive 26-04, which orders federal agencies to rank vulnerabilities by real-world risk instead of working down a list by severity score, and on September 18, 2026 it added two actively exploited Linux kernel flaws to the Known Exploited Vulnerabilities catalog: CVE-2025-39964, a race condition, and CVE-2026-53266, an out-of-bounds write.

read more

Federal agencies and the many private teams that read the bulletin lose a standing catalog of new CVEs and gain a mandate to prioritize what attackers actually exploit. Security teams that built processes around the weekly summary should shift to the Known Exploited Vulnerabilities catalog and exploitation telemetry.
