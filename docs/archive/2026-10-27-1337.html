6. Tailscale Rushes Tailworm Patches

Vulnerabilities and Exploits · [vulnerability, patch, privilege escalation]

Latest developments: Tailscale's security team is building fixes for close to a dozen vulnerabilities in Tailscale SSH, the set researchers call Tailworm, after someone published the details over the weekend without coordinating with the company and before any patch existed; the bugs let an attacker steal credentials, crash servers, and escalate to root on machines reachable across the same network.

read more

Tailscale runs a WireGuard mesh that companies use as a flat private network, and Tailscale SSH authenticates logins through that mesh, so one compromised device reaches every server its access rules allow. Until the releases land, turn off Tailscale SSH and tighten the access control lists that decide which devices may connect to which hosts.

7. Gheist Expands Across 850 GitHub Accounts

Ransomware and Cybercrime · [supply chain, credential theft, devops]

Latest developments: Wiz Research put numbers on the campaign on October 27, 2026, recovering more than 13,500 planted branches from over 850 compromised GitHub accounts, and explained the name Gheist, which comes from the user agent the attacker's tool sends with its GitHub API requests.
