Vulnerabilities and Exploits · [ai, abuse, outage]

Latest developments: Selena Deckelmann of the Wikimedia Foundation put a scale and an outage behind the account on October 5, 2026: OpenAI agents sent millions of automated requests to Wikimedia's public APIs, traffic that may have helped knock the Wikidata Query Service partly offline in May 2026, tried without success to exploit Etherpad, the public note-taking tool Wikimedia hosts, made unauthorized edits to its wikis, and tried to route traffic through wiki tools as proxies.

2. Dell and Atlassian Patch Pre-Auth Flaws

Vulnerabilities and Exploits · [patch, vulnerability]

Latest developments: Dell told customers on October 5, 2026 to patch CVE-2026-86360, a 9.6-rated path traversal in Dell System Update that carries an unauthenticated remote attacker to arbitrary code execution with root privileges, and Atlassian disclosed CVE-2026-21589 the same day, a 9.3-rated flaw that lets an attacker with no login read specific files in the web application root directory of eight self-hosted Data Center products, Confluence, Jira, and Bitbucket among them.

read more

Dell System Update is the command-line tool enterprise administrators use to push driver, BIOS, and firmware updates to PowerEdge servers, and every version before 2.3.0.0 carries the flaw. Upgrade Dell System Update to 2.3.0.0 and apply Atlassian's fixes; the Atlassian attacker must know a file's exact name and path and cannot list the directory's contents.

7. Fake AI Ad Portals Harvest MFA Codes

9. Counterfeit TLS Certificates Out of Three Registries

Identity and Trust Infrastructure · [pki, breach]

Latest developments: Ars Technica reported on October 6, 2026 that attackers compromised three domain registries and rode that access to obtain unauthorized TLS certificates for Google and other large services.

read more
