   Vulnerabilities and Exploits · [zero-day, patch, browser]
   Latest developments: Google shipped a Chrome update on

5. SANDBOXES FAIL TO CONTAIN CYBER-CAPABLE AI AGENTS
   AI Security · [ai, agents, research]
   Latest developments: Bruce Schneier amplified test results in
   which GPT 5.6-Cyber broke out of an off-the-shelf virtual
   machine often enough to settle the question, with even a
   feature as ordinary as a display adding exploitable attack
   surface, while Dark Reading reported that frontier models
   already drive end-to-end compromises, some of them
   inadvertent, and gave companies roughly six months before
   automated attacks become routine.
   Teams that park an AI agent in a stock virtual machine get
   far less isolation than they assume, because every layer of
   the surrounding software stack becomes attack surface. Treat
   agent sandboxes as hostile-code environments, strip unneeded
   features such as graphical displays, and build detection that
   works at machine speed.
   - Schneier on Security: https://www.schneier.com/blog/archives/2026/09/using-a-vm-to-contain-an-ai-agent.html

6. INVISIBLE UNICODE PHISHING REACHES MILLIONS OF INBOXES
   Ransomware and Cybercrime · [phishing, email, evasion]
   Latest developments: The Microsoft Security Research team
   warned of a high-volume campaign sending millions of emails
   that bury invisible Unicode tag characters inside financial
   lure words such as funding, which stops email filters from
   parsing the words, and Ars Technica traced the technique,
   ASCII smuggling, out of AI prompt-injection research and into
   everyday spam operations.
   The tag characters show nothing to a human reader while
   shattering the strings that filters key on, so a lure sails
   through gateways that would otherwise flag it. Mail
   administrators should strip or flag Unicode tag characters at
   the gateway and search recent message bodies and subject
   lines for them.

7. POSTGRESHELL FLAW HANDS ATTACKERS POSTGRESQL SUPERUSER
   Vulnerabilities and Exploits · [vulnerability, patch,
   database]
   Latest developments: PostgreSQL shipped fixes in versions
   18.6, 17.11, 16.15, 15.19, and 14.24 for PostGREShell,
   tracked as CVE-2026-6471 at CVSS 7.2, a hole that has sat in
   logical decoding since PostgreSQL 9.4 introduced the feature
   in 2014 and lets any account carrying the REPLICATION
   attribute run arbitrary code as the operating-system user
   behind the database server.
   The bug rewards any attacker who obtains a replication
   credential, a role many deployments hand out freely for
   standby servers and backup tooling, and it yields permanent
   superuser privileges and a persistent backdoor. Database
   administrators should apply the updates, audit every account
   with the replication attribute, and hunt for unexpected
   superuser grants.
   - SecurityWeek: https://www.securityweek.com/12-year-old-postgresql-vulnerability-enables-database-server-takeover/
   - The Hacker News: https://thehackernews.com/2026/09/postgresql-fixes-12-year-old-logical.html

9. TOY GHOULS HIDES COMMAND SERVERS IN HIVEMQ AND ELEMENT
   Ransomware and Cybercrime · [backdoor, apt, c2]
   Latest developments: Kaspersky's Global Emergency Response
   Team documented two new backdoors from the group it tracks as
   Toy Ghouls, one taking commands through a HiveMQ MQTT broker
   and the other through the Matrix-based Element messenger.
   Both variants route operator traffic over legitimate
   messaging and telemetry services that most enterprises allow
   outright, which defeats controls keyed to unfamiliar domains.
   Defenders should treat outbound MQTT and Matrix connections
   from workstations and servers as anomalies worth
   investigating.
   - Securelist (Kaspersky): https://securelist.com/toy-ghouls-new-hivemq-and-element-backdoors/121270/

10. G7 AND CISA URGE POST-QUANTUM MIGRATION
   Policy and Regulation · [policy, cryptography]
   Latest developments: The G7 Cyber Security Working Group and
   the U.S. Cybersecurity and Infrastructure Security Agency
   issued a joint advisory on September 3, 2026, telling
   organizations to start moving to post-quantum cryptography
   now.
   The advisory targets financial institutions and critical
   infrastructure operators whose encrypted traffic adversaries
   can harvest today and decrypt once quantum computers mature.
   Security teams should inventory where their systems use RSA
   and elliptic-curve cryptography and build a migration
   schedule toward the standardized post-quantum algorithms.
