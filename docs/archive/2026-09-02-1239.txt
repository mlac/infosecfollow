1. SONICWALL SMA1000 ZERO-DAYS CHAINED IN ATTACKS
   Vulnerabilities and Exploits · [zero-day, vpn, patch]
   Latest developments: SonicWall shipped updates for two
   zero-days its own researchers William Perry and Adam Babis
   found in Secure Mobile Access 1000 appliances—CVE-2026-83548,
   a pre-authentication server-side request forgery in the
   Appliance Management Console rated a perfect 10.0, and
   CVE-2026-83549—and confirmed attackers already chain the pair
   for unauthenticated remote code execution, a finding Sophos
   corroborated.
   SMA 1000 appliances serve as SSL VPN gateways for medium and
   large enterprises, government agencies, and managed security
   service providers, putting the flaws directly on the network
   edge. Administrators should patch immediately and hunt for
   compromise on any internet-facing instance.
   - The Hacker News: https://thehackernews.com/2026/09/attackers-exploit-two-sonicwall-sma.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-actively-exploited-sma1000-zero-day-flaws/

   - Help Net Security: https://www.helpnetsecurity.com/2026/09/02/sonicwall-sma-1000-cve-2026-83548-cve-2026-83549-zero-day-attacks/

2. BGP HIJACK POISONS VIRTUALIZOR AND SOFTACULOUS UPDATES
   Vulnerabilities and Exploits · [supply-chain, bgp, malware]
   Latest developments: Virtualizor disclosed that attackers
   hijacked Border Gateway Protocol routing for Softaculous's
   update servers, presented a technically valid TLS certificate
   for the domains, and delivered a booby-trapped Virtualizor
   package that planted persistent root access, with one hosting
   provider finding 5 of 34 checked hypervisors compromised in a
   window that opened August 28, 2026, at 20:57.
   Virtualizor is VPS management software from Softaculous that
   runs on hypervisors, and the routing attack turned its update
   channel into a malware delivery pipe; operators should audit
   hypervisors for compromise and rebuild affected hosts.
   - The Hacker News: https://thehackernews.com/2026/09/bgp-hijack-delivers-malicious.html
   - SecurityWeek: https://www.securityweek.com/malicious-virtualizor-update-served-via-bgp-hijacking/

3. SALITY BOTNET DISRUPTED AFTER 23 YEARS
   Ransomware and Cybercrime · [botnet, takedown, malware]
   Latest developments: The Justice Department announced that
   authorities in the United States, Bulgaria, Hungary, and
   Romania, working with CrowdStrike and the Shadowserver
   Foundation, executed a takedown on August 31, 2026,
   manipulating Sality's peer lists and seizing its payload URLs
   to sever more than 15,000 infected machines from their
   operator.
   Sality surfaced in 2003 as a file-infecting virus and grew
   into a peer-to-peer botnet that rented infected Windows
   machines for further malware delivery. Owners of affected
   computers should scan for and remove file-infector remnants,
   since the sinkhole stops new payloads without cleaning hosts.
   - The Record: https://therecord.media/sality-botnet-cyber-doj
   - The Hacker News: https://thehackernews.com/2026/09/authorities-turn-salitys-p2p-network.html
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/02/sality-botnet-disruption-crowdstrike-law-enforcement/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/sality-botnet-infrastructure-dismantled-in-joint-global-takedown/

8. MALICIOUS GIT CONFIGS HIJACK AI CODING AGENTS
   AI Security · [ai, supply-chain, agentic]
   Latest developments: Manifold Security disclosed eight flaws
   across seven command-line AI coding agents, among them
   Claude, Codex, and Cursor, in which a repository's own Git
   configuration names a command that the agent executes as the
   user, outside its sandbox and without an approval prompt, and
   four of the eight remained unpatched at publication.
   Cloning an attacker-controlled repository is enough to
   trigger the code execution, so the risk lands on any
   developer who points an agent at untrusted source. Teams
   should update agents where fixes exist and treat repository
   clones as untrusted input.
   - The Hacker News: https://thehackernews.com/2026/09/malicious-git-configs-can-make-claude.html
