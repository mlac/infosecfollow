5. Spectre v2 Variant Leaks Linux Root Password Hashes

Vulnerabilities and Exploits · [hardware, side-channel, linux]

Latest developments: Academics at VUSec and Scuola Superiore Sant'Anna disclosed Branch Target Reuse on September 29, 2026, a Spectre v2 variant that works around existing defenses by attacking just-in-time compilers in web browsers, language runtimes, and the operating system kernel across Intel, AMD, and Arm processors, and that recovers the root password hash on an Intel machine running Linux in three to five minutes on average.

read more

The attack abuses the way modern processors reuse branch target predictions, so any host that runs untrusted code inside a JIT engine leaks kernel memory. Track vendor microcode and kernel updates, and treat shared-tenant and browser-facing Linux hosts as the first systems to patch.
