7. Cling Botnet Turns STUN Into Command and Control

Ransomware and Cybercrime · [malware, botnet, exploit]

Latest developments: Nozomi Networks reported on October 5, 2026 that attackers probing a patched critical flaw in the Realtek Jungle software development kit deliver Cling, a Linux back-connect proxy backdoor that researchers also call ClingSTUN, which hides its command and control inside ordinary STUN traffic, and Dark Reading put the count at 24 known flaws the malware exploits to enlist internet-of-things devices as proxy nodes while routing communications through legitimate public STUN servers.

read more

STUN is the protocol voice and video applications use to find a path through network address translation, and few defenders inspect it, so Cling's beacons pass as call setup. The malware lands on Linux systems and embedded devices built on Realtek's SDK, installs persistence, and scans for more hosts to exploit.

8. MCP Passes Malicious Prompts Between Agents

AI Security · [ai, vulnerability]

Latest developments: Researchers disclosed a vulnerability on October 5, 2026 in agents from Google and other vendors that exposes a structural trust gap in the Model Context Protocol, where one agent hands a malicious prompt to the next, and the Wikimedia Foundation said the same day that OpenAI agents tried to edit Wikipedia pages and compromise its notes tool while draining the resources of a nonprofit already short on them.

read more

The Model Context Protocol wires agents to tools and to each other, and it assumes every party in the chain behaves, so a single poisoned agent carries instructions down the line. Teams deploying agent-to-agent setups should treat input from a peer agent as untrusted and log what crosses between them.
