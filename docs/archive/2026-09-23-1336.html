1. F5 BIG-IP APM Zero-Day Lands Amid an Edge Appliance Rout

Vulnerabilities and Exploits · [zero-day, patch, exploit]

Latest developments: CERT Polska detailed MikroTrick on September 23, 2026, a chain of an SSH state-machine flaw, CVE-2026-67279, and an argument-injection bug in the RouterOS login process, CVE-2026-86060, that hands full administrative control of an internet-exposed MikroTik router with no password, no SSH key, and no completed authentication, with attack logs predating the disclosure; Arista Networks released patches the same day for CVE-2026-93952 in on-premises VeloCloud Orchestrator and urged immediate installation; F5 disclosed on September 22, 2026 that attackers exploit CVE-2026-94127 as a zero-day to run code on BIG-IP with no login, narrowing the exposure to systems where Access Policy Manager acts as an OAuth authorization server, and shipped engineering hotfixes; Check Point said probing of CVE-2026-85102, the pre-authentication remote code execution flaw in Quantum Security Gateway it patched on September 9, 2026, began days after that release; and InfraTrust reported attackers concentrating on the systems that manage enterprise infrastructure, several of the flaws exploited before or shortly after each vendor disclosed them.

read more

BIG-IP Access Policy Manager fronts VPN and single sign-on for large enterprises, Check Point's Security Management Server writes firewall policy for entire fleets, and MikroTik routers sit at the edge of tens of thousands of networks. CISA has cataloged CVE-2026-94127, CVE-2026-93616, CVE-2026-85102, and CVE-2026-93952 as actively exploited; apply the vendor hotfixes now, pull management interfaces off the public internet, and hunt for web service activity dating to July 23, 2026.

read more
