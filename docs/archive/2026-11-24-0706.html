1. CISA Flags Exploited N-able MailAssure Flaw

Vulnerabilities and Exploits · [patch, breach, zero-day]

CISA added N-able MailAssure flaw CVE-2026-134624, a server-side request forgery rated 9.3, to its Known Exploited Vulnerabilities catalog on Monday, citing active exploitation.

Why it matters: The bug sits in the email filtering cloud N-able runs for managed service providers, handing attackers a route to internal systems behind that service.

  • Zoom in: N-able found the flaw while investigating the breach of its Mail Assure and SpamExperts Hosted Cloud. A user with high-level API access could open connections to chosen internal systems.
  • What to do: Apply the N-able patch and audit high-level API accounts. The company restored access to the affected services and continues to monitor those environments.

2. Norway Names Equinor in Azure Token Hunt

Critical Infrastructure Security · [cloud, credentials]

Norway's National Security Authority said an unknown actor hunted access tokens, secrets, and named values in Azure API Management, hitting energy firms Equinor and Skagerak Energi.

Why it matters: Stolen gateway credentials reach the backend systems an API fronts, turning one cloud flaw into access across Norwegian energy operations and other sectors.

  • What to do: Microsoft closed the flaw in Azure API Management Classic tiers. Rotate every secret, named value, and subscription key stored in the service.
  • Yes, but: The National Security Authority says it remains uncertain how the actor exploited the vulnerability.

4. OpenAI and Cisco Ship Shirudo Shield

AI Security · [ai, patch]

OpenAI and Cisco released Shirudo, an open-source Linux runtime that lets AI agents write dynamic eBPF controls blocking exploit behavior with no restart.

Why it matters: Testing and deploying a Linux patch takes days or weeks, and the vulnerable service stays exposed the whole time.

  • What to do: Teams running exposed Linux services can deploy a shield that blocks the specific behavior a vulnerability depends on while they test the vendor fix.

Wired reported that a pair of unsecured databases exposed 3.5 billion usernames, passwords, and documents tied to hundreds of millions of people.
