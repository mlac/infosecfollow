1. PHP2Shell Forces an Out-of-Cycle PHP Release

Vulnerabilities and Exploits · [zero-day, patch]

Latest developments: PHP released the emergency fixes on October 21, 2026 in versions 8.5.12, 8.4.27, 8.3.36, and 8.2.35, closing CVE-2026-109618 and CVE-2026-109619; Sophos published a proof-of-concept exploit, and the SANS Internet Storm Center raised its InfoCon level to yellow, citing exploit code that circulated before the patch landed.

read more

The two flaws, which the PHP security team rates 9.2 under CVSS v4.0, run an attacker's code on a web server with no login and reach every installation that serves web requests, among them PHP-FPM and Apache with mod_php. PHP underpins most of the public web, including WordPress, Drupal, and Magento sites, so patch now and hunt for web shells on anything internet-facing.

Ransomware and Cybercrime · [credential theft, infrastructure]

Latest developments: A researcher found that attackers took control of more than 300 Tor exit relays in early October 2026 and pointed SSH traffic leaving those relays at servers that captured login passwords.

read more
