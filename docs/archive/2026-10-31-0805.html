4. VOLTA Infostealer Ranks Victims With a Language Model

AI Security · [infostealer, ai, credential theft]

Latest developments: Cisco Talos disclosed VOLTA on October 31, 2026, a self-deleting infostealer that feeds what it takes to large language models, which profile the victim and rank that person's most valuable assets for the operator.

read more

VOLTA steals browser credentials, authenticated sessions, and cryptocurrency wallets, erases itself from the host, and uses model-driven appraisal to decide which stolen accounts deserve immediate exploitation. Defenders should treat any VOLTA infection as a triaged, prioritized theft and reset the highest-value credentials on that endpoint first.
