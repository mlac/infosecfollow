5. Xen, Rails, Chrome, and Android Ship Critical Fixes

Vulnerabilities and Exploits · [patch, zero-day, vulnerability]

Latest developments: The Xen Project disclosed two flaws on November 3, 2026 that let one malicious guest virtual machine read and write the memory of every other virtual machine on the host, dom0 included, reaching all Xen releases from 4.6 onward with patches out and no mitigation available; the Rails project fixed a critical Active Storage flaw in versions 8.1.4.1 and 8.0.5.2 that lets an unauthenticated attacker write arbitrary files on servers that process uploads through ImageMagick; Google shipped Chrome 157 with 213 security fixes, seven of them critical; and Google gave the Android remote code execution flaw that needs no user interaction the identifier CVE-2026-58868, covering Android 14 through 17.

read more

The Xen bugs break the wall between tenants on a shared host, the Rails bug hands file writes to anyone who can upload an image, and the Android flaw runs code on a phone with no action by its owner. 6. APT Package Verification Falls to a Download Swap

Vulnerabilities and Exploits · [patch, vulnerability, supply chain]

Latest developments: Debian, Ubuntu, and the APT developers published advisories on November 4, 2026 for a flaw that lets an attacker who can modify package downloads substitute their own file for a verified package and run code as root, an attack that rides APT's habit of retrying failed downloads, the default from Debian 12 onward; SonicWall said the same day that it will leave two flaws unpatched in Global Management System 9.5.2 and earlier, which it has taken end of life, among them CVE-2026-109593, an unauthenticated file read rated 9.1 that exposes internal GMS files to anyone with network access, alongside a second bug that alters database records.

read more

APT installs and updates software on most Debian and Ubuntu machines, so a machine-in-the-middle on any plain-HTTP mirror turns routine patching into root compromise. Administrators should install the new APT packages, point systems at mirrors reached over HTTPS, and move off SonicWall GMS 9.5.2 and earlier, which will never receive a fix.
