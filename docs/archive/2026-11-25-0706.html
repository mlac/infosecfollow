The Drupal security team confirmed attackers have exploited critical remote code execution flaw CVE-2026-132165 since at least Thursday, and CISA gave federal agencies three days to patch.

Why it matters: Unpatched Drupal sites face full takeover, and an Anthropic AI scanner found the bug, so AI-discovered flaws now reach attackers fast.

5. Bots Grab Leaked AWS Keys in Seconds

Cloud Security · [cloud, credentials]

Stony Brook University researchers Billy Tsouvalas and Nick Nikiforakis planted 300 decoy Docker images and watched bots find and use an embedded cloud access key in under eight seconds.

Why it matters: Any secret that reaches a public registry burns instantly, which makes rotation plans measured in hours or days worthless.

  • By the numbers: VulnCheck tracked 694 exploited CVEs from January through November 2026 and found attackers used 127 of them to steal database passwords, cloud keys, API tokens, or SSH keys.
  • What to do: Scan container images for secrets before publishing them, and treat a leaked key as used rather than merely exposed.
