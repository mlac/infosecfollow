Vulnerabilities and Exploits · [zero-click, vulnerability, mobile]

Latest developments: Researchers at the security company Calif disclosed WeWorm, a worm they built on a critical WeChat flaw that seizes a victim's account through an incoming call the target never answers or touches, then mines that account's saved contacts to call the next set of victims; Calif reported the bug to Tencent in July 2026 and demonstrated the spread across three test phones.

read more

WeChat, Tencent's messaging app, carries the flaw on both iPhone and Android, and the attacker's number must already sit in the target's contact list, a condition each new infection satisfies for the next hop. Calif estimates a live worm could reach millions of devices within hours, so users should install the current WeChat build.

7. FreeIPA Chain Hands Anonymous Clients Administrator Credentials

Vulnerabilities and Exploits · [vulnerability, identity, linux]

Latest developments: Red Hat disclosed a FreeIPA flaw that lets a client which has never authenticated create a Kerberos identity of its own choosing in the directory and land in the administrators group, a takeover that requires a second flaw in the 389 Directory Server database underneath.

read more

FreeIPA decides who may log in across a Linux domain and keeps every identity in a 389 Directory Server database reached over LDAP, so an attacker who mints an administrator ticket owns authentication for the whole domain.
