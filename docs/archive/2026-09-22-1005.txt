1. VELOCLOUD ORCHESTRATOR AND D-LINK ROUTERS UNDER FIRE
   Vulnerabilities and Exploits · [zero-day, exploit, patch]
   Latest developments: Arista said on September 22, 2026 that
   attackers exploit CVE-2026-93952, a 10.0-rated flaw in
   on-premises VeloCloud Orchestrator that lets a remote
   attacker with no login reach internal functions and the
   orchestrator host; D-Link warned the same day of
   CVE-2026-86296, a maximum-severity zero-day in legacy
   DIR-822A dual-band Wi-Fi routers that carries public
   proof-of-concept code and no patch; and Dinh Ho Anh Khoa of
   Viettel Cyber Security published details showing that
   CVE-2026-65660, which Microsoft first filed as a 6.5 spoofing
   bug, gives an authenticated user remote code execution on
   SharePoint Server 2016, 2019, and Subscription Edition.
   VeloCloud Orchestrator manages the Edge devices in a
   VeloCloud SD-WAN, and only orchestrators that authenticate
   their Edges with certificates carry the flaw. Microsoft has
   shipped SharePoint patches, D-Link owners of DIR-822A
   hardware have no fix and should retire the devices.

2. CHINESE-SPEAKING CREW LOOTS 996 ZYXEL SWITCHES
   Vulnerabilities and Exploits · [exploit, patch, kev]
   Latest developments: GreyNoise reported on September 21, 2026
   that a Chinese-speaking threat actor has exploited
   CVE-2026-7273 since August to pull sensitive data off 996
   unpatched Zyxel GS1900 Smart Managed Switches in 48
   countries, and CISA added the flaw to its Known Exploited
   Vulnerabilities catalog the same day with a federal patch
   deadline of Thursday, September 24, 2026.
   CVE-2026-7273 is a stack-based buffer overflow rated 8.8 in
   the Zyxel GS1900 line of Gigabit Ethernet switches that
   yields arbitrary operating system command execution; the
   compromised devices sit mostly in Italy, the United States,
   Taiwan, South Korea, and other European Union countries.
   Zyxel has shipped fixes, and CISA cataloged a Veeam flaw
   granting SYSTEM access alongside it.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/22/zyxel-switches-cve-2026-7273-vulnerability-exploited/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/cisa-orders-feds-to-patch-actively-exploited-zyxel-flaw-by-thursday/
   - The Hacker News: https://thehackernews.com/2026/09/zyxel-and-veeam-flaws-under-active.html
   - SecurityWeek: https://www.securityweek.com/recent-zyxel-switch-vulnerability-exploited-by-chinese-hackers/

3. CLOSEDQUORUM RUNS ITS OWN COMMAND AND CONTROL
   AI Security · [ai, malware, threat-intel]
   Latest developments: Cisco Talos released CAIRN, a research
   toolkit that classifies AI-integrated malware entirely from
   file metadata such as submitter, import hash, domain, and AI
   provider, with no download and no detonation, and used it on
   September 22, 2026 to surface CLOSEDQUORUM, a binary that
   drives its entire command and control loop through AI
   chatbots with no operator involvement.
   CLOSEDQUORUM is the first reported implant that decides its
   own next actions through a language model instead of waiting
   on a human handler, which moves large stretches of the attack
   chain off the attacker's keyboard. Talos published CAIRN so
   defenders can hunt for the same pattern in their own
   telemetry.
   - Cisco Talos: https://blog.talosintelligence.com/the-closed-quorum-inside-the-first-reported-autonomous-ai-c2-implant/
   - Cisco Talos: https://blog.talosintelligence.com/introducing-cairn-frontier-tracking-for-ai-integrated-malware/
   - Wired Security: https://www.wired.com/story/a-tool-for-tracking-ai-integrated-malware-uncovered-an-autonomous-command-system/
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/22/cairn-open-source-framework-ai-malware-closedquorum/

4. WORDPRESS CORE YIELDS TWO PATHS TO SERVER CODE
   Vulnerabilities and Exploits · [patch, rce, cms]
   Latest developments: Researchers published technical details
   and a working proof-of-concept exploit for Click2Shell on
   September 21, 2026, and a second core flaw surfaced the same
   week: Comment2Shell, CVE-2026-93485, which WordPress fixed on
   September 17, 2026 in version 7.1.1.
   Click2Shell is a cross-site request forgery bug in WordPress
   core that installs and previews a theme when a logged-in
   administrator opens a crafted link, ending in remote code
   execution; Comment2Shell lets an anonymous visitor leave a
   comment carrying a hidden script that runs code on the server
   once an administrator views the page. Site owners should move
   to WordPress 7.1.1 now.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/wordpress-click2shell-flaw-lets-hackers-execute-php-on-the-server/
