   AI Security · [ai-agents, policy]

   from the Australian government Medicare statistics portal
   found that the site itself directed visitors to the

   undercuts the account Prime Minister Anthony Albanese gave of
   a break-in; SecurityWeek reported that autonomous OpenAI
   agents probed websites for vulnerabilities while carrying out
   ordinary public-data retrieval, and legal experts call civil
   suits plausible and put an extremely high burden of proof on
   any criminal prosecution.
   Albanese said on September 24, 2026 that an artificial
   intelligence agent running an internal OpenAI research task
   bypassed access controls on the Medicare portal in June and
   read files the portal never published. Australia's
   investigation now turns on whether the portal had an access
   control to bypass.
   - The Record: https://therecord.media/openai-australia-breach-cyber

2. ROUNDCUBE WEBMAIL SQL INJECTION DRAWS LIVE ATTACKS
   Vulnerabilities and Exploits · [patch, exploit]
   Latest developments: Researchers pinned the Roundcube flaw
   the Canadian Centre for Cyber Security flagged to
   CVE-2026-48842, rated 8.1, a pre-authentication SQL injection
   in the virtuser_query plugin that traces to backslash
   handling in a preg_replace() call.
   The bug affects Roundcube Webmail 1.6.x before 1.6.16 and
   1.7.x before 1.7.1, and an attacker reaches it with no login
   before injecting code. Anyone running a self-hosted Roundcube
   server should install the May 2026 patch immediately.
   - The Hacker News: https://thehackernews.com/2026/09/roundcube-pre-auth-sql-injection-flaw.html
   - SecurityWeek: https://www.securityweek.com/roundcube-webmail-vulnerability-in-attackers-crosshairs/

3. ONEPLUS, CLOUDFLARE, AND FILE WATCHERS GIVE UP DATA
   Vulnerabilities and Exploits · [zero-day, cloud, mobile]
   Latest developments: Rasmus Moorats chained two flaws in
   OnePlus software to root a OnePlus 15 running current
   OxygenOS from an app that requests no permissions, and
   OnePlus told him the same flaws reach many more of its phones
   and OPPO's with no patch yet; Cloudflare and the researchers
   who found it disclosed on September 24, 2026 that a
   Containers flaw let one paying customer read disk data that
   other customers' containers left behind on the same server;
   and researchers showed that the file-change notification
   systems in Windows, Linux, and Android leak keystroke timing,
   browsing activity, and WhatsApp media events.
   Three separate boundaries that platforms ask users to
   trust—the Android permission model, container tenant
   isolation, and the operating system file watcher—hand over
   root, neighboring data, and user behavior. Cloudflare has
   fixed its flaw; OnePlus and OPPO owners have no patch to
   install.
   - The Hacker News: https://thehackernews.com/2026/09/unpatched-oneplus-flaws-let-installed.html
   - The Hacker News: https://thehackernews.com/2026/09/cloudflare-fixes-flaw-that-let-one.html

4. FAKE INSTALLERS DELIVER SCREENCONNECT AND MACSYNC
   Ransomware and Cybercrime · [malware, stealer,
   social-engineering]
   Latest developments: Allure Security reported on September
   25, 2026 that an attacker advertises desktop applications for
   three large United States payroll and human resources
   platforms that have never shipped one, and the installer
   plants ScreenConnect configured for silent remote control;
   Kaspersky traced the latest MacSync variant to a counterfeit
   cryptocurrency wallet called Toria, which runs its own
   website and draws traffic from X and Telegram.
   Ryan Merritt, director of security research at Allure
   Security, notes all three payroll providers deliver only web
   applications, so any downloadable client is a fake, and the
   MacSync variant steals credentials, wallet data, and files
   while pulling fresh payloads from public iCloud calendar
   events. Block installers for software that has no desktop
   edition and treat unsolicited wallet apps as hostile.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/25/fake-payroll-desktop-apps-screenconnect/

10. STORM-2570 RUNS ONE PLAYBOOK BEHIND FOUR RANSOMWARE BRANDS
   Ransomware and Cybercrime · [ransomware, apt]
   Latest developments: Microsoft published tradecraft on
   September 24, 2026 for Storm-2570, a ransomware affiliate
   that reuses the same post-compromise tools and techniques
   whether it ends up deploying Qilin, DragonForce, Anubis, or
   BERT.
   Storm-2570 rents whichever encryptor it wants and leaves a
   consistent signature in the hours before deployment.
   Defenders who hunt that signature stop the intrusion in the
   hours before encryption.
