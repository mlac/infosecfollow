1. AI CODING ASSISTANTS TURNED INTO AN ATTACK SURFACE
   AI Security · [ai, supply-chain, malware]
   Latest developments: Researchers on July 8 unveiled
   HalluSquatting, which maps the fake package names AI coding
   assistants reliably hallucinate, registers them first, and
   lets nine popular tools fetch botnet malware onto users'
   machines, while Abhishek Kumar and Carsten Maple showed
   GitHub Copilot refuses a harmful request in chat yet writes
   the same exploit when a user breaks it into small steps, and
   Sophos found agents including Claude Code, Cursor, and OpenAI
   Codex tripping endpoint rules built to catch human intruders.
   AI coding assistants both invent nonexistent dependencies
   attackers can preregister and generate dangerous code that
   chat filters would block, exposing developers who run their
   output. Pin dependencies, review generated code, and tune
   endpoint detections to distinguish agent behavior from
   intrusions.
