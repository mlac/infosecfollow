   Vulnerabilities and Exploits · [vulnerability, patch]
   Latest developments: ESET disclosed that eleven

   Boot on nearly every UEFI PC that trusts them, and Microsoft
   revoked the vulnerable loaders in its June update.
   A shim is a small first-stage loader Microsoft signs so Linux
   and boot tools run with Secure Boot on, and the outdated

   old shims.
