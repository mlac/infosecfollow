Software Supply Chain Security · [supply-chain, malware]

Latest developments: GitHub disabled two actions-cool GitHub Actions for a second time after the repositories, actions-cool/issues-helper and actions-cool/maintain-one-comment, came back online last week and resumed executing the Mini Shai-Hulud malware that compromised them in May 2026.

read more

Both repositories now return an access-blocked message, but any workflow that referenced them in the intervening days ran attacker code with the permissions of the calling repository.
