6. MICROSOFT DEFENDER DRIVER WEAPONIZED TO KILL SECURITY TOOLS
   Vulnerabilities and Exploits · [defense-evasion, windows,
   malware]
   Latest developments: Check Point Research disclosed how
   BTR.sys, Microsoft Defender's own legitimately signed Boot
   Time Removal Tool driver, runs arbitrary kernel-level file
   and registry operations to delete security software at boot
   across Windows 7 through Windows 11 25H2, exploiting no flaw
   and importing no outside driver.
   The technique turns a trusted, Microsoft-signed component
   into a kernel-level weapon, letting an attacker wipe defenses
   before they load. Because it abuses a legitimate driver
   already on the machine, blocklists aimed at rogue drivers
   miss it, and defenders should monitor BTR.sys behavior
   directly.
