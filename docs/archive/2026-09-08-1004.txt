2. HELP DESK VISHING DRAINS EXECUTIVE MICROSOFT 365 ACCOUNTS
   Ransomware and Cybercrime · [phishing, extortion, identity]
   Latest developments: Arctic Wolf gave the data theft and
   extortion cluster a name, PREY-0058, and said its tradecraft
   matches the group Google Threat Intelligence Group tracks as
   UNC6671, tying together the vishing calls,
   adversary-in-the-middle token theft, and residential-proxy
   sign-ins already documented against Microsoft 365 tenants.
   The operators phone corporate IT help desks, talk their way
   into a password reset or a session token, then sign in
   through residential proxies that look like ordinary employee
   traffic, singling out directors, vice presidents, and other
   executives; the phishing-as-a-service framework BigBear 2.0
   ran the same play past multi-factor authentication at 258
   organizations for more than 5,000 Microsoft 365 credentials.
   Help desks need identity proofing that survives a persuasive
   caller.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/08/vishing-microsoft-365-data-theft-extortion/
   - The Hacker News: https://thehackernews.com/2026/09/microsoft-365-attackers-use-help-desk.html

3. WECHAT ZERO-CLICK WORM HIJACKS ACCOUNTS THROUGH A CALL
   Vulnerabilities and Exploits · [zero-click, vulnerability,
   mobile]
   Latest developments: Researchers at the security company
   Calif disclosed WeWorm, a worm they built on a critical
   WeChat flaw that seizes a victim's account through an
   incoming call the target never answers or touches, then mines
   that account's saved contacts to call the next set of
   victims; Calif reported the bug to Tencent in July 2026 and
   demonstrated the spread across three test phones.
   WeChat, Tencent's messaging app, carries the flaw on both
   iPhone and Android, and the attacker's number must already
   sit in the target's contact list, a condition each new
   infection satisfies for the next hop. Calif estimates a live
   worm could reach millions of devices within hours, so users
   should install the current WeChat build.
   - The Hacker News: https://thehackernews.com/2026/09/wechat-zero-click-worm-took-over.html
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/08/wechat-weworm-vulnerability-exploit-account-hijacking/

4. AI AGENTS TAKE OVER ATTACK WORKFLOWS
   AI Security · [ai, credential theft, threat intelligence]
   Latest developments: Google Threat Intelligence Group
   published its Q3 2026 AI Threat Tracker, drawing on Mandiant
   incident response engagements and live platform defenses, and
   found attackers moving past single prompts into workflows

7. FREEIPA CHAIN HANDS ANONYMOUS CLIENTS ADMINISTRATOR
   CREDENTIALS
   Vulnerabilities and Exploits · [vulnerability, identity,
   linux]
   Latest developments: Red Hat disclosed a FreeIPA flaw that
   lets a client which has never authenticated create a Kerberos
   identity of its own choosing in the directory and land in the
   administrators group, a takeover that requires a second flaw
   in the 389 Directory Server database underneath.
   FreeIPA decides who may log in across a Linux domain and
   keeps every identity in a 389 Directory Server database
   reached over LDAP, so an attacker who mints an administrator
   ticket owns authentication for the whole domain.
   Administrators running FreeIPA should patch both FreeIPA and
   389 Directory Server and review the directory for identities
   nobody created.
   - The Hacker News: https://thehackernews.com/2026/09/freeipa-flaw-chain-lets-anonymous.html
