1. REVOLUT AND TELUS DISCLOSE CUSTOMER DATA THEFT
   Data Breaches · [breach, social engineering, fintech]
   Latest developments: The Record reported on September 14,
   2026 that the fraudsters who extracted Revolut customer
   records submitted emergency data requests from a working
   government email account, sharpening the disclosure Revolut
   confirmed on Saturday, September 12, 2026, and Telus warned
   subscribers the same day that intruders used stolen
   credentials across a multi-month campaign to reach personal
   data and billing records.
   The Revolut notification to affected customers lists birth
   dates, postal and email addresses, phone numbers, and copies
   of identity documents including passports, and the company
   told TechCrunch a limited number of customers lost data and
   that it contacted each of them directly. Customers of both
   companies should treat unsolicited contact referencing their
   account details as fraud and watch for identity theft.

2. THIRD JFROG ARTIFACTORY FLAW JOINS BACKDOOR CAMPAIGN
   Vulnerabilities and Exploits · [exploited, patch, supply
   chain]
   Latest developments: SecurityWeek reported on September 14,
   2026 that attackers chain three JFrog Artifactory
   vulnerabilities, one more than the pair CISA cataloged on
   September 11, to bypass authentication and raise their
   privileges to administrator before planting a backdoor.
   CISA already lists the incorrect authorization bug
   CVE-2026-42016 and the improper authentication bug
   CVE-2026-42018 as actively exploited, and Wiz dated the
   campaign against self-hosted Artifactory servers from August
   15 through September 8, 2026, finding it reached only
   operators who had skipped JFrog's earlier fixes. Anyone
   running Artifactory on their own hardware should install
   every available update and hunt for a Rust backdoor and
   unfamiliar administrator accounts.
   - SecurityWeek: https://www.securityweek.com/three-jfrog-artifactory-flaws-exploited-for-backdoor-deployment/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/cisa-hackers-now-exploit-max-severity-gitlab-flaw-in-attacks/

3. CHINESE HACKERS RIDE SOGOU FLAW TO GRAYRABBIT
   Vulnerabilities and Exploits · [apt, zero-day, espionage]
   Latest developments: SecurityWeek reported on September 14,
   2026 that CVE-2026-51990 in Tencent's Sogou Input Method for
   Windows hands attackers remote code execution from a single
   click, the mechanism behind the China-aligned espionage
   campaign that BleepingComputer tied a day earlier to the
   GrayRabbit backdoor.
   Sogou Input Method ranks among the most widely installed
   tools for typing Chinese characters on Windows, and operators
   start each intrusion with a crafted link that plants
   GrayRabbit carrying the logged-in user's full rights. Anyone
   running Sogou Input Method should update it or pull it off
   corporate machines.
   - SecurityWeek: https://www.securityweek.com/chinese-hackers-exploit-critical-tencent-software-flaw-for-one-click-code-execution/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hackers-exploit-tencent-app-flaw-to-deploy-grayrabbit-malware/

4. SEPTEMBER WINDOWS UPDATES BREAK REMOTE DESKTOP AND USB AUDIO
   Vulnerabilities and Exploits · [patch, windows, outage]
   Latest developments: Microsoft confirmed on September 14,
   2026 that its September 2026 security updates knock out

5. CISOS FIGHT OVER-PRIVILEGED AI AGENTS AS AWS MEASURES FALSE
   POSITIVES
   AI Security · [ai, agents, vulnerability management]
   Latest developments: Amazon Web Services released its
   Deception Benchmark publicly on September 14, 2026, a dataset
   and evaluation process that scores how well AI models
   separate genuine vulnerabilities from code that merely looks
   risky, and found the models piling up false positives;
   SecurityWeek reported the same day that security leaders are
   struggling to rein in over-privileged agents without
   stripping out the value those agents deliver.
   Security teams now point AI at vulnerability triage,
   penetration testing, threat modeling, incident response, and
   code review, and every false positive adds work for the
   humans reviewing the output. Teams should benchmark any model
   before they trust its findings and scope agent permissions to
   the narrowest set of systems each task requires.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/14/aws-deception-benchmark-security-vulnerabilities/
   - SecurityWeek: https://www.securityweek.com/cisos-race-to-control-ai-agents-without-destroying-their-value/

6. CONNECTWISE PATCHES WORMABLE SCREENCONNECT FLAW
   Vulnerabilities and Exploits · [patch, rmm, exploited]
   Latest developments: ConnectWise released the fix on
   September 14, 2026 for the ScreenConnect file transfer flaw
   it had covered with temporary mitigations a week earlier,
   closing a hole that lets an attacker send files through an
   active remote session and execute them without authorization.
   Huntress traced three unrelated intrusions in which
   backdoored ScreenConnect instances pushed a four-stage Visual
   Basic Script payload to every newly connected host, a spread
   that started with a Quick Assist tech-support scam, a
   phishing-delivered MSI installer, and a fake update. The flaw
   reaches both the ConnectWise cloud service and on-premises
   installations, so every operator should apply the patch and
   audit recent session file transfers.
   - SecurityWeek: https://www.securityweek.com/connectwise-patches-screenconnect-vulnerability-exploited-in-worm-like-attacks/
