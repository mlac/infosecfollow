1. CHECK POINT MANAGEMENT SERVERS YIELD ROOT
   Vulnerabilities and Exploits · [patch, rce]
   Latest developments: Check Point Software shipped a fix
   through its LivePatch channel for a critical flaw that lets
   an attacker with no credentials run code as root over the
   network on Security Management and Log Servers, and says it
   sees no sign of exploitation; Kaspersky and Tanium patched

2. PLUGIN4SHELL OPENS FOUR AI CODING AGENTS
   AI Security · [ai, supply-chain, zero-day]
   Latest developments: AIR researchers disclosed on September
   18, 2026 that Claude Code, Codex, GitHub Copilot, and Gemini
   CLI all share one zero-click remote code execution flaw,
   which they call the first supply-chain vulnerability of the
   AI agent ecosystem, and two of the four agents remain
   unpatched.
   Anyone whose coding agent installs plugins from a marketplace
   is exposed, and a successful attacker gains the same access
   to company systems and data as the employee running the
   agent. Palo Alto Networks' Unit 42 separately showed that
   default settings in Amazon's AgentCore Harness let prompt
   injection pull credentials out, and Hush Security found
   hardcoded API keys and access tokens in 12 percent of
   credential slots across roughly 82,000 public MCP
   configuration files on GitHub.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/18/plugin4shell-ai-coding-agents-vulnerability/
   - Unit 42 (Palo Alto): https://unit42.paloaltonetworks.com/securing-aws-agentcore-harness-credentials/
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/18/hush-security-mcp-credential-exposure-report/

4. LLM-WRITTEN STEALERS RIDE NPM PACKAGES
   Software Supply Chain Security · [supply-chain, malware, apt]
   Latest developments: Researchers at OpenSourceMalware
   identified 13 npm packages delivering WeaselBiscuit, a
   previously undocumented JavaScript stealer that harvests
   Chrome extension storage and overlaps functionally with
   BeaverTail and a second strain from North Korea's Contagious
   Interview campaign; separately, analysts tied a financially
   motivated actor claiming to be a bug bounty hunter to the
   PhantomRaven stealer on npm and judged with high confidence
   that a large language model wrote it, citing verbose
   comments, placeholder code, and token-analysis patterns.
   Both families reach developers through the npm registry and
   take browser-held credentials and wallet data off the
   machines that build software. Development teams should pin
   dependencies, audit recently added packages, and treat Chrome
   extension storage as credential material.
   - The Hacker News: https://thehackernews.com/2026/09/weaselbiscuit-stealer-spreads-via-13.html
   - The Hacker News: https://thehackernews.com/2026/09/claimed-bug-bounty-hunter-likely-used.html

5. BREVO ATTACK REACHES 100,000 WEBSITES
   Software Supply Chain Security · [supply-chain, malware,
   breach]
   Latest developments: SecurityWeek put the count at 100,000
   websites on September 18, 2026, and detailed the method: the
   attackers used the stolen Cloudflare API key to deploy a
   Cloudflare worker that injected the malicious scripts, a day
   after Brevo confirmed the theft.
   Brevo, the French email marketing platform, lost a Cloudflare
   API key that attackers turned into ClickFix scripts running
   on its own sites and inside the JavaScript files its
   customers embed on theirs, making every one of those sites a
   malware distribution point. Site owners who load Brevo
   JavaScript should audit their pages and rotate anything the
   injected scripts could have touched.
   - SecurityWeek: https://www.securityweek.com/brevo-supply-chain-attack-injects-malware-into-100000-websites/
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/brevo-supply-chain-attack-injected-clickfix-scripts-on-customer-sites/

6. RATHAT ANDROID TROJAN DRIVES PHONES WITH AI
   Ransomware and Cybercrime · [malware, mobile, ai]
   Latest developments: Researchers flagged RatHat on September

7. CISA RETIRES ITS WEEKLY VULNERABILITY BULLETIN
   Policy and Regulation · [policy, patch]
   Latest developments: The Cybersecurity and Infrastructure
   Security Agency ended its weekly vulnerability summary, the
   long-running roundup of newly published flaws, following
   Binding Operational Directive 26-04, which orders federal
   agencies to rank vulnerabilities by real-world risk instead
   of working down a list by severity score.
   Federal agencies and the many private teams that read the
   bulletin lose a standing catalog of new CVEs and gain a
   mandate to prioritize what attackers actually exploit.
   Security teams that built processes around the weekly summary
   should shift to the Known Exploited Vulnerabilities catalog
   and exploitation telemetry.
   - SecurityWeek: https://www.securityweek.com/cisa-retires-weekly-vulnerability-bulletin-in-risk-based-pivot/
   - Dark Reading: https://www.darkreading.com/cyber-risk/cisa-ditches-weekly-vuln-roundups-risk-based-focus
