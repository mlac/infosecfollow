1. Exposed Server BMCs Leak IPMI Password Hashes

Vulnerabilities and Exploits · [exposure, patch]

Latest developments: Researchers reported on July 28, 2026 that 24,650 of 36,872 internet-exposed baseboard management controllers hand out password-derived authentication hashes before login, through a flaw in the IPMI 2.0 handshake built on an authentication protocol introduced in 2004.

read more
