1. CHROME 153 PATCHES SEVENTH ZERO-DAY OF 2026
   Vulnerabilities and Exploits · [zero-day, patch, browser]
   Latest developments: Google shipped Chrome 153.0.8010.36 and
   .37 for Windows and macOS and 153.0.8010.36 for Linux on
   September 8, 2026, fixing 230 flaws, among them
   CVE-2026-87491, an out-of-bounds write in the V8 JavaScript
   and WebAssembly engine that attackers already exploit in the
   wild, the seventh Chrome zero-day of the year and the second
   in six days after CVE-2026-85046.
   Google rates CVE-2026-87491 medium severity and says the
   exploit runs code inside the browser sandbox, and it withheld
   technical detail while users update. Every Chrome and
   Chromium-based browser deployment needs the update now.

3. SHIELDCRASH BYPASSES MICROSOFT'S DEFENDER PATCH
   Vulnerabilities and Exploits · [zero-day,
   privilege-escalation, patch]
   Latest developments: Hours after Microsoft published its
   September 2026 updates, the anonymous researcher known as
   Nightmare Eclipse, who also goes by Chaotic Eclipse, released
   a proof-of-concept exploit named ShieldCrash that grants
   SYSTEM privileges and defeats Microsoft's fix for
   CVE-2026-69414, the 7.8-rated Defender flaw the same

   out-of-band Microsoft update and monitor Defender's
   remediation routines for abuse.

4. DOPPELCART RUNS 119,000 FAKE STOREFRONTS
   Ransomware and Cybercrime · [phishing, fraud, malware]
   Latest developments: Researchers named DoppelCart, a
   card-skimming operation that runs more than 119,000 domains
   as fake online shops to harvest payment card details, and
   separately documented a phishing method that assembles the
   malicious page inside the victim's browser from Microsoft
   services and blob URLs, which leaves defenders no hosted site
   to detect or block; Palo Alto Networks' Unit 42 traced a
   pay-per-install network that used YouTube gaming lures and

   enterprise networks.
   All three operations lean on scale and on infrastructure that
   reputation-based defenses trust, whether that is a fresh
   domain among 119,000, a Microsoft-hosted blob URL, or a
   YouTube video. Blocklists alone will not hold, so defenders
   need content inspection at the browser and endpoint.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/doppelcart-fraud-network-uses-119-000-fake-shops-to-steal-credit-cards/

5. F5 BIG-IP ROOTKIT HIDES WEB SHELL IN MEMORY
   Vulnerabilities and Exploits · [rootkit, apt,
   network-appliance]
   Latest developments: Sophos published an analysis on
   September 7, 2026 of a Linux rootkit tied to break-ins at F5
   BIG-IP Access Policy Manager appliances that intercepts PHP
   file loading: when Apache loads any of three of the
   appliance's own PHP scripts, the rootkit appends a web shell
   to the copy in memory, so the file on disk still checks out
   clean.
   The technique gives attackers a fileless backdoor on
   internet-facing remote-access appliances that survives disk
   scanning and file integrity checks. F5 BIG-IP APM operators
   need memory-level inspection and should treat compromised
   appliances as unrecoverable without a rebuild.
   - The Hacker News: https://thehackernews.com/2026/09/f5-big-ip-apm-malware-injects-php-web.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hackers-breach-f5-big-ip-apm-devices-to-deploy-linux-rootkit/

6. LIQUID NETWORK THIEVES RETURN $263 MILLION
   Ransomware and Cybercrime · [cryptocurrency, cybercrime]
   Latest developments: Whoever drained nearly 4,000 bitcoin,
   roughly $320 million, from the Liquid Network federation
   wallet on September 6, 2026 through a bug in Elements
   returned 3,400 of those coins, about $263 million, the next
   day while demanding that the sidechain fix the flaw, and kept
   598.5 bitcoin worth some $47 million; Liquid remains paused,
   so holders cannot redeem the L-BTC token for bitcoin.
   Liquid is a Bitcoin sidechain that locks up real bitcoin to
   back L-BTC, and the attackers reached the federation wallet
   that holds the reserve. In parallel prosecutions and
   investigations, Malone Lam pleaded guilty to racketeering
   charges over a $245 million crypto heist that funded Hamptons
   vacations, cars, and private jets, and CrowdStrike detailed
   Slim Spider, a Brazil-based crew that has stolen
   cryptocurrency custody secrets from Brazilian financial
   institutions since March 2026.
