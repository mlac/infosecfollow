1. SHAI-HULUD RIDES A COMPROMISED NPM SDK
   Ransomware and Cybercrime · [supply chain, npm, credential
   theft]
   Latest developments: Socket reported on October 8, 2026 that
   version 0.5.144 of the npm package tensorlake, the TypeScript
   development kit for Tensorlake sandboxes and cloud services,
   carries obfuscated malware from the ChainDrop and Shai-Hulud
   supply chain campaign that harvests credentials, exfiltrates
   secrets, sets up persistence, and runs code the operator
   supplies; CloudSEK and Checkmarx separately named a campaign
   MALFEX, where one author published 12 npm packages since
   August 2023 and eight of them delivered the Overlord remote
   access trojan and information stealers across 40,767
   downloads, while researchers found 16 malicious Firefox
   extensions posing as Rabby and OKX wallet portals that
   intercept recovery phrases and private keys during wallet
   imports.
   Developers who installed tensorlake 0.5.144 or any of the
   MALFEX packages should treat every credential on the build
   host as stolen, rotate tokens, and audit repositories for new
   persistence. Unit 42 traced the same pattern deeper, showing
   crews using Web3 infrastructure and open-source packages to
   reach enterprise cloud environments.

2. SONICWALL, SPLUNK, AND TP-LINK ROUTER FLAWS
   Vulnerabilities and Exploits · [patch, zero-day, policy]
   Latest developments: Cisco published advisories on October 8,
   2026 for a dozen critical vulnerabilities, five of them in
   the NX-OS data center network operating system, where an
   attacker can run arbitrary code with root privileges on Nexus
   switches; SecurityWeek reported the same day that Splunk
   patched critical and high-severity flaws carrying attackers
   to authentication bypass, arbitrary code execution, and
   privilege escalation, and that SEC Consult published
   technical details of the internet-service-provider router
   vulnerabilities a multistate lawsuit against TP-Link cites;
   SonicWall shipped hotfixes for four flaws in its Secure
   Mobile Access 1000 appliances, among them a 10.0-rated
   pre-authentication server-side request forgery that routes an
   attacker's requests through the gateway into internal
   functions, and says it has no evidence anyone exploits the
   four.
   The SMA1000 gateways hand remote workers access to corporate
   networks and applications, which puts a pre-authentication
   flaw at the network edge, and the Nexus switches sit in the
   middle of data center traffic. Administrators should install
   the Cisco NX-OS, SonicWall, and Splunk updates now and treat
   exposed TP-Link ISP routers as untrusted equipment.

10. FAKEGIT FLOODS GITHUB WITH 17,610 FAKE REPOS
   Ransomware and Cybercrime · [malware, github, infostealer]
   Latest developments: BleepingComputer reported on October 8,
   2026 that the FakeGit campaign reactivated earlier this month
   and now runs more than 17,610 counterfeit GitHub repositories
   that distribute the SmartLoader malware loader, which in turn
   pushes the StealC information stealer.
   FakeGit builds repositories that pass for real projects and
   hands anyone who downloads from them SmartLoader and then
   StealC, which lifts browser credentials and session data.

   unfamiliar GitHub account before running its code or
   binaries.
