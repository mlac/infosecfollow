1. CLOSEDQUORUM Runs Its Own Command and Control

AI Security · [ai, malware, threat-intel]

Latest developments: Cisco Talos released CAIRN, a research toolkit that classifies AI-integrated malware entirely from file metadata such as submitter, import hash, domain, and AI provider, with no download and no detonation, and used it on September 22, 2026 to surface CLOSEDQUORUM, a Windows binary that drives its entire command and control loop through AI chatbots with no operator involvement; BleepingComputer named the four models it queries for post-compromise decisions, Google Gemini, DeepSeek, Qwen, and Mistral.

read more

CLOSEDQUORUM is the first reported implant that decides its own next actions through a language model instead of waiting on a human handler, which moves large stretches of the attack chain off the attacker's keyboard. Talos published CAIRN so defenders can hunt for the same pattern in their own telemetry.

3. WordPress Core Yields Two Paths to Server Code

Vulnerabilities and Exploits · [patch, rce, cms]

Latest developments: WordPress shipped version 7.1.2 on September 22, 2026 for a third core flaw, this one letting an attacker with no account make a site load a PHP file from outside its theme folders and, on some servers, run their own code, and backported the fix to every branch the project still supports, back to 4.7; researchers published a working proof-of-concept for Click2Shell the day before.

read more

6. Malicious npm Packages Steal Credentials and Repositories

Ransomware and Cybercrime · [supply-chain, npm, credential-theft]

read more

Attackers now bury malicious logic in the code a package runs during normal use, which slips past the registry and enterprise controls built to inspect install scripts. Development teams should pin dependencies, review new packages that mimic popular utility names, and revoke OAuth tokens belonging to departed employees.

Vulnerabilities and Exploits · [zero-day, exploit, patch]

Latest developments: Check Point Software shipped emergency hotfixes on September 22, 2026 and identified the flaw as CVE-2026-93616, a path traversal that lets anyone who reaches the Security Management Server's web service run scripts on it without logging in, which attackers used in a handful of targeted attacks on July 23, 2026; CISA added that flaw and CVE-2026-85102, an improper certificate validation bug in multiple Check Point products, to its Known Exploited Vulnerabilities catalog the same day.

read more
