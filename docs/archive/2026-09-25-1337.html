2. Fake Installers Deliver ScreenConnect and MacSync

Ransomware and Cybercrime · [malware, stealer, social-engineering]

Latest developments: Jamf Threat Labs flagged a new PamStealer build on September 25, 2026 that keeps its JavaScript for Automation dropper, swaps the lure and delivery method, and recovers its main payload only through a server-side decryption chain, layering persistence on macOS; Allure Security reported the same day that an attacker advertises desktop applications for three large United States payroll and human resources platforms that have never shipped one, and the installer plants ScreenConnect configured for silent remote control; Kaspersky traced the latest MacSync variant to a counterfeit cryptocurrency wallet called Toria, which runs its own website and draws traffic from X and Telegram.

read more

Ryan Merritt, director of security research at Allure Security, notes all three payroll providers deliver only web applications, so any downloadable client is a fake, and the MacSync variant steals credentials, wallet data, and files while pulling fresh payloads from public iCloud calendar events. Block installers for software that has no desktop edition and treat unsolicited wallet apps as hostile.

3. SharePoint and MikroTik Exploits Reach the KEV Catalog

Vulnerabilities and Exploits · [exploit, patch]

Latest developments: CISA added two actively exploited flaws to its Known Exploited Vulnerabilities catalog on September 25, 2026: CVE-2026-65660, the SharePoint Server code injection bug that Dinh Ho Anh Khoa of Viettel Cyber Security showed gives an authenticated user remote code execution, and CVE-2026-67279, the RouterOS SSH state-machine flaw that CERT Polska chained into the MikroTrick attack; CISA and BleepingComputer also detailed attacks on CVE-2026-5430, a 9.8-rated path traversal in WSO2 API Control Plane, and on CVE-2026-71362 in Adobe Commerce and Magento.

read more

Microsoft originally filed the SharePoint bug as a 6.5-rated spoofing issue, and MikroTrick hands an attacker administrative control of an internet-exposed router with no password and no completed authentication. Federal agencies face patch deadlines under Binding Operational Directive 26-04, and every operator of SharePoint Server 2016, 2019, Subscription Edition, RouterOS, WSO2, or Magento should patch now.
