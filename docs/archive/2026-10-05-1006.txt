1. NETSCALER ZERO-DAY HITS FRESHLY PATCHED APPLIANCES
   Vulnerabilities and Exploits · [zero-day, patch, exploit]
   Latest developments: Citrix confirmed that attackers
   exploited CVE-2026-88779, rated 8.7, against NetScaler ADC
   and Gateway appliances administrators had just patched for
   CVE-2026-88771 and CVE-2026-88772, and researchers tied the
   memory overflow to crashes that knock SAML authentication
   deployments offline while they test the bug for remote code
   execution.
   The flaw sits in how NetScaler ADC and NetScaler Gateway
   handle a memory buffer, and a single hit takes the appliance
   down, cutting remote access for everyone behind it. Citrix
   shipped emergency builds, and CISA placed the bug in its
   Known Exploited Vulnerabilities catalog, which starts the
   Binding Operational Directive 26-04 clock for federal
   agencies.

4. AI-FOUND REJETTO HFS FLAW UNDER ATTACK
   Vulnerabilities and Exploits · [exploit, ai, patch]
   Latest developments: VulnCheck reported on October 5, 2026
   that attackers are probing CVE-2026-61500, the 9.3-rated
   session forgery flaw in Rejetto HTTP File Server that an AI
   system discovered, where a weak pseudo-random number
   generator hands an attacker a predictable session-cookie
   signing key.
   Rejetto HFS is a small Windows file server that
   administrators and hobbyists expose straight to the internet.
   Whoever recovers the signing key forges an administrator
   session and runs code on the host, so upgrade the software or
   take the server off the internet.
   - SecurityWeek: https://www.securityweek.com/exploitation-hits-rejetto-hfs-vulnerability-discovered-by-ai/

5. CLING BOTNET TURNS STUN INTO COMMAND AND CONTROL
   Ransomware and Cybercrime · [malware, botnet, exploit]
   Latest developments: Nozomi Networks reported on October 5,
   2026 that attackers probing a patched critical flaw in the
   Realtek Jungle software development kit deliver Cling, a
   Linux back-connect proxy backdoor that researchers also call
   ClingSTUN, which hides its command and control inside
   ordinary STUN traffic and carries exploits for dozens of
   vulnerabilities to spread on its own.
   STUN is the protocol voice and video applications use to find
   a path through network address translation, and few defenders
   inspect it, so Cling's beacons pass as call setup. The
   malware lands on Linux systems and embedded devices built on
   Realtek's SDK, installs persistence, and scans for more hosts
   to exploit.
   - SecurityWeek: https://www.securityweek.com/linux-backdoor-abuses-stun-protocol-exploits-dozens-of-flaws/
   - The Hacker News: https://thehackernews.com/2026/10/realtek-jungle-sdk-exploit-attempts.html

   Ransomware and Cybercrime · [phishing, fraud]
   Latest developments: Group-IB reported on October 5, 2026
   that the Milk Dragon phishing kit, also known as NaiLong,
   pulls shoppers off Facebook and TikTok posts advertising fake
   brand discounts and onto pages that harvest payment card
   numbers and one-time passcodes, and counted 258 phishing
   pages and victims in 66 countries since the kit appeared in
   October 2025.

   clicks. Collecting the one-time passcode alongside the card
   number lets the operators complete the very transaction the
   bank asked the shopper to confirm, so reach retailers through
   their own sites.
