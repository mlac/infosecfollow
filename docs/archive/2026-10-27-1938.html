6. Brotli and Magento Bugs Enter the KEV Catalog

Vulnerabilities and Exploits · [patch, exploitation, supply chain]

Latest developments: CISA cited evidence of active exploitation on October 27, 2026 and added two flaws to its Known Exploited Vulnerabilities catalog: CVE-2026-111497, the unchecked return value bug in Google's Brotli compression library, and CVE-2026-48356, an unrestricted file upload flaw in Adobe Commerce and Magento; Help Net Security laid out how far the Brotli bug travels past the Node.js disclosure that made it famous on October 21, 2026.

read more

The Brotli out-of-bounds write, which researchers call Node2Shell, Broccoli2Shell, and Brotli2Shell, sits in the C library that Node.js, .NET, PowerShell, Bun, Envoy, and the Python brotli packages all bundle, and it fires when an application decompresses attacker-supplied Brotli data. Patch the runtimes and rebuild anything that statically links the library, and update Adobe Commerce and Magento storefronts now.

7. Tailscale Rushes Tailworm Patches

Vulnerabilities and Exploits · [vulnerability, patch, privilege escalation]

Latest developments: Tailscale's security team is building fixes for close to a dozen vulnerabilities in Tailscale SSH, the set researchers call Tailworm, after someone published the details over the weekend without coordinating with the company and before any patch existed; the bugs let an attacker steal credentials, crash servers, and escalate to root on machines reachable across the same network.

read more

Tailscale runs a WireGuard mesh that companies use as a flat private network, and Tailscale SSH authenticates logins through that mesh, so one compromised device reaches every server its access rules allow. 10. EDK2 Firmware Flaw Reaches Most Servers

Vulnerabilities and Exploits · [vulnerability, firmware, patch]

Latest developments: Ars Technica reported on October 27, 2026 that a critical flaw in EDK2 runs an attacker's code early in the boot process and affects most servers on the planet.

read more
