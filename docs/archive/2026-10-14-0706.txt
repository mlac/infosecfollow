1. EXPLOITED WINDOWS SHELL BUG STRIPS MARK OF THE WEB
   Vulnerabilities and Exploits · [patch, zero-day]
   Latest developments: Help Net Security detailed
   CVE-2026-96951 on October 14, 2026 as a Mark of the Web
   bypass in Windows Shell that a remote attacker triggers with
   a crafted file sent by email, instant message, Teams, or
   Slack; SecurityWeek and The Hacker News counted 1,413 fixes
   in the release, among them 1,102 in Windows, 134 in Office,
   and 36 in SharePoint Server; and Microsoft confirmed that the
   same updates stop non-admin users from connecting over Remote
   Desktop on devices running the Administrator protection
   feature.
   The Mark of the Web flag tells Windows a file came from the
   internet and triggers the warning prompts that follow;
   CVE-2026-96951 removes that signal, leaving SmartScreen and
   Office protections quiet. Attackers already exploit it, CISA
   put it in the Known Exploited Vulnerabilities catalog, and
   administrators who install the October updates should plan
   for the Remote Desktop regression and for Windows 11 24H2
   Home and Pro falling out of support.
   - Help Net Security: https://www.helpnetsecurity.com/2026/10/14/microsoft-patch-tuesday-cve-2026-96951-motw-bypass/

2. SAP, DOCKER HUB, AND GHOSTSCRIPT SHIP CRITICAL FIXES
   Vulnerabilities and Exploits · [patch, supply chain]
   Latest developments: SAP disclosed on October 13, 2026 a CVSS
   10 flaw in its Cloud SDK for Python that hands an
   application's OAuth2 client credentials to a server the
   attacker controls once the attacker controls a tenant
   subdomain, one of 20 fixes that also close critical NetWeaver
   and S/4HANA bugs; Docker patched CVE-2026-105445, a
   two-year-old Docker Hub flaw in the
   personal-account-to-organization conversion that let one user
   push, pull, or delete another user's images with a personal
   access token; the Ghostscript maintainers fixed
   CVE-2026-39919, a heap buffer overflow that reaches remote
   code execution through a crafted PDF; Citrix, Fortinet, and
   Ivanti together closed 29 flaws; and Adobe shipped 176 across
   11 products including Commerce, ColdFusion, and Photoshop.
   The flaws sit in build pipelines and document plumbing: any
   web service that renders uploaded PDFs through Ghostscript
   runs attacker code, and the Docker Hub bug let tampered
   images travel under a trusted publisher's name. Docker fixed
   its flaw on September 30, 2026 and found no evidence anyone
   exploited it; patch SAP Business Technology Platform
   applications, Ghostscript, and the Citrix, Fortinet, and
   Ivanti gateways now.
   - The Hacker News: https://thehackernews.com/2026/10/sap-discloses-critical-cvss-10-flaw-in.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/docker-hub-flaw-let-attackers-impersonate-users-tamper-with-images/

4. VGHOST FLAW BREAKS VIRTUAL MACHINES OUT TO THE HOST
   Vulnerabilities and Exploits · [vulnerability, cloud]
   Latest developments: Tencent Zhuque Lab, hunting with AI,
   found CVE-2026-74580, named Vghost, in the Linux kernel's
   vhost subsystem: a local user reads and writes kernel memory
   at will and becomes root across nearly a decade of kernel
   versions, and in one virtualization configuration an
   untrusted virtual machine writes to the host's memory and
   hijacks the process running it.
   vhost carries network and storage traffic for virtual
   machines inside the kernel, so cloud and hosting operators
   running multi-tenant KVM hold the exposure along with anyone
   who gives shell access to untrusted users. Patch kernels and
   start with hosts that run guests you do not control.
   - The Hacker News: https://thehackernews.com/2026/10/ai-found-linux-kernel-flaw-gives-local.html
