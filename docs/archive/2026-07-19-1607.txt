2. WP2SHELL WORDPRESS CORE RCE GETS PUBLIC EXPLOITS
   Vulnerabilities and Exploits · [rce, patch, exploit]
   Latest developments: Attackers now hold public exploits and a
   working proof-of-concept for the two wp2shell bugs, which
   carry CVE IDs CVE-2026-60137 and CVE-2026-63030, and
   researchers surfaced a persistent-object-cache variant that
   widens the reach.
   wp2shell pairs two WordPress core flaws—a facilitated SQL
   injection and a REST API batch-route confusion that chains to
   remote code execution—so a single anonymous HTTP request runs
   code on a bare install with zero plugins. Adam Kues of
   Assetnote and Searchlight Cyber, along with the trio TF1T,
   dtro, and haongo, reported the bugs; WordPress fixed them in
   6.9.5 and 7.0.2, so administrators of every 6.9 and 7.0 site
   must patch now.
