1. STOLEN CONNECTWISE CREDENTIAL OPENS 173 MICROSOFT 365 TENANTS
   Ransomware and Cybercrime · [supply chain, credential theft,
   cloud]
   Latest developments: ConnectWise shut customer access to its
   Cloud Backup service on October 17, 2026 after attackers
   reached the application identities behind it and compromised
   Microsoft 365 tenants, confirming the campaign researchers
   described a day earlier, in which one compromised Microsoft
   365 credential belonging to the service signed in to 173
   customer tenants.
   ConnectWise Cloud Backup, sold until recently as SkyKick,
   copies Microsoft 365 mail and files for managed service
   providers and their clients, so a single vendor credential
   reaches far down the customer chain. Administrators should
   pull sign-in logs for the ConnectWise service principal,
   revoke active sessions, and rotate application secrets.
   - The Hacker News: https://thehackernews.com/2026/10/hackers-use-compromised-connectwise.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack/

   Ransomware and Cybercrime · [supply chain, malware, npm]

8. EDITED OPEN WEIGHTS CARRY HIDDEN BACKDOORS
   Vulnerabilities and Exploits · [ai, supply chain]
   Latest developments: Bruce Schneier amplified research on
   October 16, 2026 showing that any open model whose weights
   someone has edited—a task-specific fine-tune, a merged
   adapter, or an abliterated build that strips the model's
   ability to refuse—can hide a backdoor that downloaders never
   verify, and Microsoft and NVIDIA published a whitepaper the
   same day laying out a shared taxonomy, evaluations, and
   controls for enterprises that run open-weight models.
   Enterprises pull modified open-weight models off public hubs
   to cut cost or remove refusals, and the edited weights arrive
   with no provenance a security team can check. Treat
   downloaded weights as untrusted code: pin sources, record
   hashes, and run the evaluations Microsoft and NVIDIA describe
   before deployment.
   - Schneier on Security: https://www.schneier.com/blog/archives/2026/10/backdooring-open-weight-ai-models.html
   - Microsoft Security Blog: https://www.microsoft.com/en-us/security/blog/2026/10/16/managing-open-weight-model-risk-in-enterprise-deployments/
