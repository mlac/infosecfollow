1. CITRIX NETSCALER ZERO-DAYS UNDER ACTIVE EXPLOITATION
   Vulnerabilities and Exploits · [zero-day, exploitation,
   patch]
   Latest developments: Citrix confirmed on September 27, 2026
   that attackers exploit CVE-2026-88771, an improper input
   validation flaw, and CVE-2026-88772, a memory buffer flaw,
   for remote code execution on NetScaler ADC and NetScaler
   Gateway, released fixes for those two plus six more
   vulnerabilities running through CVE-2026-88778, and CISA
   added both exploited bugs to its Known Exploited
   Vulnerabilities catalog; one of the two reaches every
   deployment on an affected version, including appliances in
   the default configuration.
   NetScaler ADC and Gateway terminate remote access and
   load-balance applications for enterprises worldwide, and
   remote code execution on one hands an attacker the network
   edge. Install the Citrix updates now and hunt for signs of
   compromise on any appliance that sat exposed before the
   patch.
   - The Hacker News: https://thehackernews.com/2026/09/warning-two-unpatched-citrix-netscaler.html
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/citrix-admins-warned-to-shut-down-netscalers-over-2-exploited-zero-days/
   - CISA Advisories: https://www.cisa.gov/news-events/alerts/2026/09/27/critical-zero-day-vulnerabilities-exploited-citrix-netscaler-adc-gateway
   - CISA Advisories: https://www.cisa.gov/news-events/alerts/2026/09/27/cisa-adds-two-known-exploited-vulnerabilities-catalog

2. SHAREPOINT EXPLOITATION PUTS AGENCIES ON A MONDAY DEADLINE
   Vulnerabilities and Exploits · [patch, exploitation, kev]
   Latest developments: SecurityWeek reported on September 27,
   2026 that attackers now exploit CVE-2026-65660 in the wild,
   and the CISA patching deadline for federal agencies falls
   Monday, September 28, 2026.
   CVE-2026-65660, rated 8.8, is a code injection flaw in
   Microsoft Office SharePoint Server that gives an
   authenticated user remote code execution; CISA listed it
   alongside CVE-2026-67279 in MikroTik RouterOS. Patch both,
   and treat any internet-facing SharePoint server as a
   priority.
   - SecurityWeek: https://www.securityweek.com/microsoft-sharepoint-flaw-cve-2026-65660-now-exploited-in-attacks/
   - The Hacker News: https://thehackernews.com/2026/09/sharepoint-rce-and-mikrotik-routeros.html

3. SCAREWARE ADS AND THE MACFINGER CLICKFIX CAMPAIGN
   Ransomware and Cybercrime · [malvertising, clickfix, social
   engineering]
   Latest developments: Ars Technica reported on September 25,
   2026 that Google ad placements across the internet deliver
   scareware that freezes a Mac and tells its owner the machine
   carries an infection, and the SANS Internet Storm Center
   published a breakdown of the malware behind the Macfinger
   ClickFix campaign the same day.
   Both routes convince the person at the keyboard to act: the
   ad fakes an infection warning, and ClickFix lures hand the
   victim a command to paste. Train staff to treat any browser
   page claiming an infection as hostile, and block the
   paste-and-run pattern at the endpoint.
   - Ars Technica Security: https://arstechnica.com/security/2026/09/google-ads-caught-delivering-convincing-scareware-ads-to-unsuspecting-users/
   - SANS Internet Storm Center: https://isc.sans.edu/diary/rss/33368

4. WIRESHARK PATCHES 19 FLAWS AS AN OFFICE UPDATE DEACTIVATES
   LICENSES
   Vulnerabilities and Exploits · [patch, vulnerability]
   Latest developments: The Wireshark project shipped release
   4.6.9 on September 27, 2026, closing 19 vulnerabilities and
   16 bugs in the packet analyzer that sits on nearly every
   incident responder's laptop, and Microsoft halted the rollout
   of the KB5002907 Microsoft 365 update after it deactivated
   and in some cases removed perpetual Office 2016 and Office
   2019 installations.
   Wireshark parses untrusted capture files, so a malformed
   packet trace turns its dissectors into an attack surface
   against the analyst; update to 4.6.9. Organizations running
   perpetual Office licenses alongside Microsoft 365 should hold
   KB5002907 until Microsoft resumes the rollout.
   - SANS Internet Storm Center: https://isc.sans.edu/diary/rss/33372
   - BleepingComputer: https://www.bleepingcomputer.com/news/microsoft/microsoft-365-kb5002907-update-paused-after-office-license-deactivations/

5. CLOUDFLARE CONTAINERS LEAKED DATA ACROSS TENANTS
   Vulnerabilities and Exploits · [cloud, vulnerability]
   Latest developments: Cloudflare fixed a vulnerability in its
   Containers and Sandboxes products, BleepingComputer reported
   on September 27, 2026, that let any customer holding a
   Workers Paid account recover residual data from other
   customers' containers sharing the same physical host.
   Containers and Sandboxes run customer workloads on
   Cloudflare's shared fleet, and the flaw broke the isolation
   boundary that separates one tenant's leftover data from the
   next tenant on the machine. Cloudflare deployed the fix on
   its own platform, so customers take no action, though anyone
   who ran sensitive workloads on the service should weigh what
   data the containers held.
   - BleepingComputer: https://www.bleepingcomputer.com/news/security/cloudflare-fixes-containers-cross-tenant-flaw-exposing-customer-data/

   Policy and Regulation · [policy, elections, patch]
   Latest developments: CISA published the election security
   plan that Homeland Security Secretary Markwayne Mullin
   ordered in July 2026, and it flags attacks on voter

   offices from patching their systems.
   State and county election offices run the machinery of
   American voting on small budgets and thin staff, which leaves

   federal election cycle.
   - SecurityWeek: https://www.securityweek.com/cisa-election-security-plan-flags-patching-barriers-voter-database-attacks/

8. CONIFERS FINDS DETECTION RULES FAILING QUIETLY
   Security Operations · [detection, soc]
   Latest developments: Conifers assessed 14,652 detection rules
   across its customer base and found that 47 percent of the
   detections in the average organization need attention, with
   failures falling into five groups that start with logic bugs.
   The study covered rules customers wrote themselves and rules
   vendors manage inside SIEM, endpoint, cloud, identity, email,
   and network tools. A rule can show as deployed on a coverage
   dashboard and still never fire when an attacker uses the
   technique it targets, so test detections against real
   technique execution instead of trusting the dashboard.
   - Help Net Security: https://www.helpnetsecurity.com/2026/09/25/threat-detections-coverage-gaps-report/
